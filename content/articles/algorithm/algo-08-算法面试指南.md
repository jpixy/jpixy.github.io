## 解题流程

### 标准步骤

1. **理解问题**（2-3分钟）
   - 复述问题确认理解
   - 澄清边界条件和约束
   - 问清输入输出格式

2. **举例验证**（1-2分钟）
   - 用简单例子确认理解
   - 思考边界情况

3. **设计方案**（5-10分钟）
   - 从暴力解法开始
   - 分析优化空间
   - 讨论多种方案

4. **编写代码**（10-15分钟）
   - 边写边解释
   - 保持代码清晰

5. **测试验证**（3-5分钟）
   - 手动走一遍测试用例
   - 检查边界情况

6. **优化讨论**（2-3分钟）
   - 分析复杂度
   - 讨论优化方向

## 复杂度分析

### 时间复杂度

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 数组访问 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历数组 |
| O(n log n) | 线性对数 | 归并排序 |
| O(n²) | 平方 | 双重循环 |
| O(2^n) | 指数 | 子集枚举 |
| O(n!) | 阶乘 | 全排列 |

### 常见算法复杂度

| 算法 | 时间 | 空间 |
|------|------|------|
| 二分查找 | O(log n) | O(1) |
| 归并排序 | O(n log n) | O(n) |
| 快速排序 | O(n log n)平均 | O(log n) |
| 堆排序 | O(n log n) | O(1) |
| DFS/BFS | O(V + E) | O(V) |
| Dijkstra | O((V+E) log V) | O(V) |
| 动态规划 | 取决于状态数 | 取决于状态数 |

### 数据规模与复杂度

| 数据规模 | 可接受复杂度 |
|----------|--------------|
| n ≤ 10 | O(n!) |
| n ≤ 20 | O(2^n) |
| n ≤ 500 | O(n³) |
| n ≤ 5000 | O(n²) |
| n ≤ 10^6 | O(n log n) |
| n ≤ 10^8 | O(n) |
| n > 10^8 | O(log n) 或 O(1) |

## 代码模板

### 二分查找

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### BFS

```python
def bfs(start):
    queue = deque([start])
    visited = {start}
    level = 0
    
    while queue:
        for _ in range(len(queue)):
            node = queue.popleft()
            for neighbor in get_neighbors(node):
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        level += 1
    
    return level
```

### DFS

```python
def dfs(node, visited):
    if node in visited:
        return
    visited.add(node)
    for neighbor in get_neighbors(node):
        dfs(neighbor, visited)
```

### 回溯

```python
def backtrack(path, choices):
    if is_valid(path):
        result.append(path[:])
        return
    
    for choice in choices:
        if not valid(choice):
            continue
        path.append(choice)
        backtrack(path, new_choices)
        path.pop()
```

## 面试技巧

### DO

- **边思考边说**：展示思维过程
- **先说思路**：获得认可后再编码
- **从暴力开始**：然后优化
- **写简洁代码**：变量名清晰
- **主动测试**：展示严谨性
- **分析复杂度**：时间和空间

### DON'T

- **沉默思考太久**：1-2分钟后要开口
- **直接上最优解**：可能遗漏思路
- **忽略边界情况**：空输入、单元素
- **代码太乱**：影响阅读和调试
- **复制粘贴**：说明理解不够

### 沟通话术

```
"让我确认一下问题..."
"先考虑暴力解法..."
"这个复杂度是O(n²)，可以优化..."
"我用XX方法，因为..."
"让我用这个例子验证一下..."
"边界情况包括..."
```

## 准备策略

### 刷题顺序

1. **基础**：数组、链表、栈、队列
2. **进阶**：树、图、堆
3. **技巧**：双指针、滑动窗口、二分
4. **综合**：动态规划、回溯

### 刷题方法

- **质量重于数量**：真正理解每道题
- **分类练习**：集中突破一类
- **定时练习**：模拟面试环境
- **总结模板**：建立自己的模板库

## 总结

| 阶段 | 关键点 |
|------|--------|
| 理解 | 复述、澄清、举例 |
| 设计 | 暴力→优化→确认 |
| 编码 | 边写边说、清晰 |
| 测试 | 手动验证、边界 |
| 分析 | 时空复杂度 |

算法面试考察的是**思维过程**和**代码能力**，多练习、多总结是提升的关键。
