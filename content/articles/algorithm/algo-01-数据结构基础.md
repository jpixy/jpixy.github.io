## 数组

### 特点

- **连续内存**：元素紧密排列
- **随机访问**：O(1)通过索引访问
- **固定大小**（静态数组）或**动态扩容**

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| 访问 | O(1) |
| 搜索 | O(n) |
| 插入 | O(n) |
| 删除 | O(n) |
| 尾部插入 | O(1)摊还 |

### 常见技巧

**双指针**：
- 两端向中间：回文、两数之和
- 快慢指针：环检测、中点查找
- 滑动窗口：子数组问题

**前缀和**：
预处理累计和，O(1)查询区间和。

```
原数组: [1, 2, 3, 4, 5]
前缀和: [0, 1, 3, 6, 10, 15]
区间[i,j]的和 = prefix[j+1] - prefix[i]
```

## 链表

### 类型

| 类型 | 特点 |
|------|------|
| 单链表 | 只能向后遍历 |
| 双链表 | 可前后遍历 |
| 循环链表 | 尾节点指向头 |

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| 访问 | O(n) |
| 搜索 | O(n) |
| 插入（已知位置） | O(1) |
| 删除（已知位置） | O(1) |

### 常见技巧

**哑节点（Dummy Node）**：
简化头节点处理。

```
dummy → 1 → 2 → 3
返回 dummy.next
```

**快慢指针**：
- 找中点：快指针走两步，慢指针走一步
- 检测环：快慢指针相遇
- 倒数第k个：快指针先走k步

**反转链表**：
```
prev = null, curr = head
while curr:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
return prev
```

## 栈

### 特点

- **LIFO**：后进先出
- **操作**：push、pop、peek

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| Push | O(1) |
| Pop | O(1) |
| Peek | O(1) |

### 应用场景

- 括号匹配
- 表达式求值
- 深度优先搜索
- 单调栈

### 单调栈

维护单调递增或递减的栈，用于找下一个更大/更小元素。

```
问题：每个元素右边第一个比它大的元素
输入: [2, 1, 2, 4, 3]
输出: [4, 2, 4, -1, -1]

使用单调递减栈
```

## 队列

### 类型

| 类型 | 特点 |
|------|------|
| 普通队列 | FIFO |
| 双端队列 | 两端都可操作 |
| 优先队列 | 按优先级出队 |

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Peek | O(1) |

### 应用场景

- 广度优先搜索
- 任务调度
- 缓存淘汰
- 滑动窗口最大值（单调队列）

### 单调队列

维护滑动窗口的最大/最小值。

```
问题：滑动窗口最大值
使用双端队列，维护递减序列
新元素入队前，移除所有比它小的元素
```

## 哈希表

### 特点

- **键值映射**
- **平均O(1)操作**
- **无序**

### 复杂度

| 操作 | 平均 | 最差 |
|------|------|------|
| 插入 | O(1) | O(n) |
| 删除 | O(1) | O(n) |
| 查找 | O(1) | O(n) |

### 冲突解决

**链地址法**：
冲突的元素存储在链表中。

**开放地址法**：
- 线性探测：顺序查找下一个空位
- 二次探测：按平方跳跃
- 双重哈希：使用第二个哈希函数

### 应用场景

- 两数之和
- 查重/去重
- 计数
- 缓存

## 堆

### 特点

- **完全二叉树**
- **最大堆**：父节点 ≥ 子节点
- **最小堆**：父节点 ≤ 子节点

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| 插入 | O(log n) |
| 删除顶部 | O(log n) |
| 获取顶部 | O(1) |
| 建堆 | O(n) |

### 数组实现

```
父节点: (i-1) / 2
左子节点: 2*i + 1
右子节点: 2*i + 2
```

### 应用场景

- 优先队列
- 堆排序
- Top K问题
- 合并K个有序链表
- 中位数维护（大顶堆+小顶堆）

### Top K问题

**找最大的K个**：维护大小为K的最小堆
**找最小的K个**：维护大小为K的最大堆

## 字符串

### 常见操作

- 子串搜索
- 回文判断
- 字符串匹配

### KMP算法

利用已匹配信息，避免回溯。

关键：构建next数组（前缀函数）。

### Rabin-Karp算法

使用哈希滚动匹配，适合多模式匹配。

### 字典树（Trie）

前缀树，用于：
- 前缀搜索
- 自动补全
- 拼写检查

```
插入: O(m)，m为字符串长度
搜索: O(m)
前缀搜索: O(m)
```

## 并查集

### 特点

- **集合合并**：O(α(n)) ≈ O(1)
- **集合查询**：O(α(n)) ≈ O(1)

### 核心操作

**Find**：找到元素所属集合的根

**Union**：合并两个集合

### 优化

- **路径压缩**：查找时压平路径
- **按秩合并**：小树合并到大树

### 应用场景

- 连通分量
- 判断环
- 最小生成树（Kruskal）

## 选择指南

| 需求 | 数据结构 |
|------|----------|
| 快速访问 | 数组 |
| 频繁插入删除 | 链表 |
| LIFO | 栈 |
| FIFO | 队列 |
| 快速查找 | 哈希表 |
| 有序数据 | 树 |
| 优先级 | 堆 |
| 连通性 | 并查集 |

---

## 总结

| 数据结构 | 优势 | 劣势 |
|----------|------|------|
| 数组 | 随机访问快 | 插入删除慢 |
| 链表 | 插入删除快 | 访问慢 |
| 栈/队列 | 特定顺序访问 | 功能受限 |
| 哈希表 | 查找快 | 无序、空间大 |
| 堆 | 快速获取极值 | 只能访问顶部 |

选择合适的数据结构是算法设计的第一步。
