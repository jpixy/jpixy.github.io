# 销售获客与客户开发

## 一、客户来源全景图

### 1.1 To B销售的客户来源

```
                    客户来源
                       │
        ┌──────────────┼──────────────┐
        │              │              │
     公司提供        自主开发        转介绍
        │              │              │
  ┌─────┴─────┐  ┌─────┴─────┐  ┌─────┴─────┐
  │           │  │           │  │           │
市场线索  分配客户  人脉拓展  陌生开发  老客户  合作伙伴
                                 推荐      推荐
```

### 1.2 各来源占比（典型企业）

| 客户来源 | 占比 | 转化率 | 特点 |
|----------|------|--------|------|
| 市场线索 | 40% | 15-25% | 量大但质量参差 |
| 存量客户增购 | 25% | 40-60% | 最高转化率 |
| 销售自拓 | 20% | 10-20% | 考验销售能力 |
| 渠道/伙伴推荐 | 10% | 25-35% | 质量较高 |
| 老客户转介绍 | 5% | 30-50% | 信任度高 |

## 二、公司提供的销售线索

### 2.1 市场部线索来源

**线上渠道**：
- 官网注册/表单提交
- 内容下载（白皮书、报告）
- Webinar/直播参与者
- 广告投放（SEM、信息流）
- 社交媒体互动

**线下渠道**：
- 行业展会/峰会
- 客户沙龙/研讨会
- 商务合作
- 媒体活动

### 2.2 线索分配机制

**按区域分配**：
```
├── 华北区销售 → 北京、天津、河北...
├── 华东区销售 → 上海、江苏、浙江...
├── 华南区销售 → 广东、福建、海南...
└── ...
```

**按行业分配**：
```
├── 金融行业销售 → 银行、保险、证券线索
├── 政府行业销售 → 政府、公安、教育线索
├── 制造行业销售 → 工业、汽车、电子线索
└── ...
```

**按客户规模分配**：
```
├── KA销售 → 年收入>10亿的企业
├── 中型客户销售 → 年收入1-10亿的企业
└── SMB销售 → 年收入<1亿的企业
```

### 2.3 如何高效跟进公司线索

**线索跟进SOP**：

```
收到线索（0小时）
    │
    ├── 1. 线索清洗（1小时内）
    │   └── 核实公司信息、联系人信息
    │
    ├── 2. 首次触达（24小时内）
    │   └── 电话/邮件/微信
    │
    ├── 3. 需求确认（48小时内）
    │   └── 确认需求真实性、预算、时间表
    │
    ├── 4. 线索评级
    │   ├── A类（高意向）→ 重点跟进
    │   ├── B类（中意向）→ 持续培育
    │   └── C类（低意向）→ 放入池子
    │
    └── 5. 进入销售流程
        └── 约访、方案、POC...
```

**线索跟进技巧**：

| 线索类型 | 跟进策略 | 话术要点 |
|----------|----------|----------|
| 内容下载 | 提供更多相关资料 | "您下载的白皮书对您有帮助吗？" |
| Webinar参与 | 针对会议内容跟进 | "关于会上讲的XX，您有什么问题吗？" |
| 官网咨询 | 快速响应需求 | "您咨询的XX产品，我来详细介绍下" |
| 展会名片 | 回顾现场交流 | "展会上和您聊过，您提到的XX需求..." |

## 三、人脉开发与维护

### 3.1 人脉的价值

```
人脉类型
├── 强关系（信任度高，转化率高）
│   ├── 前同事
│   ├── 前客户
│   ├── 同学/校友
│   └── 深度合作伙伴
│
├── 弱关系（数量大，机会广）
│   ├── 行业活动认识
│   ├── 社交媒体连接
│   ├── 朋友的朋友
│   └── 一面之缘
│
└── 潜在关系（待激活）
    ├── 目标客户高管
    ├── 行业KOL
    └── 关键决策人
```

### 3.2 人脉开发策略

**1. 存量人脉梳理**

```
步骤1：盘点现有人脉
├── 翻看微信通讯录
├── 整理名片盒
├── 回顾前公司同事
├── 梳理校友资源
└── 列出所有可能的连接

步骤2：分类标注
├── 决策人：能直接拍板
├── 影响人：能影响决策
├── 信息人：能提供情报
└── 引荐人：能介绍资源

步骤3：制定触达计划
└── 每周重新连接5个旧人脉
```

**2. 新人脉拓展**

| 方法 | 具体操作 | 预期效果 |
|------|----------|----------|
| 行业活动 | 参加峰会、沙龙、论坛 | 每次3-5个有效名片 |
| 内容输出 | 写文章、做分享、发动态 | 吸引同频人主动连接 |
| 社群运营 | 加入/创建行业社群 | 持续曝光建立影响力 |
| 校友会 | 参与校友活动、建立连接 | 天然信任关系 |
| 行业协会 | 加入协会、参与工作 | 获取行业人脉资源 |

### 3.3 人脉维护的关键

**黄金法则：先给予，后索取**

```
错误做法：
"李总您好，我是XX公司的销售，我们有个产品..."
→ 立即推销，99%被忽略

正确做法：
1. 先建立连接
2. 持续提供价值（行业资讯、人脉介绍、问题解答）
3. 等待需求出现
4. 自然切入业务
```

**人脉维护SOP**：

| 关系等级 | 维护频率 | 维护方式 |
|----------|----------|----------|
| 核心客户/人脉 | 每周 | 电话/见面/深度交流 |
| 重要人脉 | 每月 | 微信/有价值的分享 |
| 一般人脉 | 每季度 | 节日问候/行业信息 |
| 休眠人脉 | 每半年 | 重新激活尝试 |

## 四、人脉用完了怎么办？

### 4.1 问题诊断

**人脉用完的表现**：
- 找不到新的约访对象
- 每次拜访都是陌生人
- 没有人帮忙引荐
- 陷入"打陌call"循环

**根本原因**：
1. 只消耗不补充
2. 单向索取不给予
3. 没有系统化经营
4. 不注重口碑积累

### 4.2 破局策略

**策略一：老客户转介绍**

```
时机选择：
├── 项目成功交付后
├── 客户主动表达满意后
├── 帮客户解决了大问题后
└── 客户续约/增购时

话术模板：
"张总，这次项目合作很愉快，您对我们的服务满意吗？"
（等待肯定回答）
"您身边有没有类似需求的朋友？如果您觉得我们做得好，
能否帮忙引荐一下？"

激励机制：
├── 商务回馈（折扣、礼品）
├── 关系回馈（帮客户解决其他问题）
└── 荣誉回馈（客户案例、公开感谢）
```

**策略二：圈层渗透**

```
找到一个行业切入点：
    │
    ├── 做好一个标杆案例
    │   │
    │   ├── 案例包装（痛点→方案→效果）
    │   │
    │   └── 案例传播
    │       ├── 客户背书
    │       ├── 行业活动分享
    │       └── 媒体/自媒体传播
    │
    └── 通过标杆辐射同行
        ├── "XX公司在用我们的方案"
        ├── 同行交流活动
        └── 行业社群传播
```

**策略三：生态合作**

```
合作伙伴类型：
├── 互补产品厂商
│   └── 你卖云，他卖ERP，互相推荐
│
├── 咨询/实施公司
│   └── 他做咨询，你提供产品
│
├── 渠道代理商
│   └── 他有客户，你有产品
│
└── 行业专家/顾问
    └── 他有影响力，你有解决方案
```

### 4.3 建立持续获客引擎

**个人品牌打造**：

```
输入：
├── 深耕行业知识
├── 积累客户案例
├── 持续学习提升
└── 建立独特见解

输出：
├── 朋友圈/社交媒体内容
├── 行业文章/观点
├── 公开分享/演讲
└── 社群互动/答疑

效果：
├── 吸引客户主动咨询
├── 建立专业信任
├── 获得转介绍
└── 形成正向循环
```

**销售版"增长飞轮"**：

```
     ┌────────────────────┐
     │                    │
     ↓                    │
  专业服务              好口碑
     │                    ↑
     ↓                    │
  客户成功 ────────→ 客户转介绍
     │                    │
     ↓                    │
  更多客户 ←──────────────┘
```

## 五、陌生客户开发

### 5.1 陌生开发的必要性

> 即使有再多线索和人脉，优秀销售都不放弃陌生开发。
> 因为最好的客户可能不在现有池子里。

**陌生开发价值**：
- 突破现有客户圈层
- 发现新的市场机会
- 锻炼销售基本功
- 不依赖公司资源

### 5.2 目标客户研究

**客户画像构建**：

```
理想客户画像（ICP）
├── 公司特征
│   ├── 行业：金融/制造/零售...
│   ├── 规模：年收入/员工数
│   ├── 发展阶段：成长期/成熟期
│   └── 技术现状：现有系统/痛点
│
├── 决策特征
│   ├── 决策流程：快速/漫长
│   ├── 预算周期：年度/项目制
│   └── 决策链：IT主导/业务主导
│
└── 个人特征
    ├── 职位：CTO/IT总监/业务负责人
    ├── 职能：技术/业务/采购
    └── 痛点：效率/成本/合规
```

**目标客户名单构建**：

| 信息来源 | 具体方法 |
|----------|----------|
| 行业报告 | 行业100强、细分领域排名 |
| 企业数据库 | 天眼查、企查查、IT桔子 |
| 招聘信息 | 目标客户在招什么岗位 |
| 新闻动态 | 融资、扩张、数字化项目 |
| 社交媒体 | LinkedIn、脉脉 |
| 行业活动 | 参会名单、演讲嘉宾 |

### 5.3 陌生触达方法

**电话开发**：

```
准备工作：
├── 研究客户背景
├── 准备开场白
├── 预判可能问题
└── 设定本次目标

电话结构：
├── 开场（10秒）
│   └── 自我介绍 + 价值一句话
│
├── 破冰（20秒）
│   └── 为什么打给你 + 相关性
│
├── 价值（30秒）
│   └── 我们能解决什么问题
│
├── 确认（20秒）
│   └── 这对您重要吗？
│
└── 行动（10秒）
    └── 约时间/发资料/其他

示例：
"王总您好，我是XX公司的张三，专注数据库领域。
看到贵公司在招数据库DBA，猜测您们在这块有规划。
我们帮XX银行节省了40%的数据库成本，
不知道这个话题对您有没有价值？
方便的话，我发个资料给您看看？"
```

**邮件开发**：

```
主题行（决定是否打开）
├── 个性化：提及公司名/具体问题
├── 价值导向：强调收益
└── 好奇心：引发兴趣

示例：[公司名]数据库成本优化方案

正文结构：
├── 第一段：为什么写这封邮件（相关性）
├── 第二段：我们是谁/能解决什么问题
├── 第三段：相似客户案例（一句话）
└── 第四段：清晰的CTA（行动召唤）

注意：
├── 控制在150字以内
├── 不要附件（会被拦截）
├── 移动端友好
└── 持续跟进（3-5次）
```

**LinkedIn/脉脉开发**：

```
步骤1：完善个人主页
├── 专业头像
├── 价值主张明确
└── 内容持续更新

步骤2：精准添加连接
├── 搜索目标公司+职位
├── 添加时写个性化备注
└── 不要立即推销

步骤3：价值互动
├── 点赞评论对方动态
├── 分享有价值的内容
├── 逐步建立关系

步骤4：自然切入
└── 关系建立后，自然过渡到业务
```

## 六、保持获客持续性

### 6.1 时间分配原则

**三三三法则**：

```
销售时间分配：
├── 1/3 跟进现有商机
│   └── 推进成交
│
├── 1/3 维护存量客户
│   └── 续约增购
│
└── 1/3 开发新客户
    └── 补充漏斗
```

### 6.2 建立销售漏斗纪律

**每周检查清单**：

```
□ 本周新增了几个线索？
□ 约了几个新客户见面？
□ 商机池是否健康？
□ 有没有花时间做新开发？
□ 有没有请老客户帮忙介绍？
```

**漏斗健康度**：

```
理想漏斗结构：
├── 线索：100个
├── 初步沟通：50个
├── 方案阶段：20个
├── POC/试用：10个
├── 商务谈判：5个
└── 签约：2-3个

如果只有商务阶段的单，
说明上游开发不足，
下个月必然面临断粮。
```

### 6.3 心态建设

**关于拒绝**：
- 被拒绝是常态，不是失败
- 每100个cold call，5个会有兴趣
- 每20个见面，1个可能成交
- 拒绝只是"现在不需要"，不是"永远不需要"

**关于坚持**：
> 销售的成功公式：
> **能力 × 努力 × 坚持 = 结果**
> 
> 人脉会用完，但能力不会。
> 方法会过时，但勤奋不会。
> 客户会流失，但口碑不会。

## 七、总结

### 7.1 获客来源优先级

```
1. 老客户转介绍（最高转化率）
2. 存量客户增购（最低成本）
3. 市场线索跟进（量大）
4. 人脉开发（信任度高）
5. 陌生开发（保持基本功）
```

### 7.2 核心观点

1. **不要只依赖公司线索**：公司线索是锦上添花，不是唯一来源
2. **人脉是用出来的**：但要先存后取，给予先于索取
3. **陌生开发不能丢**：最好的客户可能在你的舒适区之外
4. **口碑是最好的获客**：做好每一个客户，让客户帮你介绍客户
5. **持续性大于爆发力**：每天开发一点，比突击一周更有效

### 7.3 行动清单

```
今天：
□ 盘点现有人脉，找出5个可以重新连接的人

本周：
□ 请一个满意客户帮忙介绍
□ 做3个陌生cold call
□ 在社交媒体发一条有价值的内容

本月：
□ 参加一个行业活动
□ 建立一个客户案例
□ 发展一个合作伙伴关系
```
