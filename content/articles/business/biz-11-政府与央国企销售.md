# 政府与央国企销售

## 一、政府/央国企市场概述

### 1.1 市场特点

**政府/央国企 vs 民企销售对比**：

| 维度 | 政府/央国企 | 民营企业 |
|------|------------|----------|
| 决策周期 | 长（6-24个月） | 相对短（1-6个月） |
| 决策流程 | 复杂、多层审批 | 相对灵活 |
| 预算机制 | 年度预算、专项预算 | 灵活调整 |
| 采购方式 | 招投标为主 | 商务谈判为主 |
| 合规要求 | 极高 | 一般 |
| 关系因素 | 重要但需合规 | 重要 |
| 付款周期 | 较长 | 可协商 |
| 客户粘性 | 高（换供应商难） | 中等 |

### 1.2 客户分类

```
政府类客户：
├── 中央部委
├── 省级政府及厅局
├── 地市级政府
├── 区县级政府
├── 事业单位
└── 公检法司

央企国企：
├── 央企（97家）
│   ├── 总部
│   ├── 二级单位
│   └── 三级及以下
├── 省属国企
├── 市属国企
└── 国有金融机构
```

### 1.3 预算与采购周期

**年度预算周期**：

```
时间线：

7-9月：预算编制
├── 各部门提需求
├── 信息化规划
└── 预算申报

10-12月：预算审批
├── 内部审批
├── 财政审核
└── 预算批复

1-3月：预算下达
├── 预算正式下达
├── 项目立项
└── 采购准备

4-6月：采购执行
├── 采购招标
├── 合同签订
└── 项目实施

7-12月：验收付款
├── 项目验收
├── 审计检查
└── 款项支付

⚠️ 关键：预算不进入=全年没机会
```

## 二、政府采购流程

### 2.1 采购方式

**法定采购方式**：

```
公开招标（最常用）：
├── 金额：>400万（货物服务）/>200万（工程）
├── 特点：公开、公平、竞争
├── 周期：1-3个月
└── 要求：资质、业绩、技术方案

邀请招标：
├── 适用：技术复杂、供应商有限
├── 特点：邀请3家以上投标
└── 需要：审批同意

竞争性谈判：
├── 适用：招标失败、紧急采购
├── 特点：与供应商谈判
└── 数量：3家以上

单一来源采购：
├── 适用：唯一供应商、专利产品
├── 特点：直接采购
├── 要求：审批严格
└── 公示：需公示理由

询价采购：
├── 适用：标准化产品
├── 特点：比价采购
└── 金额：较小项目
```

### 2.2 招投标流程

**完整招投标流程**：

```
1. 项目立项
   ├── 需求论证
   ├── 可行性研究
   ├── 预算申请
   └── 立项批复

2. 采购准备
   ├── 编制采购计划
   ├── 选择采购方式
   ├── 编制招标文件
   └── 发布招标公告

3. 投标
   ├── 获取招标文件
   ├── 编制投标文件
   ├── 投标保证金
   └── 递交投标文件

4. 评标
   ├── 开标
   ├── 资格审查
   ├── 技术评审
   ├── 商务评审
   └── 综合评分

5. 定标
   ├── 评标报告
   ├── 中标公示
   ├── 中标通知
   └── 质疑/投诉处理

6. 合同签订
   ├── 合同谈判
   ├── 合同审批
   ├── 合同签订
   └── 履约保证金

7. 履约验收
   ├── 项目实施
   ├── 验收评审
   ├── 付款申请
   └── 资金支付
```

### 2.3 评标方法

**常见评标方法**：

```
综合评分法（最常用）：
├── 技术分（40-60%）
│   ├── 技术方案
│   ├── 实施方案
│   ├── 服务方案
│   └── 技术资质
├── 商务分（20-40%）
│   ├── 价格分
│   ├── 业绩分
│   ├── 资质分
│   └── 信誉分
└── 综合分 = 技术分 + 商务分

最低价中标法：
├── 满足基本要求
├── 最低报价中标
└── 适用于标准化产品

⚠️ 技术标一般有门槛分（如60分）
⚠️ 低于门槛分直接淘汰
```

## 三、央国企销售特点

### 3.1 决策特点

**决策链条**：

```
典型央企决策链：

业务需求部门
     │
     ↓
信息化部门（IT）
     │
     ↓
采购部门
     │
     ↓
财务部门
     │
     ↓
分管领导
     │
     ↓
总经理办公会/党委会
     │
     ↓
集团审批（如需）
```

**决策特点**：

```
集体决策：
├── 三重一大制度
├── 党委会/董事会决策
├── 会议纪要记录
└── 个人不敢独断

流程合规：
├── 流程不能省略
├── 审批层层进行
├── 留痕备查
└── 审计风险意识

风险规避：
├── 选择大品牌
├── 选择有业绩的
├── 不愿当第一个吃螃蟹
└── "用xxx没问题"

预算驱动：
├── 有预算才能买
├── 预算额度限制
├── 预算使用时间
└── 年底突击花钱
```

### 3.2 国企合规要求

**合规红线**：

```
招投标合规：
├── 不得围标串标
├── 不得泄露标底
├── 不得指定品牌
├── 不得设置歧视性条款
└── 保证充分竞争

商业行为合规：
├── 禁止商业贿赂
├── 礼品馈赠限制
├── 宴请限制
├── 差旅费用合规
└── 廉政承诺书

利益冲突合规：
├── 关联交易披露
├── 亲属回避
├── 离职后回避期
└── 供应商管理

⚠️ 违规后果：
├── 供应商黑名单
├── 项目作废
├── 刑事责任
└── 职业生涯影响
```

## 四、销售策略

### 4.1 项目发现

**信息渠道**：

```
公开渠道：
├── 政府采购网（中央、各省）
├── 中国招标投标公共服务平台
├── 各央企采购平台
├── 发改委项目公示
└── 信息化规划文件

关系渠道：
├── 老客户复购/扩展
├── 合作伙伴推荐
├── 行业圈子
├── SI/集成商
└── 咨询公司

市场活动：
├── 行业峰会
├── 客户交流会
├── 专题研讨
└── 案例分享会
```

### 4.2 前期运作

**项目运作节奏**：

```
预算前（关键！）：
├── 了解客户规划
├── 引导需求方向
├── 影响预算金额
├── 推动预算立项
└── 目标：进入预算

招标前：
├── 深入了解需求
├── 技术交流
├── 方案讨论
├── 试点/POC
├── 影响招标参数
└── 目标：设置门槛

招标中：
├── 高质量投标
├── 技术方案优化
├── 价格策略
├── 风险规避
└── 目标：高分中标

中标后：
├── 高质量交付
├── 客户关系维护
├── 持续服务
├── 挖掘新需求
└── 目标：复购扩展
```

### 4.3 关系策略

**关键角色识别**：

```
用户（User）：
├── 使用产品的人
├── 提出业务需求
├── 评估产品好坏
└── 策略：满足需求、建立口碑

技术评估者（Tech Buyer）：
├── IT/信息化部门
├── 技术评估把关
├── 参与方案评审
└── 策略：技术认可、消除顾虑

经济决策者（Economic Buyer）：
├── 控制预算
├── 最终审批
├── 通常是领导
└── 策略：展现价值、建立信任

Coach（内线）：
├── 支持你的人
├── 提供信息
├── 帮助推动
└── 策略：维护关系、信息对称
```

**合规的关系建设**：

```
可以做的：
├── 技术交流
├── 案例分享
├── 专家座谈
├── 培训赋能
├── 行业活动邀请
├── 正常商务宴请（合理标准）
└── 产品试用

不能做的：
├── 商业贿赂
├── 回扣
├── 超标准礼品
├── 利益输送
├── 围标串标
├── 泄露竞争信息
└── 任何违法违规行为
```

### 5.3 报价策略

**定价考虑因素**：

```
成本因素：
├── 产品成本
├── 实施成本
├── 服务成本
├── 管理成本
└── 利润要求

竞争因素：
├── 竞对可能报价
├── 历史成交价
├── 预算金额
└── 最低价风险

评分因素：
├── 价格分计算方式
├── 最高限价
```

## 七、常见问题与应对

### 7.1 常见挑战

```
挑战1：进不了预算
├── 原因：前期工作不足
├── 应对：提前一年布局
└── 方法：参与规划、影响需求

挑战2：招标参数不利
├── 原因：竞对运作
├── 应对：合法合规质疑
└── 预防：前期技术交流

挑战3：价格战
├── 原因：恶性竞争
├── 应对：差异化、技术分
└── 底线：不做亏损项目

挑战4：关系不如竞对
├── 原因：客户关系薄弱
├── 应对：产品+方案+服务
└── 长期：持续投入客户关系

挑战5：回款困难
├── 原因：流程长、预算紧
├── 应对：及时跟进、关系维护
└── 预防：合同条款、客户资信
```

### 7.2 风险防范

```
合规风险：
├── 所有行为留痕
├── 不触碰红线
├── 合规培训
└── 法务审核

合同风险：
├── 条款仔细审核
├── 付款条款明确
├── 违约责任清晰
└── 法务把关

交付风险：
├── 范围清晰界定
├── 变更走流程
├── 资源提前准备
└── 风险定期评估

回款风险：
├── 客户资信评估
├── 分期付款设计
├── 及时催款
└── 法律手段保留
```

## 八、总结

### 8.1 政企销售核心

```
三个前提：
├── 合规是底线
├── 预算是基础
├── 关系是润滑剂

三个关键阶段：
├── 预算前：进预算、引导需求
├── 招标前：技术交流、影响参数
├── 招标中：高质量投标、合理报价

三个成功要素：
├── 产品过硬
├── 方案专业
├── 服务到位
```

### 8.2 政企销售自检

```
每个项目问自己：
□ 预算进了吗？金额够吗？
□ 关键决策链清楚吗？
□ 有支持我们的Coach吗？
□ 竞对是谁？优劣势？
□ 招标参数对我们有利吗？
□ 技术方案够专业吗？
□ 报价策略是什么？
□ 有什么风险需要防范？
```
