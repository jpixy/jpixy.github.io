# 销售预测与漏斗管理

## 一、销售漏斗基础

### 1.1 什么是销售漏斗

**销售漏斗模型**：

```
     ┌─────────────────────────────┐
     │        线索 (Leads)         │ ← 市场活动、网站、渠道
     └─────────────┬───────────────┘
                   ▼  转化率 30%
       ┌───────────────────────┐
       │    商机 (Opportunity)  │ ← 有明确需求和预算
       └───────────┬───────────┘
                   ▼  转化率 50%
         ┌─────────────────────┐
         │    提案 (Proposal)   │ ← 提交方案和报价
         └─────────┬───────────┘
                   ▼  转化率 60%
           ┌───────────────────┐
           │   谈判 (Negotiate) │ ← 商务谈判
           └───────┬───────────┘
                   ▼  转化率 80%
             ┌─────────────────┐
             │   成交 (Won)     │ ← 签约收款
             └─────────────────┘
```

### 1.2 漏斗阶段定义

**典型B2B销售阶段**：

| 阶段 | 定义 | 转化率 | 周期 |
|------|------|--------|------|
| 线索 | 有联系方式，待验证需求 | 30% | 1-2周 |
| 商机 | 确认需求、预算、时间 | 40% | 2-4周 |
| 需求确认 | 完成需求调研 | 50% | 2-4周 |
| 方案演示 | 完成产品演示/POC | 60% | 2-4周 |
| 商务报价 | 提交正式报价 | 70% | 1-2周 |
| 商务谈判 | 价格和条款谈判 | 80% | 1-4周 |
| 合同签订 | 合同流转中 | 90% | 1-2周 |
| 成交 | 签约完成 | 100% | - |

### 1.3 阶段推进标准

**阶段推进检查清单**：

```
线索 → 商机：
□ 确认有业务需求
□ 确认有预算/预算计划
□ 确认有决策时间
□ 确认有决策权人
□ 确认我们能满足需求

商机 → 需求确认：
□ 完成需求调研
□ 了解详细业务场景
□ 识别关键决策人
□ 了解竞争对手

需求确认 → 方案演示：
□ 完成解决方案设计
□ 安排产品演示/POC
□ 获得技术认可

方案演示 → 商务报价：
□ 客户认可方案
□ 明确采购范围
□ 提交正式报价

商务报价 → 商务谈判：
□ 客户对价格有反馈
□ 进入正式谈判
□ 明确谈判关键点

商务谈判 → 合同签订：
□ 商务条款达成一致
□ 合同文本确认
□ 进入签约流程

合同签订 → 成交：
□ 合同签署完成
□ 首付款到账
```

## 二、漏斗健康度分析

### 2.1 漏斗数量分析

**漏斗覆盖率**：

```
漏斗覆盖率 = 漏斗金额 / 销售目标

推荐覆盖倍数：
├── 漏斗总量：3-4倍目标
├── 加权漏斗：1.5-2倍目标
└── 季度末：1倍目标

示例：
├── 季度目标：1000万
├── 漏斗金额：3500万
├── 覆盖率：3.5倍 ✓
```

**加权漏斗**：

```
加权漏斗 = Σ(商机金额 × 阶段概率)

示例：
商机A：100万 × 20%（商机阶段）= 20万
商机B：200万 × 50%（方案阶段）= 100万
商机C：150万 × 80%（谈判阶段）= 120万
────────────────────────────────
加权漏斗 = 240万
```

### 2.2 漏斗质量分析

**质量指标**：

```
1. 阶段分布
   ├── 健康：各阶段均有分布，呈漏斗形
   └── 不健康：头重脚轻（只有早期）或脚重头轻

2. 停留时间
   ├── 健康：各阶段在正常周期内
   └── 不健康：超期商机过多（僵尸商机）

3. 来源分布
   ├── 健康：多渠道来源，不依赖单一
   └── 不健康：过度依赖某个来源

4. 客户分布
   ├── 健康：大中小客户均有
   └── 不健康：过度依赖大单

5. 时间分布
   ├── 健康：均匀分布在各周/月
   └── 不健康：季末堆积（压单）
```

## 三、销售预测

### 3.1 预测方法

**常用预测方法**：

```
1. 阶段加权法（Pipeline Weighted）
   ├── 按阶段概率加权
   ├── 简单易行
   └── 适合：漏斗管理成熟

2. 销售判断法（Rep Forecast）
   ├── 销售自己预测
   ├── 考虑具体情况
   └── 适合：有经验销售

3. 承诺法（Commit）
   ├── 销售承诺能完成的
   ├── 区分Commit/Upside/Pipeline
   └── 适合：考核压力大

4. 历史趋势法（Historical）
   ├── 基于历史转化率
   ├── 考虑季节性
   └── 适合：成熟业务

5. AI预测（Predictive）
   ├── 机器学习模型
   ├── 多因素综合
   └── 适合：数据丰富
```

### 3.2 预测分类

**Commit分类管理**：

```
Commit（承诺）：
├── 有90%+把握本期成交
├── 关键步骤都已完成
├── 只差签字/付款
└── 算入业绩预测

Best Case（最佳情况）：
├── 有70-90%把握
├── 可能本期成交
├── 还有不确定因素
└── 作为Upside

Pipeline（管道）：
├── 早期商机
├── 本期可能性<70%
├── 需要继续推进
└── 下期目标
```

### 3.3 预测准确性

**预测偏差分析**：

```
预测准确率 = 1 - |预测值 - 实际值| / 实际值

目标：准确率 > 90%

偏差原因分析：
├── 预测偏高（Over Forecast）
│   ├── 阶段判断过于乐观
│   ├── 成交时间延后
│   └── 商机丢失
│
└── 预测偏低（Under Forecast）
    ├── 突然加速的项目
    ├── 新增大单
    └── 阶段判断保守
```

## 四、Pipeline管理

### 4.1 Pipeline Review

**每周Pipeline Review**：

```
Review频率：
├── 销售个人：每天更新
├── 团队Review：每周一次
├── 管理层Review：每周/双周

Review内容：
├── 本周预计成交
├── 关键商机进展
├── 阶段推进情况
├── 异常商机处理
├── 新增商机情况
└── 下周工作计划

Review问题：
├── 这个商机现在什么状态？
├── 为什么还在这个阶段？
├── 下一步行动是什么？
├── 什么时候能推进？
├── 有什么障碍需要帮助？
└── 这个预测靠谱吗？
```

### 4.2 商机推进

**推进技巧**：

```
卡在早期阶段：
├── 需求不明确→深入调研
├── 找不到决策人→向上突破
├── 客户不积极→创造紧迫感
└── 竞争激烈→差异化价值

卡在方案阶段：
├── 技术担忧→POC证明
├── 方案不匹配→调整方案
├── 无法说服老板→帮助内部销售
└── 比较竞对→突出差异

卡在商务阶段：
├── 价格分歧→价值谈判/调整范围
├── 条款分歧→灵活协商
├── 采购流程→配合流程
└── 等待预算→跟进时间
```

### 4.3 僵尸商机处理

**识别和处理僵尸商机**：

```
僵尸商机特征：
├── 超过正常周期2倍
├── 长期无实质进展
├── 客户不再响应
├── 决策人变更
└── 需求已经消失

处理方式：
├── 重新评估：是否还有机会？
├── 激活尝试：最后一次推动
├── 降级/删除：清理漏斗
└── 转为培育：长期跟进

清理价值：
├── 保持漏斗真实性
├── 提高预测准确性
├── 释放销售精力
└── 聚焦高质量商机
```

## 五、CRM最佳实践

### 5.1 CRM数据管理

**数据录入要求**：

```
必填信息：
├── 客户基本信息
├── 联系人和角色
├── 商机金额
├── 预计成交时间
├── 当前阶段
├── 竞争对手
├── 下一步行动
└── 更新日期

更新频率：
├── 商机状态：实时更新
├── 阶段变更：及时更新
├── 金额变化：及时更新
├── 跟进记录：每次接触后
└── 预测调整：每周Review
```

### 5.2 CRM使用规范

**商机管理规范**：

```
创建商机：
├── 满足商机标准才创建
├── 信息尽量完整
├── 阶段准确判断
└── 预计时间合理

更新商机：
├── 每次接触后更新
├── 阶段推进及时调整
├── 预测每周确认
└── 丢单要记录原因

关闭商机：
├── 赢单：记录成交信息
├── 丢单：记录丢单原因
├── 作废：说明原因
└── 延期：调整预计时间
```

## 六、销售预测会议

### 6.1 Forecast会议

**周度Forecast会议**：

```
参会人：销售团队、销售经理、销售VP
时间：每周固定时间（如周一上午）
时长：1-2小时

议程：
1. 上周回顾（10分钟）
   ├── 预测vs实际
   ├── 赢单/丢单分析
   └── 关键事件

2. 本周预测（30分钟）
   ├── 本周预计成交
   ├── 关键商机状态
   └── 风险和问题

3. 月度/季度预测（20分钟）
   ├── 整体预测vs目标
   ├── 差距分析
   └── 弥补措施

4. 关键商机Review（30分钟）
   ├── Top商机逐个Review
   ├── 问题诊断
   └── 行动计划

5. 下一步行动（10分钟）
   ├── 本周重点
   ├── 需要支持
   └── 责任分配
```

### 6.2 QBR（季度业务回顾）

**销售QBR**：

```
QBR内容：

1. 业绩回顾
   ├── 目标完成情况
   ├── 增长对比
   └── 关键指标

2. 漏斗分析
   ├── 漏斗健康度
   ├── 转化率分析
   └── 质量评估

3. 赢单/丢单分析
   ├── 赢单成功因素
   ├── 丢单原因分析
   └── 改进措施

4. 下季度计划
   ├── 目标设定
   ├── 策略调整
   └── 资源需求

5. 团队发展
   ├── 人员表现
   ├── 培训需求
   └── 激励措施
```

## 七、总结

### 7.1 漏斗管理核心

```
三个关键：
├── 数量够：足够的漏斗覆盖
├── 质量高：真实、活跃的商机
└── 流动快：持续推进、不卡壳

三个习惯：
├── 每天更新CRM
├── 每周Review漏斗
└── 每月分析改进

三个纪律：
├── 阶段标准统一
├── 预测真实准确
└── 僵尸及时清理
```

### 7.2 销售自检

```
每周问自己：
□ 我的漏斗覆盖率够吗？
□ 各阶段分布健康吗？
□ 有多少商机超期了？
□ 本周能成交几个？
□ 每个商机下一步是什么？
□ 有什么商机需要帮助？
□ 预测准确吗？
□ 新增商机够吗？
```
