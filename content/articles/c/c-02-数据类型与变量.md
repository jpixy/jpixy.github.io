## 基本数据类型

### 整数类型

```
┌──────────────────────────────────────────────────────────┐
│                    整数类型大小 (典型值)                   │
├──────────────┬────────┬─────────────────────────────────┤
│    类型      │  字节  │          取值范围                │
├──────────────┼────────┼─────────────────────────────────┤
│ char         │   1    │ -128 ~ 127                      │
│ short        │   2    │ -32,768 ~ 32,767                │
│ int          │   4    │ -2^31 ~ 2^31-1                  │
│ long         │  4/8   │ 平台相关                        │
│ long long    │   8    │ -2^63 ~ 2^63-1                  │
└──────────────┴────────┴─────────────────────────────────┘
```

**注意**: 具体大小与平台相关，使用 `sizeof` 确认。

### 无符号类型

```c
unsigned char      // 0 ~ 255
unsigned short     // 0 ~ 65,535
unsigned int       // 0 ~ 4,294,967,295
unsigned long long // 0 ~ 18,446,744,073,709,551,615
```

### 浮点类型

| 类型 | 字节 | 精度 | 范围 |
|------|------|------|------|
| float | 4 | ~7位有效数字 | ±3.4×10^38 |
| double | 8 | ~15位有效数字 | ±1.7×10^308 |
| long double | 8-16 | 平台相关 | 平台相关 |

```c
float f = 3.14f;      // 后缀 f
double d = 3.14159;   // 默认 double
long double ld = 3.14159265358979L;  // 后缀 L
```

### 固定宽度类型 (C99)

```c
#include <stdint.h>

int8_t    i8;   // 精确 8 位有符号
uint8_t   u8;   // 精确 8 位无符号
int16_t   i16;  // 精确 16 位有符号
uint16_t  u16;  // 精确 16 位无符号
int32_t   i32;  // 精确 32 位有符号
uint32_t  u32;  // 精确 32 位无符号
int64_t   i64;  // 精确 64 位有符号
uint64_t  u64;  // 精确 64 位无符号

// 指针大小的整数
intptr_t  ip;   // 可存储指针的有符号整数
uintptr_t up;   // 可存储指针的无符号整数
size_t    sz;   // 无符号，用于表示大小
```

**面试重点**: `size_t` 是无符号类型，与负数比较时注意隐式转换！

## 变量

### 变量声明与初始化

```c
// 声明
int a;              // 未初始化 (值不确定)
int b = 10;         // 声明并初始化
int c = 10, d = 20; // 多变量

// C99: 可在任意位置声明
for (int i = 0; i < n; i++) { ... }
```

### 变量作用域

```c
int global = 1;     // 全局变量 (整个程序)

void func(void) {
    int local = 2;  // 局部变量 (函数内)
    {
        int block = 3;  // 块级变量 (块内)
    }
    // block 不可访问
}
```

### 存储类别

```c
auto int a;      // 自动变量 (默认，可省略)
static int b;    // 静态变量 (生命周期延长到程序结束)
extern int c;    // 外部变量 (声明其他文件的变量)
register int d;  // 建议放寄存器 (编译器可忽略)
```

**static 的两种用法**:
```c
// 1. 局部静态: 值在函数调用间保持
void counter(void) {
    static int count = 0;
    count++;
    printf("%d\n", count);  // 每次调用递增
}

// 2. 文件级 static: 限制作用域为当前文件
static int file_private = 42;  // 其他文件不可见
```

## 类型转换

### 隐式转换

```c
int i = 10;
double d = i;      // int → double (安全)
int j = d;         // double → int (截断小数)

// 整数提升
char c = 'A';
int x = c + 1;     // char → int

// 算术转换 (向更大类型转换)
int a = 5;
double b = 2.0;
double c = a / b;  // a 转为 double
```

### 显式转换 (强制转换)

```c
double pi = 3.14159;
int n = (int)pi;         // 截断为 3

// 指针转换
void *vp = malloc(100);
int *ip = (int *)vp;

// 整数与指针 (需谨慎)
uintptr_t addr = (uintptr_t)ptr;
```

### 常见陷阱

```c
// 陷阱1: 无符号与有符号比较
unsigned int u = 1;
int s = -1;
if (s < u) { ... }  // 错误! s 被转为无符号，变成很大的数

// 陷阱2: 整数除法截断
int a = 5 / 2;      // 结果是 2，不是 2.5
double d = 5 / 2;   // 仍是 2.0
double e = 5.0 / 2; // 正确: 2.5

// 陷阱3: 溢出
int max = INT_MAX;
int overflow = max + 1;  // 未定义行为!
```

## sizeof 运算符

### 基本用法

```c
#include <stdio.h>

int main(void) {
    printf("char: %zu\n", sizeof(char));       // 1
    printf("short: %zu\n", sizeof(short));     // 2
    printf("int: %zu\n", sizeof(int));         // 4
    printf("long: %zu\n", sizeof(long));       // 4 或 8
    printf("long long: %zu\n", sizeof(long long)); // 8
    printf("float: %zu\n", sizeof(float));     // 4
    printf("double: %zu\n", sizeof(double));   // 8
    printf("void*: %zu\n", sizeof(void*));     // 4 或 8
    return 0;
}
```

### sizeof 与数组

```c
int arr[10];
printf("%zu\n", sizeof(arr));       // 40 (10 * 4)
printf("%zu\n", sizeof(arr[0]));    // 4
printf("%zu\n", sizeof(arr) / sizeof(arr[0])); // 10 (元素个数)

// 陷阱: 函数参数中的数组
void func(int arr[]) {
    // arr 已退化为指针
    printf("%zu\n", sizeof(arr));   // 8 (指针大小)
}
```

### 编译时计算

```c
// sizeof 在编译时求值
int arr[sizeof(int) * 10];  // 合法

// 但 VLA (变长数组) 是运行时
int n = 10;
int vla[n];
printf("%zu\n", sizeof(vla));  // 运行时求值
```

## 常量

### 字面量

```c
// 整数
42        // int
42L       // long
42LL      // long long
42U       // unsigned int
0x2A      // 十六进制
052       // 八进制
0b101010  // 二进制 (C23)

// 浮点
3.14      // double
3.14f     // float
3.14L     // long double

// 字符
'A'       // char (值为65)
'\n'      // 转义字符
'\x41'    // 十六进制
'\101'    // 八进制
```

### const 关键字

```c
const int MAX = 100;    // 常量变量
MAX = 200;              // 错误: 不能修改

// const 与指针
const int *p1;          // 指向常量的指针 (值不可变)
int *const p2;          // 常量指针 (地址不可变)
const int *const p3;    // 两者都不可变
```

### 枚举常量

```c
enum Color { RED, GREEN, BLUE };        // 0, 1, 2
enum Status { OK = 0, ERR = -1 };       // 指定值
enum { BUFFER_SIZE = 1024 };            // 匿名枚举作常量
```

## 面试题

### 题目1: sizeof 陷阱

```c
void func(int arr[10]) {
    printf("%zu\n", sizeof(arr));  // 输出什么?
}
```

**答案**: 输出 8 (64位系统)。数组参数退化为指针。

### 题目2: 类型转换

```c
unsigned int a = 1;
int b = -1;
printf("%d\n", a > b);  // 输出什么?
```

**答案**: 输出 0 (false)。b 被转为无符号，变成 UINT_MAX。

### 题目3: 整数溢出

```c
int x = INT_MAX;
if (x + 1 > x) {
    printf("Overflow detected\n");
}
```

**答案**: 未定义行为。有符号整数溢出是UB，编译器可能优化掉这个检查。
