## 内存区域

### 程序内存布局

```
┌─────────────────────────────┐ 高地址
│         Stack               │ ← 局部变量、函数参数
│         ↓                   │   向下增长
├─────────────────────────────┤
│                             │
│         (空闲)               │
│                             │
├─────────────────────────────┤
│         ↑                   │
│         Heap                │ ← malloc 分配
│                             │   向上增长
├─────────────────────────────┤
│         BSS                 │ ← 未初始化全局变量
├─────────────────────────────┤
│         Data                │ ← 已初始化全局变量
├─────────────────────────────┤
│         Text (Code)         │ ← 程序代码
└─────────────────────────────┘ 低地址
```

### 各区域特点

| 区域 | 分配方式 | 生命周期 | 大小 |
|------|----------|----------|------|
| Stack | 自动 | 函数调用期间 | 有限 (通常 1-8MB) |
| Heap | 手动 (malloc/free) | 手动控制 | 可用内存大小 |
| BSS | 编译时 | 程序运行期间 | 固定 |
| Data | 编译时 | 程序运行期间 | 固定 |
| Text | 编译时 | 程序运行期间 | 固定 |

## malloc 系列函数

### malloc

```c
#include <stdlib.h>

// 分配 n 字节未初始化内存
void *malloc(size_t n);

// 使用
int *arr = (int *)malloc(10 * sizeof(int));
if (arr == NULL) {
    // 分配失败处理
    perror("malloc failed");
    exit(1);
}

// 使用内存...

free(arr);
arr = NULL;  // 防止悬空指针
```

### calloc

```c
// 分配 n 个元素，每个 size 字节，并清零
void *calloc(size_t n, size_t size);

// 使用
int *arr = (int *)calloc(10, sizeof(int));
// 所有元素被初始化为 0
```

### realloc

```c
// 调整已分配内存的大小
void *realloc(void *ptr, size_t new_size);

// 使用
int *arr = malloc(10 * sizeof(int));
// ... 需要更多空间
int *new_arr = realloc(arr, 20 * sizeof(int));
if (new_arr == NULL) {
    // realloc 失败，原 arr 仍然有效
    free(arr);
    return;
}
arr = new_arr;  // 成功，更新指针
```

**realloc 行为**:
- `new_size == 0`: 相当于 free (返回 NULL)
- `ptr == NULL`: 相当于 malloc
- 可能返回原地址 (就地扩展)
- 可能返回新地址 (移动数据)

### aligned_alloc (C11)

```c
// 分配对齐内存
void *aligned_alloc(size_t alignment, size_t size);

// 使用 (size 必须是 alignment 的倍数)
void *p = aligned_alloc(64, 64 * 10);  // 64字节对齐

// POSIX 版本
int posix_memalign(void **memptr, size_t alignment, size_t size);
```

## 常见内存问题

### 内存泄漏

```c
void leak_example(void) {
    int *p = malloc(100);
    // 忘记 free(p);
    return;  // 内存泄漏!
}

// 常见场景
void leak_scenario(void) {
    char *s = malloc(100);
    
    // 提前返回忘记释放
    if (error_condition) {
        return;  // 泄漏!
    }
    
    // 异常路径忘记释放
    s = malloc(200);  // 原来的 100 字节泄漏!
    
    free(s);
}
```

### 双重释放

```c
int *p = malloc(100);
free(p);
free(p);  // 未定义行为! 可能崩溃或数据损坏

// 预防: 释放后置 NULL
free(p);
p = NULL;
free(p);  // free(NULL) 是安全的
```

### 悬空指针

```c
int *p = malloc(sizeof(int));
*p = 42;
free(p);
// p 仍然指向已释放的内存 (悬空指针)
*p = 100;  // 未定义行为!

// 预防
free(p);
p = NULL;
```

### 缓冲区溢出

```c
int *arr = malloc(10 * sizeof(int));
arr[10] = 100;  // 越界写入! 未定义行为

// 可能导致:
// 1. 覆盖 malloc 的元数据 → free 时崩溃
// 2. 覆盖其他数据
// 3. 安全漏洞
```

### 使用未初始化内存

```c
int *p = malloc(sizeof(int));
printf("%d\n", *p);  // 未定义! 值是垃圾

// 使用 calloc 或手动初始化
int *p = calloc(1, sizeof(int));  // 初始化为 0
```

## 内存管理最佳实践

### 模式1: 检查返回值

```c
void *safe_malloc(size_t size) {
    void *p = malloc(size);
    if (p == NULL) {
        fprintf(stderr, "Out of memory\n");
        exit(EXIT_FAILURE);
    }
    return p;
}
```

### 模式2: 谁分配谁释放

```c
// 好: 调用者分配，调用者释放
void process(char *buffer, size_t size) {
    // 使用 buffer，不负责分配/释放
}

// 坏: 函数内分配，需要调用者释放 (容易忘记)
char *bad_function(void) {
    return malloc(100);  // 调用者必须记得 free
}

// 如果必须返回分配的内存，在文档中明确说明
/**
 * @return 新分配的字符串，调用者负责 free
 */
char *strdup_custom(const char *s);
```

### 模式3: RAII 风格 (在函数级别)

```c
int process_file(const char *filename) {
    int result = -1;
    FILE *f = NULL;
    char *buffer = NULL;
    
    f = fopen(filename, "r");
    if (!f) goto cleanup;
    
    buffer = malloc(1024);
    if (!buffer) goto cleanup;
    
    // 正常处理...
    result = 0;
    
cleanup:
    free(buffer);  // free(NULL) 是安全的
    if (f) fclose(f);
    return result;
}
```

### 模式4: 结构体封装

```c
typedef struct {
    int *data;
    size_t size;
    size_t capacity;
} Vector;

Vector *vector_create(size_t initial_capacity) {
    Vector *v = malloc(sizeof(Vector));
    if (!v) return NULL;
    
    v->data = malloc(initial_capacity * sizeof(int));
    if (!v->data) {
        free(v);
        return NULL;
    }
    
    v->size = 0;
    v->capacity = initial_capacity;
    return v;
}

void vector_destroy(Vector *v) {
    if (v) {
        free(v->data);
        free(v);
    }
}
```

## 内存调试工具

### Valgrind

```bash
# 编译时加 -g
gcc -g -o program program.c

# 运行 Valgrind
valgrind --leak-check=full ./program
```

**输出示例**:
```
==12345== HEAP SUMMARY:
==12345==     in use at exit: 100 bytes in 1 blocks
==12345==   total heap usage: 10 allocs, 9 frees, 1,000 bytes allocated
==12345== 
==12345== 100 bytes in 1 blocks are definitely lost
==12345==    at 0x4C2AB80: malloc (vg_replace_malloc.c:339)
==12345==    by 0x400544: leak_function (program.c:10)
==12345==    by 0x400560: main (program.c:15)
```

### AddressSanitizer (ASan)

```bash
# 编译时加标志
gcc -fsanitize=address -g -o program program.c

# 运行
./program
```

**检测能力**:
- 堆缓冲区溢出
- 栈缓冲区溢出
- 使用已释放内存
- 内存泄漏

### Electric Fence

```bash
# 安装
sudo apt install electric-fence

# 链接
gcc -o program program.c -lefence

# 运行 - 缓冲区溢出会立即崩溃
./program
```

## 高级话题

### 内存池

```c
// 简单的固定大小内存池
#define BLOCK_SIZE 64
#define POOL_SIZE 1024

typedef struct Block {
    struct Block *next;
} Block;

typedef struct {
    Block *free_list;
    char memory[POOL_SIZE * BLOCK_SIZE];
} MemoryPool;

void pool_init(MemoryPool *pool) {
    pool->free_list = NULL;
    for (int i = 0; i < POOL_SIZE; i++) {
        Block *b = (Block *)(pool->memory + i * BLOCK_SIZE);
        b->next = pool->free_list;
        pool->free_list = b;
    }
}

void *pool_alloc(MemoryPool *pool) {
    if (!pool->free_list) return NULL;
    Block *b = pool->free_list;
    pool->free_list = b->next;
    return b;
}

void pool_free(MemoryPool *pool, void *ptr) {
    Block *b = (Block *)ptr;
    b->next = pool->free_list;
    pool->free_list = b;
}
```

### mmap

```c
#include <sys/mman.h>

// 分配大块内存
void *p = mmap(NULL, size, 
               PROT_READ | PROT_WRITE,
               MAP_PRIVATE | MAP_ANONYMOUS,
               -1, 0);
if (p == MAP_FAILED) {
    perror("mmap");
}

// 释放
munmap(p, size);
```

## 面试题

### 题目1: 实现 realloc

```c
void *my_realloc(void *ptr, size_t old_size, size_t new_size) {
    if (ptr == NULL) {
        return malloc(new_size);
    }
    if (new_size == 0) {
        free(ptr);
        return NULL;
    }
    
    void *new_ptr = malloc(new_size);
    if (new_ptr == NULL) {
        return NULL;
    }
    
    // 拷贝数据
    size_t copy_size = old_size < new_size ? old_size : new_size;
    memcpy(new_ptr, ptr, copy_size);
    
    free(ptr);
    return new_ptr;
}
```

### 题目2: 检测内存泄漏

```c
// 包装 malloc/free 进行跟踪
#ifdef DEBUG
static int alloc_count = 0;

void *debug_malloc(size_t size, const char *file, int line) {
    void *p = malloc(size);
    if (p) {
        alloc_count++;
        printf("ALLOC: %p (%zu bytes) at %s:%d\n", p, size, file, line);
    }
    return p;
}

void debug_free(void *p, const char *file, int line) {
    if (p) {
        alloc_count--;
        printf("FREE: %p at %s:%d\n", p, file, line);
    }
    free(p);
}

#define malloc(size) debug_malloc(size, __FILE__, __LINE__)
#define free(p) debug_free(p, __FILE__, __LINE__)

void check_leaks(void) {
    printf("Outstanding allocations: %d\n", alloc_count);
}
#endif
```

### 题目3: 为什么 free 不需要大小参数?

**答案**: malloc 在返回的内存块前面存储了元数据 (包括大小)。free 通过指针找到元数据，从而知道要释放多少内存。

```
┌──────────────────┬──────────────────────────┐
│     Metadata     │       User Data          │
│  (size, etc.)    │                          │
└──────────────────┴──────────────────────────┘
                   ↑
                   malloc 返回的指针
```
