## 指针本质

### 什么是指针

**指针是存储内存地址的变量**：

```
变量a: 值=10, 地址=0x1000
指针p: 值=0x1000（存的是a的地址）
```

**关键理解**：
- 指针本身也是变量，有自己的地址
- 指针的值是另一个变量的地址
- 通过指针可以间接访问目标变量

### 指针大小

**指针大小取决于系统位数**：
- 32位系统：4字节
- 64位系统：8字节

无论指向什么类型，指针大小相同（存的都是地址）。

### 指针类型的意义

**指针类型决定**：
- 解引用时读取多少字节
- 指针运算的步长

```c
int *p;    // 解引用读4字节，p+1移动4字节
char *q;   // 解引用读1字节，q+1移动1字节
```

## 指针运算

### 取地址与解引用

```c
int a = 10;
int *p = &a;   // &取地址
int b = *p;    // *解引用，b=10
*p = 20;       // 通过指针修改a的值
```

### 指针算术

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

p + 1;    // 指向arr[1]，移动sizeof(int)字节
p++;      // p指向下一个元素
p - 1;    // 指向前一个元素

// 两指针相减：得到元素个数
int *q = &arr[4];
ptrdiff_t diff = q - p;  // 结果是元素个数，不是字节数
```

### 指针比较

```c
if (p < q) {
    // p指向的地址比q小
}

if (p == NULL) {
    // 空指针检查
}
```

## 指针与数组

### 数组名与指针

**数组名是首元素地址的常量**：

```c
int arr[5] = {1, 2, 3, 4, 5};

arr == &arr[0];      // true，都是首元素地址
*(arr + 2) == arr[2]; // true

// 但数组名不是指针变量
arr++;  // 错误！数组名不能修改
```

### 数组指针与指针数组

```c
// 指针数组：数组的元素是指针
int *arr[5];     // 5个int指针的数组

// 数组指针：指向数组的指针
int (*p)[5];     // 指向含5个int的数组的指针

int matrix[3][5];
int (*row)[5] = matrix;  // row指向第一行
row++;                    // 指向下一行
```

### 字符串与指针

```c
// 字符数组：可修改
char str1[] = "hello";
str1[0] = 'H';  // OK

// 字符串字面量：只读
char *str2 = "hello";
str2[0] = 'H';  // 未定义行为！
```

## 多级指针

### 二级指针

```c
int a = 10;
int *p = &a;
int **pp = &p;

**pp = 20;  // 修改a的值
*pp = NULL; // 修改p的值
```

**应用场景**：
- 函数内修改指针本身
- 动态二维数组

### 函数修改外部指针

```c
// 错误：无法修改外部指针
void alloc_wrong(int *p) {
    p = malloc(sizeof(int));  // 只修改了本地副本
}

// 正确：使用二级指针
void alloc_correct(int **pp) {
    *pp = malloc(sizeof(int));  // 修改外部指针
}

int *ptr = NULL;
alloc_correct(&ptr);  // ptr现在指向分配的内存
```

## 函数指针

### 基本语法

```c
// 函数指针声明
int (*fp)(int, int);

// 函数定义
int add(int a, int b) {
    return a + b;
}

// 赋值和调用
fp = add;        // 或 fp = &add
int result = fp(3, 4);  // 或 (*fp)(3, 4)
```

### 回调函数

```c
void foreach(int *arr, int n, void (*callback)(int)) {
    for (int i = 0; i < n; i++) {
        callback(arr[i]);
    }
}

void print(int x) {
    printf("%d ", x);
}

int arr[] = {1, 2, 3, 4, 5};
foreach(arr, 5, print);  // 输出: 1 2 3 4 5
```

### 函数指针数组

```c
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

int (*ops[])(int, int) = {add, sub, mul};
int result = ops[0](3, 4);  // 调用add
```

## 动态内存管理

### 分配与释放

```c
// malloc：分配未初始化的内存
int *p = (int *)malloc(n * sizeof(int));

// calloc：分配并初始化为0
int *q = (int *)calloc(n, sizeof(int));

// realloc：调整大小
p = realloc(p, new_size);

// free：释放内存
free(p);
p = NULL;  // 避免悬空指针
```

### 常见错误

**内存泄漏**：
```c
void leak() {
    int *p = malloc(100);
    // 忘记free
}  // p离开作用域，内存泄漏
```

**悬空指针**：
```c
int *p = malloc(sizeof(int));
free(p);
*p = 10;  // 错误！访问已释放内存
```

**重复释放**：
```c
free(p);
free(p);  // 错误！重复释放
```

**越界访问**：
```c
int *p = malloc(5 * sizeof(int));
p[5] = 10;  // 错误！越界
```

### 内存检测工具

**Valgrind**：
```bash
valgrind --leak-check=full ./program
```

**AddressSanitizer**：
```bash
gcc -fsanitize=address -g program.c -o program
```

## void指针

### 通用指针

```c
void *p;

// 可以存储任何类型的地址
int a = 10;
p = &a;

// 使用前必须转换
int *ip = (int *)p;
int b = *ip;
```

### 应用场景

**通用函数**：
```c
void swap(void *a, void *b, size_t size) {
    char temp[size];
    memcpy(temp, a, size);
    memcpy(a, b, size);
    memcpy(b, temp, size);
}

int x = 1, y = 2;
swap(&x, &y, sizeof(int));
```

**malloc返回值**：
```c
void *malloc(size_t size);
// 返回void*，需要转换为目标类型
```

## const与指针

### 四种组合

```c
// 1. 指向常量的指针（常量指针）
const int *p1;      // 不能通过p1修改值，但p1可以指向别处
int const *p1;      // 同上

// 2. 常量指针（指针常量）
int *const p2;      // p2不能指向别处，但可以修改值

// 3. 指向常量的常量指针
const int *const p3; // 都不能改

// 4. 普通指针
int *p4;             // 都能改
```

### 记忆技巧

```
const在*左边：指向的内容不可变
const在*右边：指针本身不可变
```

## restrict关键字

### 含义

**告诉编译器：该指针是访问数据的唯一方式**

```c
void add(int *restrict a, int *restrict b, int *restrict c, int n) {
    for (int i = 0; i < n; i++) {
        c[i] = a[i] + b[i];
    }
}
```

### 优化效果

编译器可以假设a、b、c不重叠，进行更激进的优化（如向量化）。

**注意**：如果违反约定（指针实际重叠），行为未定义。
