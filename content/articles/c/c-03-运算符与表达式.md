## 运算符分类

### 算术运算符

```c
int a = 10, b = 3;

a + b   // 13  加法
a - b   // 7   减法
a * b   // 30  乘法
a / b   // 3   整数除法 (截断)
a % b   // 1   取模 (余数)

// 自增自减
++a;    // 前置: 先加后用
a++;    // 后置: 先用后加
--a;
a--;
```

**面试重点**: `i++ + ++i` 是未定义行为！

### 关系运算符

```c
a == b  // 等于
a != b  // 不等于
a > b   // 大于
a < b   // 小于
a >= b  // 大于等于
a <= b  // 小于等于
```

**返回值**: 0 (假) 或 1 (真)

### 逻辑运算符

```c
!a      // 逻辑非
a && b  // 逻辑与 (短路)
a || b  // 逻辑或 (短路)
```

**短路求值**:
```c
// 如果 ptr 为 NULL，不会访问 ptr->data
if (ptr != NULL && ptr->data > 0) { ... }

// 如果 a 为真，不会调用 expensive_func()
if (a || expensive_func()) { ... }
```

## 位运算符

### 基本位运算

```c
unsigned int a = 0b1010;  // 10
unsigned int b = 0b1100;  // 12

a & b   // 0b1000 = 8   按位与
a | b   // 0b1110 = 14  按位或
a ^ b   // 0b0110 = 6   按位异或
~a      // 取反 (所有位翻转)

a << 2  // 0b101000 = 40  左移 (×4)
a >> 1  // 0b0101 = 5     右移 (÷2)
```

### 位运算技巧

```c
// 1. 判断奇偶
(n & 1) == 0  // 偶数
(n & 1) == 1  // 奇数

// 2. 设置第k位为1
n |= (1 << k);

// 3. 清除第k位
n &= ~(1 << k);

// 4. 切换第k位
n ^= (1 << k);

// 5. 检查第k位
(n >> k) & 1

// 6. 获取最低位的1
n & (-n)

// 7. 清除最低位的1
n & (n - 1)

// 8. 判断是否为2的幂
(n & (n - 1)) == 0 && n > 0

// 9. 交换两数 (不用临时变量)
a ^= b;
b ^= a;
a ^= b;

// 10. 取绝对值 (无分支)
int mask = n >> 31;
int abs_n = (n ^ mask) - mask;
```

### 位运算内存布局

```
int a = 0b00001010 (十进制 10)

位:    7   6   5   4   3   2   1   0
     +---+---+---+---+---+---+---+---+
     | 0 | 0 | 0 | 0 | 1 | 0 | 1 | 0 |
     +---+---+---+---+---+---+---+---+

a << 2 = 0b00101000 (十进制 40)
     +---+---+---+---+---+---+---+---+
     | 0 | 0 | 1 | 0 | 1 | 0 | 0 | 0 |
     +---+---+---+---+---+---+---+---+
```

## 赋值运算符

### 复合赋值

```c
a += b;   // a = a + b
a -= b;   // a = a - b
a *= b;   // a = a * b
a /= b;   // a = a / b
a %= b;   // a = a % b
a &= b;   // a = a & b
a |= b;   // a = a | b
a ^= b;   // a = a ^ b
a <<= n;  // a = a << n
a >>= n;  // a = a >> n
```

### 连续赋值

```c
int a, b, c;
a = b = c = 10;  // 从右向左: c=10, b=c, a=b
```

## 其他运算符

### 条件运算符

```c
// 三元运算符
int max = (a > b) ? a : b;

// 嵌套 (可读性差，慎用)
int sign = (n > 0) ? 1 : (n < 0) ? -1 : 0;
```

### 逗号运算符

```c
// 从左到右求值，返回最右值
int x = (a = 1, b = 2, a + b);  // x = 3

// 常用于 for 循环
for (int i = 0, j = n; i < j; i++, j--) { ... }
```

### sizeof 运算符

```c
sizeof(int)      // 类型大小
sizeof(arr)      // 数组大小 (总字节数)
sizeof(expr)     // 表达式类型大小 (不求值)
```

### 地址与解引用

```c
int a = 10;
int *p = &a;     // & 取地址
int b = *p;      // * 解引用
```

## 运算符优先级

### 完整优先级表 (从高到低)

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | () [] -> . | 左到右 |
| 2 | ! ~ ++ -- + - * & (type) sizeof | 右到左 |
| 3 | * / % | 左到右 |
| 4 | + - | 左到右 |
| 5 | << >> | 左到右 |
| 6 | < <= > >= | 左到右 |
| 7 | == != | 左到右 |
| 8 | & | 左到右 |
| 9 | ^ | 左到右 |
| 10 | \| | 左到右 |
| 11 | && | 左到右 |
| 12 | \|\| | 左到右 |
| 13 | ?: | 右到左 |
| 14 | = += -= 等 | 右到左 |
| 15 | , | 左到右 |

### 常见优先级陷阱

```c
// 陷阱1: 位运算优先级低于比较
if (a & 0x01 == 1)      // 错误! 等于 a & (0x01 == 1)
if ((a & 0x01) == 1)    // 正确

// 陷阱2: 移位与加法
a << 2 + 1              // 等于 a << 3，不是 (a << 2) + 1
(a << 2) + 1            // 明确意图

// 陷阱3: 条件运算符
a ? b : c ? d : e       // 等于 a ? b : (c ? d : e)

// 建议: 不确定时加括号
```

## 表达式求值

### 未定义行为

```c
// 1. 同一变量多次修改
int i = 0;
int j = i++ + ++i;   // 未定义行为!

// 2. 序列点问题
a[i] = i++;          // 未定义行为!

// 3. 函数参数求值顺序
printf("%d %d\n", i++, i++);  // 未定义行为!
```

### 序列点

序列点是程序执行中的点，在此之前的所有副作用都已完成。

**常见序列点**:
- `;` 语句结束
- `,` 逗号运算符
- `&&` `||` `?:` 的操作数之间
- 函数调用前 (参数求值完成后)

## 面试题

### 题目1: 位运算实现加法

```c
int add(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;  // 进位
        a = a ^ b;                  // 无进位加法
        b = carry;
    }
    return a;
}
```

### 题目2: 不用比较求最大值

```c
int max(int a, int b) {
    int diff = a - b;
    int sign = (diff >> 31) & 1;  // 0: a>=b, 1: a<b
    return a - sign * diff;
}
```

### 题目3: 统计二进制中1的个数

```c
// 方法1: 循环检查
int count1(unsigned int n) {
    int count = 0;
    while (n) {
        count += n & 1;
        n >>= 1;
    }
    return count;
}

// 方法2: Brian Kernighan 算法 (更快)
int count2(unsigned int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);  // 清除最低位的1
        count++;
    }
    return count;
}
```
