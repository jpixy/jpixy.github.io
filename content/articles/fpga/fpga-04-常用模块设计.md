## 计数器

### 基本计数器

最基础的时序逻辑模块。每个时钟周期计数值加1或减1。

**上升计数器**：从0计数到最大值，溢出后回到0。

**下降计数器**：从最大值计数到0。

**可逆计数器**：可以选择上升或下降。

### 模N计数器

计数到N-1后回到0。用于分频、产生周期信号。

分频系数为N，输出时钟频率为输入频率除以N。

### 格雷码计数器

相邻计数值只有1位变化。用于跨时钟域的指针。

格雷码转换：gray = binary ^ (binary >> 1)

### 计数器应用

**分频**：产生低频时钟。

**定时**：产生固定延迟或超时信号。

**地址生成**：顺序访问存储器。

**PWM生成**：比较计数值产生占空比可调的脉冲。

## FIFO

### 概念

先进先出队列。一端写入，另一端读取，数据按写入顺序输出。

用于缓冲数据、跨时钟域传输、速率匹配。

### 同步FIFO

读写使用同一时钟。实现相对简单。

**组成**：
- 存储器（Block RAM或分布式RAM）
- 写指针
- 读指针
- 空/满状态逻辑

**空判断**：读指针等于写指针

**满判断**：写指针比读指针多一圈

### 异步FIFO

读写使用不同时钟。需要处理跨时钟域问题。

**关键技术**：
- 格雷码指针：避免多位同时变化
- 两级同步：指针跨时钟域同步
- 保守判断：空满判断略有延迟但安全

写侧看到的读指针是延迟的，满判断保守（可能误判满）。

读侧看到的写指针是延迟的，空判断保守（可能误判空）。

### FIFO深度选择

需要根据读写速率差异和突发长度计算。

如果写入速率持续高于读取速率，任何深度的FIFO都会溢出。

FIFO用于应对突发，不能解决持续的速率不匹配。

## UART

### 协议概述

通用异步收发器。串行通信，无时钟线，通过波特率约定时序。

**帧格式**：起始位（低）+ 数据位（5-8位）+ 校验位（可选）+ 停止位（高）

**波特率**：常见9600、115200等。

### 发送模块

**功能**：接收并行数据，串行输出。

**实现**：
1. 空闲时输出高电平
2. 收到发送请求，输出起始位
3. 按波特率逐位输出数据
4. 输出停止位
5. 返回空闲

需要波特率发生器产生位时钟。

### 接收模块

**功能**：接收串行数据，输出并行数据。

**实现**：
1. 检测起始位下降沿
2. 等待半个位周期到达位中心
3. 每个位周期采样一次
4. 采集完所有数据位
5. 检查停止位

通常使用16倍过采样，检测起始位后计数到8找到位中心。

### 错误检测

**帧错误**：停止位不为高。

**校验错误**：奇偶校验不匹配。

**溢出错误**：新数据到达时旧数据未取走。

## SPI

### 协议概述

同步串行接口，4线：SCLK、MOSI、MISO、CS。

主设备产生时钟和片选，全双工通信。

### 时钟极性和相位

**CPOL**：空闲时时钟电平。0为低，1为高。

**CPHA**：数据采样边沿。0为第一边沿，1为第二边沿。

四种模式：Mode 0 (0,0)、Mode 1 (0,1)、Mode 2 (1,0)、Mode 3 (1,1)

### 主设备实现

1. 拉低CS片选
2. 产生SCLK时钟
3. 在合适边沿输出MOSI数据
4. 在合适边沿采样MISO数据
5. 传输完成后拉高CS

### 从设备实现

1. 监测CS拉低
2. 跟随SCLK时钟
3. 采样MOSI数据
4. 输出MISO数据
5. CS拉高后复位

## I2C

### 协议概述

两线制串行总线：SCL（时钟）和SDA（数据）。

支持多主多从，通过地址寻址设备。

### 信号特点

开漏输出，需要外部上拉。多设备通过线与实现仲裁。

**起始条件**：SCL高时，SDA下降沿。

**停止条件**：SCL高时，SDA上升沿。

### 传输格式

起始 → 7位地址 + 读写位 → ACK → 数据字节 → ACK → ... → 停止

每个字节后接收方拉低SDA表示应答。

### FPGA实现要点

开漏输出需要三态控制。输出0时驱动低电平，输出1时设为高阻。

SCL和SDA都可能被拉伸，主设备需要检测。

多主仲裁需要监测SDA是否与期望一致。

## 存储器接口

### Block RAM

FPGA片上存储资源。通常18Kb或36Kb一块。

**单口**：一个读写端口。

**简单双口**：一个写端口，一个读端口。

**真双口**：两个独立读写端口。

### 存储器初始化

可以通过初始化文件预设内容。

用于ROM、查找表等固定数据。

### DDR接口

外部DRAM通常使用DDR（双倍数据率）接口。

数据在时钟上升沿和下降沿都传输。

FPGA需要专用的PHY和控制器处理复杂的时序。

大多使用厂商提供的IP核。

### 存储器控制器

管理对存储器的访问请求。

**功能**：地址映射、刷新管理、请求仲裁、数据缓冲。

## IP核使用

### 概念

预先设计好的功能模块。可以是厂商提供或第三方购买。

**软核**：HDL代码，可跨平台，可定制。

**硬核**：利用FPGA专用硬件，性能最优。

### 常用IP

**时钟管理**：PLL/MMCM配置。

**存储器接口**：DDR控制器。

**高速接口**：PCIe、以太网MAC。

**处理器**：MicroBlaze、RISC-V软核。

**DSP**：FFT、FIR滤波器。

### 使用建议

优先使用厂商IP，经过充分验证。

了解IP的接口和时序要求。

注意资源占用和性能指标。

## 总结

| 模块 | 要点 |
|------|------|
| 计数器 | 分频、定时、地址生成 |
| FIFO | 缓冲、跨时钟域 |
| UART | 异步串行、波特率 |
| SPI | 同步串行、主从模式 |
| I2C | 两线、多设备、开漏 |
| 存储器 | Block RAM、DDR接口 |

这些模块是FPGA设计的基础组件。掌握它们的设计和使用是进行复杂系统设计的前提。
