# HFT优化系列-定点运算详解

定点运算是 HFT 系统实现高精度金融计算的核心技术。本文深入解析定点数的原理、实现与最佳实践。

---

## 一、为什么需要定点运算

### 1.1 浮点数的问题

| 问题 | 说明 |
|-----|------|
| 精度丢失 | 0.1 + 0.2 ≠ 0.3 |
| 累积误差 | 大量运算后误差放大 |
| 比较困难 | 无法精确判断相等 |
| 性能问题 | 某些场景比整数慢 |
| 不确定性 | 舍入模式影响结果 |

**金融场景示例**：

| 操作 | 浮点结果 | 期望结果 |
|-----|---------|---------|
| 0.1 + 0.2 | 0.30000000000000004 | 0.3 |
| 1.0 - 0.9 | 0.09999999999999998 | 0.1 |
| 0.1 × 3 | 0.30000000000000004 | 0.3 |

### 1.2 定点数的优势

| 优势 | 说明 |
|-----|------|
| 精确 | 无舍入误差 |
| 可预测 | 结果确定 |
| 高效 | 整数运算快 |
| 可比较 | 精确相等判断 |
| 可复现 | 跨平台一致 |

### 1.3 适用场景

| 场景 | 说明 |
|-----|------|
| 价格 | 交易价格表示 |
| 数量 | 订单数量 |
| 金额 | 成交金额 |
| 费用 | 手续费计算 |
| 风控 | 限额计算 |

## 二、定点数基础

### 2.1 表示方法

定点数将实数表示为整数除以固定比例因子：

```
实数值 = 整数值 / 比例因子

例：表示 123.45（2 位小数）
  整数值 = 12345
  比例因子 = 100
  123.45 = 12345 / 100
```

### 2.2 比例因子选择

| 小数位数 | 比例因子 | 精度 | 适用场景 |
|---------|---------|------|---------|
| 2 | 100 | 0.01 | 货币（整分） |
| 4 | 10000 | 0.0001 | 股票价格 |
| 6 | 1000000 | 0.000001 | 外汇汇率 |
| 8 | 100000000 | 1e-8 | 加密货币 |

### 2.3 整数类型选择

| 类型 | 范围 | 适用场景 |
|-----|------|---------|
| int32 | ±21亿 | 小金额 |
| int64 | ±9.2e18 | 大多数场景 |
| int128 | ±1.7e38 | 极大数值 |

**范围计算示例（int64，4 位小数）**：

```
最大值 = 9,223,372,036,854,775,807
最大可表示 = 922,337,203,685,477.5807

足够表示全球任何金融资产价格
```

### 2.4 符号处理

| 方式 | 说明 |
|-----|------|
| 有符号整数 | 直接支持正负 |
| 无符号 + 符号位 | 更大正数范围 |
| 补码 | 标准方式 |

## 三、基本运算

### 3.1 加法与减法

定点数加减法直接使用整数运算：

```
设 A = a / scale, B = b / scale

A + B = (a + b) / scale
A - B = (a - b) / scale
```

**注意**：必须确保同比例因子

### 3.2 乘法

```
A × B = (a × b) / (scale × scale)
      = (a × b) / scale / scale

结果需要除以一个 scale
```

**溢出风险**：a × b 可能溢出

**解决方案**：
- 使用更大类型（int128）
- 先除后乘（损失精度）
- 分步计算

### 3.3 除法

```
A / B = (a / scale) / (b / scale)
      = a / b  ← 丢失 scale

正确做法：
A / B = (a × scale) / b
```

**溢出风险**：a × scale 可能溢出

### 3.4 运算总结

| 运算 | 公式 | 溢出风险 |
|-----|------|---------|
| 加 | (a + b) / s | 低 |
| 减 | (a - b) / s | 低 |
| 乘 | (a × b) / s² | 高 |
| 除 | (a × s) / b | 中 |

## 四、精度与舍入

### 4.1 舍入模式

| 模式 | 说明 | 示例 (2.5) |
|-----|------|-----------|
| 向下舍入 | 趋向负无穷 | 2 |
| 向上舍入 | 趋向正无穷 | 3 |
| 向零舍入 | 趋向零 | 2 |
| 四舍五入 | 0.5 向上 | 3 |
| 银行家舍入 | 0.5 向偶数 | 2 |

### 4.2 金融场景舍入

| 场景 | 推荐模式 | 原因 |
|-----|---------|------|
| 买入金额 | 向上舍入 | 保守，多收钱 |
| 卖出金额 | 向下舍入 | 保守，少付钱 |
| 通用 | 银行家舍入 | 统计无偏 |
| 费用 | 向上舍入 | 不少收费 |

### 4.3 实现舍入

**向下舍入（整数除法默认）**：
```
result = numerator / denominator
```

**四舍五入**：
```
正数: result = (numerator + denominator/2) / denominator
负数: result = (numerator - denominator/2) / denominator
```

**向上舍入**：
```
正数: result = (numerator + denominator - 1) / denominator
```

## 五、溢出处理

### 5.1 溢出检测

**加法溢出检测**：
```
if (b > 0 && a > MAX - b) overflow;
if (b < 0 && a < MIN - b) overflow;
```

**乘法溢出检测**：
```
if (a != 0 && result / a != b) overflow;
```

### 5.2 溢出预防

| 策略 | 说明 |
|-----|------|
| 范围检查 | 运算前验证 |
| 更大类型 | int64 → int128 |
| 分步计算 | 拆分大运算 |
| 饱和运算 | 溢出时取极值 |

### 5.3 乘法安全实现

**方法1：使用更大类型**
```
int64 a, b;
int128 temp = (int128)a * b;
int64 result = temp / scale;
```

**方法2：分步计算**
```
// 将 a 分解为高位和低位
high = a / scale;
low = a % scale;
result = high * b + (low * b) / scale;
```

## 六、比例因子转换

### 6.1 同比例运算要求

| 运算 | 要求 |
|-----|------|
| 加/减 | 必须同比例 |
| 乘 | 可以不同，结果调整 |
| 除 | 可以不同，结果调整 |
| 比较 | 必须同比例 |

### 6.2 比例转换

**升精度（不损失）**：
```
scale1 → scale2 (scale2 > scale1)
new_value = old_value * (scale2 / scale1)
```

**降精度（可能损失）**：
```
scale1 → scale2 (scale2 < scale1)
new_value = old_value / (scale1 / scale2)  // 需要舍入
```

### 6.3 混合精度运算

```
A (scale=100) × B (scale=10000)
= (a/100) × (b/10000)
= (a × b) / 1000000

结果 scale = 1000000
```

## 八、性能优化

### 8.1 编译时计算

| 优化 | 说明 |
|-----|------|
| constexpr scale | 编译时确定 |
| 常量折叠 | 编译时计算常量 |
| 内联展开 | 消除函数调用 |

### 8.2 除法优化

整数除法较慢，可优化：

**方法1：乘以倒数**
```
// 代替 x / 100
x * 0.01  // 浮点
// 或使用定点倒数
```

**方法2：位移（2的幂）**
```
x / 256 = x >> 8
```

**方法3：编译器优化**
编译器对常量除法自动优化为乘法

### 8.3 乘法优化

```
// 2的幂可用位移
x * 1024 = x << 10

// 10的幂保持整数乘法
x * 10000  // 编译器优化
```

### 8.4 比较优化

定点数比较是简单整数比较：
```
a < b  // 直接整数比较，最快
```

## 九、金融计算实践

### 9.1 价格表示

| 市场 | 精度 | 比例因子 |
|-----|------|---------|
| 股票 | 2-4 位 | 10000 |
| 期货 | 2-4 位 | 10000 |
| 外汇 | 4-5 位 | 100000 |
| 加密货币 | 8 位 | 100000000 |

### 9.2 金额计算

```
成交金额 = 价格 × 数量

price: scale = 10000 (4位)
quantity: scale = 1 (整数)
amount: scale = 10000

amount = price_raw * quantity  // 无需额外处理
```

### 9.3 手续费计算

```
手续费 = 金额 × 费率

amount: scale = 10000
rate: scale = 1000000 (百万分之一)

fee_raw = (amount_raw * rate_raw) / 1000000
```

### 9.4 盈亏计算

```
盈亏 = (卖出价 - 买入价) × 数量

pnl_raw = (sell_price_raw - buy_price_raw) * quantity
```

### 9.5 汇率转换

```
USD 金额 × 汇率 = CNY 金额

usd: scale = 100 (分)
rate: scale = 10000 (4位小数)
cny: scale = 100 (分)

cny_raw = (usd_raw * rate_raw) / 10000
```

## 十、常见陷阱

### 10.1 精度陷阱

| 陷阱 | 说明 | 解决 |
|-----|------|------|
| 混合精度 | 不同 scale 运算 | 统一转换 |
| 隐式转换 | 浮点→定点损失 | 显式转换 |
| 累积误差 | 虽无舍入但有溢出 | 范围检查 |

### 10.2 溢出陷阱

| 陷阱 | 场景 | 解决 |
|-----|------|------|
| 乘法溢出 | 大数相乘 | 128位中间结果 |
| 加法溢出 | 累加大量 | 范围检查 |
| 转换溢出 | 高精度→低精度 | 饱和处理 |

### 10.3 舍入陷阱

| 陷阱 | 说明 | 解决 |
|-----|------|------|
| 负数舍入 | 方向相反 | 分正负处理 |
| 一致性 | 不同地方舍入不同 | 统一规则 |
| 累积 | 多次舍入累积 | 最后舍入 |
