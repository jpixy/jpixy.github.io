## 一、经典概率题

### Q1: 硬币翻转

**问题**：一枚硬币，正面朝上的概率是p。连续翻转直到出现正面为止，期望需要翻转多少次？

**答案**：

```
设期望次数为E

E = 1 × p + (1 + E) × (1 - p)
  = p + (1-p) + (1-p)E
  = 1 + (1-p)E

E - (1-p)E = 1
pE = 1
E = 1/p

例如：p = 0.5时，E = 2次
```

### Q2: 两个硬币

**问题**：有两个硬币，一个是公平的(P=0.5)，一个是双面正(P=1)。随机选一个硬币，翻转一次得到正面。这个硬币是公平硬币的概率是多少？

**答案**：

```
使用贝叶斯定理：

P(公平|正面) = P(正面|公平) × P(公平) / P(正面)

P(正面|公平) = 0.5
P(公平) = 0.5
P(正面) = P(正面|公平)×P(公平) + P(正面|双正)×P(双正)
        = 0.5 × 0.5 + 1 × 0.5
        = 0.75

P(公平|正面) = 0.5 × 0.5 / 0.75 = 1/3

答案：1/3
```

### Q3: 生男生女问题

**问题**：一个家庭有两个孩子。已知其中一个是男孩，另一个也是男孩的概率是多少？

**答案**：

```
可能的组合：(男,男), (男,女), (女,男), (女,女)
已知至少一个是男孩，排除(女,女)
剩余：(男,男), (男,女), (女,男)

P(两个都是男) = 1/3

注意：如果问的是"大的孩子是男孩"，则答案是1/2
因为只剩(男,男), (男,女)两种情况
```

## 二、期望值计算

### Q4: 骰子游戏

**问题**：掷一个公平骰子，可以选择拿当前点数作为奖金（美元），或者重新掷一次（最多掷N次）。最优策略下的期望奖金是多少？

**答案**：

```python
# 动态规划解法
def dice_game(n):
    """n次机会的期望奖金"""
    if n == 1:
        return 3.5  # 只有一次机会，期望是3.5
    
    # 上一轮的期望
    prev_exp = dice_game(n - 1)
    
    # 当前策略：如果点数大于下一轮期望，接受；否则重掷
    threshold = prev_exp
    
    # 期望 = sum(接受的点数×概率) + P(重掷)×下一轮期望
    exp = 0
    for i in range(1, 7):
        if i > threshold:
            exp += i / 6  # 接受
        else:
            exp += prev_exp / 6  # 重掷
    
    return exp

# N=2: E ≈ 4.25
# N=3: E ≈ 4.67
# N→∞: E → 6
```

### Q5: 收集优惠券问题

**问题**：有N种不同的优惠券，每次随机获得一种。收集齐所有种类的期望次数是多少？

**答案**：

```
设已有k种，获得第k+1种的期望次数：
E[k→k+1] = N/(N-k)

总期望：
E = Σ(k=0 to N-1) N/(N-k)
  = N × (1/N + 1/(N-1) + ... + 1/1)
  = N × H(N)

其中H(N)是第N个调和数 ≈ ln(N) + γ

例如：N=10，E ≈ 10 × 2.93 ≈ 29次
```

### Q6: 赌徒破产问题

**问题**：赌徒有n元，每次赢1元概率p，输1元概率1-p。赢到N元或输光为止。赢到N元的概率是多少？

**答案**：

```
设从n元开始赢到N元的概率为P(n)

边界条件：P(0) = 0, P(N) = 1

递推：P(n) = p × P(n+1) + (1-p) × P(n-1)

对于p ≠ 0.5：
P(n) = (1 - (q/p)^n) / (1 - (q/p)^N)
其中 q = 1-p

对于p = 0.5：
P(n) = n/N

例如：n=10, N=20, p=0.5
P(10) = 10/20 = 0.5
```

## 三、概率推导

### Q7: 蒙提霍尔问题

**问题**：三扇门后有一辆车和两只羊。你选了一扇门，主持人打开另一扇有羊的门。你要换吗？

**答案**：

```
初始选择正确的概率：1/3
初始选择错误的概率：2/3

如果初始错误（概率2/3），换门必赢
如果初始正确（概率1/3），换门必输

换门赢的概率：2/3
不换赢的概率：1/3

结论：应该换门！
```

### Q8: 生日问题

**问题**：N个人中至少两人生日相同的概率是多少？需要多少人才能使概率超过50%？

**答案**：

```
全不同的概率：
P(全不同) = 365/365 × 364/365 × 363/365 × ... × (365-N+1)/365

至少两人相同：
P(至少两人相同) = 1 - P(全不同)

计算：
N = 23 时，P ≈ 50.7%
N = 50 时，P ≈ 97%
N = 70 时，P ≈ 99.9%

答案：23人
```

### Q9: 随机行走

**问题**：在一维随机行走中，从原点出发，每步+1或-1概率各为0.5。回到原点的概率是多少？期望步数是多少？

**答案**：

```
回到原点的概率：
对于一维对称随机行走，回到原点的概率是1（几乎必然回归）

但期望步数是无穷大！

证明：
2n步后回到原点的概率：
P(2n) = C(2n,n) × (1/2)^(2n) ≈ 1/√(πn)

期望回归时间：
E = Σ 2n × P(第一次在2n步回归)
  = ∞ （发散）

这是一个有趣的悖论：必然发生的事件期望时间可以是无穷大
```

## 四、策略问题

### Q10: 最优停止问题（秘书问题）

**问题**：面试N个候选人，必须当场决定是否录用。如何最大化选到最佳候选人的概率？

**答案**：

```
最优策略：
1. 拒绝前 N/e ≈ 0.37N 个候选人（观察期）
2. 之后录用第一个比观察期所有人都好的候选人

成功概率：
P ≈ 1/e ≈ 0.37

代码实现：
```python
def secretary_problem(candidates):
    n = len(candidates)
    observe = int(n / math.e)
    
    # 观察期找最大值
    threshold = max(candidates[:observe]) if observe > 0 else float('-inf')
    
    # 选择第一个超过阈值的
    for i in range(observe, n):
        if candidates[i] > threshold:
            return i
    
    return n - 1  # 否则选最后一个
```

### Q11: 赌场筹码问题

**问题**：你有100元，可以下任意赌注。赢的概率60%，赔率1:1。目标是赚到200元。最优策略是什么？

**答案**：

```
Kelly Criterion建议的赌注比例：
f* = (bp - q) / b
   = (1×0.6 - 0.4) / 1
   = 0.2 = 20%

但如果目标是达到200元：

策略1：全押（bold play）
- 每次全押，期望达到目标的概率更高（对于不利游戏）

策略2：保守（timid play）
- 每次只押1元

对于有利游戏（p>0.5），Kelly策略长期最优
但如果有时间限制，需要权衡

期望增长率最大化：使用Kelly比例
但Kelly会让你永远达不到"翻倍"的目标

实际答案取决于具体约束条件
```

## 五、估算题

### Q12: 快速估算

**问题**：估算纽约有多少钢琴调音师。

**框架**：
```
1. 纽约人口：约800万
2. 家庭数：约300万（假设2.7人/户）
3. 有钢琴的家庭：约5% = 15万台
4. 每台钢琴每年调音：2次 = 30万次/年
5. 工作日：250天/年
6. 每天可调音：4台
7. 每个调音师年工作量：1000次
8. 需要调音师：30万/1000 = 300人

答案：约300人
```

### Q13: 交易相关估算

**问题**：估算一个HFT系统每天处理多少条消息。

```
假设：
1. 交易时间：6.5小时 = 23400秒
2. 覆盖品种：1000个
3. 每个品种每秒更新：10次
4. 每次更新消息：3条（bid/ask/trade）

计算：
消息数 = 23400 × 1000 × 10 × 3
       = 7亿条/天

峰值可能是平均的10倍
需要处理：约10000条/秒（平均）到100000条/秒（峰值）

## 六、脑筋急转弯

### Q14: 称重问题

**问题**：有12个球，其中一个重量不同。用天平最少称几次能找出来？

**答案**：
```
答案：3次

策略：
第一次：4个 vs 4个
- 如果平衡：异常球在剩余4个中
- 如果不平衡：异常球在这8个中

第二次和第三次用类似的三分法

关键洞察：每次称重可以得到3种结果（左重、右重、平衡）
3次称重最多区分3^3=27种情况
12个球×2种可能（重或轻）=24种情况 < 27
所以3次足够
```

### Q15: 烧绳子问题

**问题**：两根不均匀的绳子，每根燃烧完需要1小时。如何测量45分钟？

**答案**：
```
1. 同时点燃第一根绳子的两端和第二根绳子的一端
2. 第一根燃烧完时（30分钟），点燃第二根的另一端
3. 第二根燃烧完时，又过了15分钟

总时间：30 + 15 = 45分钟
```
