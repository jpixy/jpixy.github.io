# 自动驾驶工作流程

本文详细解析自动驾驶系统从传感器采集到执行控制的完整工作流程，揭示每个环节的处理逻辑。

---

## 一、整体工作流程

### 1.1 主循环

```mermaid
flowchart TB
    SENSOR[传感器<br/>数据采集] --> PERCEPT[感知<br/>处理]
    PERCEPT --> PLAN[规划<br/>决策]
    PLAN --> CTRL[控制<br/>执行]
    CTRL -.->|10-100 Hz 循环| SENSOR
```

### 1.2 时间约束

| 环节 | 频率 | 延迟预算 | 说明 |
|-----|------|---------|------|
| 传感器采集 | 10-60 Hz | <10ms | 同步采集 |
| 感知处理 | 10-30 Hz | <50ms | 神经网络推理 |
| 规划决策 | 10-20 Hz | <20ms | 轨迹生成 |
| 控制执行 | 50-100 Hz | <10ms | 实时控制 |
| 端到端 | - | <100ms | 从感知到控制 |

### 1.3 数据流

```
原始数据量/秒:
├── 摄像头 (8×1080P×30fps): ~3 GB/s
├── 激光雷达 (128线): ~150 MB/s
├── 毫米波雷达 (5个): ~10 MB/s
└── GPS/IMU: ~1 MB/s
─────────────────────────
总计: ~3.2 GB/s
```

## 二、传感器数据采集

### 2.1 同步机制

**时间同步要求**：

| 传感器组合 | 同步精度 |
|-----------|---------|
| 相机-相机 | <1ms |
| 相机-激光雷达 | <5ms |
| 所有传感器 | <10ms |

**同步方法**：

| 方法 | 说明 |
|-----|------|
| 硬件触发 | 主时钟触发各传感器 |
| PTP 时间同步 | IEEE 1588 精确时间 |
| GPS 时间戳 | GPS PPS 信号同步 |
| 软件插值 | 时间戳匹配插值 |

### 2.2 摄像头数据流

```mermaid
graph TB
    A[图像采集] --> B[ISP 处理<br/>去马赛克、降噪、HDR]
    B --> C[畸变校正<br/>使用标定参数]
    C --> D[时间戳标记]
    D --> E[感知模块]
```

### 2.3 激光雷达数据流

```mermaid
graph TB
    A[激光扫描] --> B[点云生成<br/>距离+角度→XYZ]
    B --> C[运动补偿<br/>补偿车辆运动畸变]
    C --> D[坐标变换<br/>转到车体坐标系]
    D --> E[感知模块]
```

### 2.4 数据预处理

| 传感器 | 预处理内容 |
|-------|-----------|
| 摄像头 | ISP、畸变校正、归一化 |
| 激光雷达 | 运动补偿、滤波、分割地面 |
| 毫米波 | 杂波过滤、聚类 |
| IMU | 零偏补偿、滤波 |

## 三、感知处理流程

### 3.1 感知总览

```mermaid
graph TB
    A[传感器数据] --> B[相机感知分支]
    A --> C[激光感知分支]
    B --> D[融合感知]
    C --> D
    D --> E[目标检测]
    D --> F[语义分割]
    D --> G[车道线检测]
```

### 3.2 目标检测流程

```mermaid
graph TB
    A[输入图像/点云] --> B[特征提取<br/>Backbone: ResNet/ViT]
    B --> C[特征金字塔<br/>FPN 多尺度]
    C --> D[检测头<br/>分类 + 回归]
    D --> E[后处理<br/>NMS、置信度过滤]
    E --> F[检测结果<br/>类别, 位置, 置信度]
```

### 3.3 多目标跟踪

```mermaid
graph TB
    A[当前帧检测] --> B[特征提取<br/>外观/运动特征]
    B --> C[关联匹配<br/>匈牙利算法/GNN]
    C --> D[匹配目标]
    C --> E[新目标]
    C --> F[消失目标]
    D --> G[更新轨迹]
    E --> H[初始化轨迹]
    F --> I[标记丢失]
    G --> J[轨迹管理<br/>删除/确认]
    H --> J
    I --> J
    J --> K[跟踪结果<br/>ID, 轨迹, 状态]
```

### 3.4 传感器融合

**融合流程**：

```mermaid
graph TB
    A[相机检测结果] --> D[融合模块]
    B[激光雷达检测] --> D
    C[毫米波检测] --> D
    D --> E[统一目标列表]
```

**融合策略**：

| 级别 | 输入 | 方法 |
|-----|------|------|
| 早期融合 | 原始数据 | BEVFusion |
| 中期融合 | 特征 | 特征拼接/注意力 |
| 晚期融合 | 检测结果 | 匹配投票 |

## 四、定位流程

### 4.1 定位融合

```mermaid
graph TB
    A[GPS/RTK] --> D[状态估计<br/>EKF/UKF]
    B[IMU 积分] --> D
    C[视觉/激光定位] --> D
    D --> E[位姿输出]
```

### 4.2 激光定位流程

```mermaid
graph TB
    A[当前点云] --> B[特征提取<br/>边缘/平面特征]
    B --> C[地图匹配<br/>ICP/NDT]
    C --> D[位姿优化<br/>最小化匹配误差]
    D --> E[车辆位姿<br/>x, y, z, roll, pitch, yaw]
```

### 4.3 视觉定位流程

```mermaid
graph TB
    A[当前图像] --> B[特征提取<br/>ORB/SuperPoint]
    B --> C[地图检索<br/>找最相似位置]
    C --> D[PnP 求解<br/>2D-3D 对应]
    D --> E[相机位姿]
```

### 4.4 IMU 预积分

| 步骤 | 说明 |
|-----|------|
| 高频积分 | 100-1000Hz 积分加速度/角速度 |
| 预积分因子 | 两关键帧间的相对运动 |
| 因子图优化 | 与其他约束联合优化 |
| 偏置估计 | 在线估计零偏 |

---

## 五、预测流程

### 5.1 预测任务

```mermaid
graph TB
    A[当前状态] --> B[历史编码<br/>过去轨迹编码]
    B --> C[场景编码<br/>地图+周围车辆]
    C --> D[交互建模<br/>车辆间交互]
    D --> E[轨迹解码<br/>生成多条预测]
    E --> F[预测轨迹<br/>多模态, 带概率]
```

### 5.2 预测输出

| 输出 | 说明 |
|-----|------|
| 多模态轨迹 | 多条可能的未来轨迹 |
| 概率分布 | 每条轨迹的概率 |
| 预测时长 | 通常 3-8 秒 |
| 不确定性 | 预测的置信度 |

### 5.3 行人意图预测

```mermaid
graph TB
    A[行人检测] --> B[姿态估计<br/>身体朝向]
    B --> C[行为分类<br/>站立/行走/准备过马路]
    C --> D[意图推理<br/>是否会过马路]
    D --> E[意图 + 预测轨迹]
```

---

## 六、规划决策流程

### 6.1 规划层次

```mermaid
graph TB
    A[导航目的地] --> B[全局路径规划<br/>A*/Dijkstra<br/>时间尺度: 分钟]
    B --> C[行为决策<br/>状态机/学习<br/>时间尺度: 秒]
    C --> D[运动规划<br/>优化/采样<br/>时间尺度: 毫秒]
    D --> E[可执行轨迹]
```

### 6.2 行为决策流程

```mermaid
graph TB
    A[当前状态 + 感知结果] --> B[场景理解<br/>路口/高速/停车]
    B --> C[可行动作枚举<br/>直行/变道/停车]
    C --> D[动作评估<br/>安全性/效率/舒适性]
    D --> E[动作选择<br/>选最优动作]
    E --> F[行为指令<br/>跟车/变道/停车...]
```

### 6.3 运动规划流程

```mermaid
graph TB
    A[行为指令 + 约束] --> B[参考线生成<br/>基于车道线]
    B --> C[可行驶空间<br/>SL/ST 图]
    C --> D[轨迹生成]
    D --> D1[采样法]
    D --> D2[优化法]
    D1 --> E[轨迹评估<br/>碰撞/舒适性检查]
    D2 --> E
    E --> F[最优轨迹]
```

### 6.4 轨迹表示

| 表示方法 | 说明 |
|---------|------|
| 离散点 | (x, y, θ, v, a, κ, t) 序列 |
| 多项式 | 五次多项式拟合 |
| 贝塞尔曲线 | 平滑曲线 |
| Frenet 坐标 | 沿参考线的 s-l 表示 |

---

## 七、控制执行流程

### 7.1 控制总览

```mermaid
graph TB
    A[规划轨迹] --> B[横向控制<br/>转向]
    A --> C[纵向控制<br/>加减速]
    B --> D[转向角指令]
    C --> E[油门/刹车指令]
    D --> F[执行器]
    E --> F
```

### 7.2 横向控制流程

```mermaid
graph TB
    A[目标轨迹 + 当前位姿] --> B[误差计算<br/>横向误差、航向误差]
    B --> C[控制器计算<br/>PID/Stanley/MPC]
    C --> D[限幅处理<br/>最大转向角/速率]
    D --> E[转向角指令]
```

### 7.3 纵向控制流程

```mermaid
graph TB
    A[目标速度/位置 + 当前状态] --> B[误差计算<br/>速度误差/距离误差]
    B --> C[控制器计算<br/>PID/MPC]
    C --> D[油门刹车分配<br/>正→油门, 负→刹车]
    D --> E[油门/刹车指令]
```

### 7.4 MPC 控制流程

```mermaid
graph TB
    A[当前状态 + 目标轨迹] --> B[建立预测模型<br/>车辆运动学/动力学]
    B --> C[定义代价函数<br/>跟踪误差+舒适性]
    C --> D[定义约束<br/>物理限制]
    D --> E[求解优化问题<br/>QP/SQP 求解器]
    E --> F[控制序列<br/>只执行第一个]
```

### 7.5 执行器接口

| 接口 | 协议 | 频率 |
|-----|------|------|
| 转向 | CAN | 100Hz |
| 油门 | CAN | 100Hz |
| 刹车 | CAN | 100Hz |
| 档位 | CAN | 10Hz |

## 八、安全监控流程

### 8.1 安全架构

```mermaid
graph TB
    subgraph 安全监控层
        A[感知监控]
        B[规划监控]
        C[控制监控]
        D[系统监控]
    end
    A --> E[安全仲裁<br/>降级 / MRM / 接管]
    B --> E
    C --> E
    D --> E
```

### 8.2 监控内容

| 层面 | 监控内容 |
|-----|---------|
| 感知 | 目标合理性、时间戳 |
| 定位 | 精度、连续性 |
| 规划 | 碰撞检查、可行性 |
| 控制 | 跟踪误差、执行状态 |
| 系统 | CPU/内存/温度 |

### 8.3 MRM 流程

**Minimal Risk Maneuver**：

```mermaid
graph TB
    A[异常检测] --> B[评估严重性]
    B --> C[可恢复]
    B --> D[不可恢复]
    C --> E[降级运行]
    D --> F[触发 MRM]
    F --> G[靠边停车]
    F --> H[原地停车]
```

## 九、系统时序

### 9.1 典型时序图

| 阶段 | 时间范围 (ms) | 持续时间 |
|------|---------------|---------|
| 传感器采集 | 0-10 | ~10ms |
| 感知推理 | 10-50 | ~40ms |
| 预测 | 50-60 | ~10ms |
| 规划 | 60-80 | ~20ms |
| 控制 | 80-90 | ~10ms |
| 执行 | 90-100 | ~10ms |
| **端到端延迟** | - | **~80-100ms** |

### 9.2 并行处理

| 时刻 T | 采集 | 感知 | 规划 | 控制 |
|--------|------|------|------|------|
| 数据帧 | [T] | [T-1] | [T-2] | [T-3] |

各模块并行处理不同时刻数据，实现流水线处理。
