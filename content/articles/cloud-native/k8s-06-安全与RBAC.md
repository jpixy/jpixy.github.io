# Kubernetes安全与RBAC

## 一、K8s安全模型

### 1.1 安全层次

```
┌─────────────────────────────────────────────────────────────┐
│                      应用安全                                │
│  (代码安全、依赖安全、容器镜像安全)                         │
├─────────────────────────────────────────────────────────────┤
│                      运行时安全                              │
│  (Pod安全策略、容器运行时安全)                              │
├─────────────────────────────────────────────────────────────┤
│                      访问控制                                │
│  (认证、授权RBAC、准入控制)                                 │
├─────────────────────────────────────────────────────────────┤
│                      网络安全                                │
│  (NetworkPolicy、TLS、服务网格)                             │
├─────────────────────────────────────────────────────────────┤
│                      数据安全                                │
│  (Secret加密、etcd加密、存储加密)                           │
├─────────────────────────────────────────────────────────────┤
│                      基础设施安全                            │
│  (节点安全、网络隔离、审计日志)                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 API请求流程

```
         客户端请求
              │
              ▼
    ┌─────────────────┐
    │    认证         │ ←── 你是谁？
    │ Authentication  │     (证书、Token、OIDC)
    └────────┬────────┘
             │
             ▼
    ┌─────────────────┐
    │    授权         │ ←── 你能做什么？
    │ Authorization   │     (RBAC、ABAC、Webhook)
    └────────┬────────┘
             │
             ▼
    ┌─────────────────┐
    │   准入控制      │ ←── 请求是否合规？
    │ Admission Ctrl  │     (Webhook、Policy)
    └────────┬────────┘
             │
             ▼
       请求被处理
```
