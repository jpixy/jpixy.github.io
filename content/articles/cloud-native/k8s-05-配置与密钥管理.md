# Kubernetes配置与密钥管理

## 一、ConfigMap详解

### 1.1 创建ConfigMap

**命令行创建**：

```bash
# 从字面值创建
kubectl create configmap my-config \
  --from-literal=key1=value1 \
  --from-literal=key2=value2

# 从文件创建
kubectl create configmap my-config \
  --from-file=config.properties \
  --from-file=settings.json

# 从目录创建
kubectl create configmap my-config \
  --from-file=./config-dir/

# 从环境变量文件创建
kubectl create configmap my-config \
  --from-env-file=app.env
```

**YAML创建**：

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
  namespace: default
data:
  # 简单键值对
  DATABASE_HOST: mysql.default.svc.cluster.local
  DATABASE_PORT: "3306"
  LOG_LEVEL: info
  
  # 多行配置文件
  application.yaml: |
    server:
      port: 8080
      context-path: /api
    spring:
      datasource:
        url: jdbc:mysql://mysql:3306/mydb
        username: ${DB_USER}
        password: ${DB_PASS}
    logging:
      level:
        root: INFO
        com.example: DEBUG
  
  nginx.conf: |
    server {
      listen 80;
      location / {
        proxy_pass http://backend:8080;
      }
    }

binaryData:
  # 二进制数据（base64编码）
  logo.png: iVBORw0KGgoAAAANSUhEUgAAAAE...
```

### 1.2 使用ConfigMap

**作为环境变量**：

```yaml
spec:
  containers:
  - name: app
    image: myapp:v1
    
    # 单个值
    env:
    - name: DB_HOST
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: DATABASE_HOST
    
    # 可选：不存在时不报错
    - name: OPTIONAL_CONFIG
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: optional-key
          optional: true
    
    # 所有键作为环境变量
    envFrom:
    - configMapRef:
        name: app-config
      prefix: CONFIG_  # 可选前缀
```

**作为Volume挂载**：

```yaml
spec:
  containers:
  - name: app
    image: myapp:v1
    volumeMounts:
    - name: config-volume
      mountPath: /etc/config
      readOnly: true
  
  volumes:
  - name: config-volume
    configMap:
      name: app-config
      # 可选：指定文件权限
      defaultMode: 0644
      # 可选：只挂载特定键
      items:
      - key: application.yaml
        path: application.yaml
      - key: nginx.conf
        path: nginx/nginx.conf
```

**挂载为单个文件（不覆盖目录）**：

```yaml
volumeMounts:
- name: config-volume
  mountPath: /etc/nginx/nginx.conf
  subPath: nginx.conf
```

### 1.3 ConfigMap热更新

**自动更新的情况**：

```
Volume挂载方式：
├── 约60秒后自动更新
├── 使用subPath时不会自动更新
└── 应用需要监听文件变化或重启
```

**不自动更新的情况**：

```
环境变量方式：
├── 不会自动更新
└── 需要重启Pod
```

**强制触发更新**：

```bash
# 添加注解触发滚动更新
kubectl patch deployment myapp \
  -p '{"spec":{"template":{"metadata":{"annotations":{"configmap-hash":"'$(kubectl get cm app-config -o jsonpath='{.metadata.resourceVersion}')'"}}}}}'
```
