# Kubernetes存储管理

## 一、存储概述

### 1.1 存储抽象

```
┌─────────────────────────────────────────────────────────────┐
│                        用户层                               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │            PersistentVolumeClaim (PVC)              │   │
│  │            "我需要10GB的存储"                        │   │
│  └───────────────────────┬─────────────────────────────┘   │
├──────────────────────────┼──────────────────────────────────┤
│                     Kubernetes层                            │
│  ┌───────────────────────┼─────────────────────────────┐   │
│  │            StorageClass                              │   │

└─────────────────────────────────────────────────────────────┘
```

### 1.2 Volume类型

**临时存储**：

```yaml
volumes:
# emptyDir：Pod生命周期内的临时存储
- name: cache
  emptyDir:
    sizeLimit: 1Gi
    medium: Memory  # 或 "" (磁盘)

# configMap：配置文件
- name: config
  configMap:
    name: my-config
    items:
    - key: config.yaml
      path: config.yaml

# secret：敏感信息
- name: secret
  secret:
    secretName: my-secret
    defaultMode: 0400

# downwardAPI：Pod元数据
- name: podinfo
  downwardAPI:
    items:
    - path: labels
      fieldRef:
        fieldPath: metadata.labels
```

**持久存储**：

```yaml
volumes:
# hostPath：挂载Node目录（谨慎使用）
- name: host-data
  hostPath:
    path: /data
    type: DirectoryOrCreate

# persistentVolumeClaim：持久卷声明
- name: data
  persistentVolumeClaim:
    claimName: my-pvc
```
