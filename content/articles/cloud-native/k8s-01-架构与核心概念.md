# Kubernetes架构与核心概念

## 一、Kubernetes概述

### 1.1 什么是Kubernetes

Kubernetes（K8s）是Google开源的容器编排平台，用于自动化部署、扩展和管理容器化应用。

**核心价值**：

```
容器编排：
├── 自动化部署和回滚
├── 服务发现和负载均衡
├── 存储编排
├── 自动装箱（资源调度）
├── 自我修复
├── 密钥和配置管理
└── 水平扩缩容
```

### 1.2 K8s与Docker的关系

```
容器运行时演进：

Docker时代（早期）：
├── Docker = 容器运行时 + 镜像构建 + 编排
└── K8s使用Docker作为运行时

CRI标准化（现在）：
├── K8s通过CRI接口对接容器运行时
├── 支持多种运行时：containerd、CRI-O
├── Docker镜像格式仍是标准（OCI）
└── 1.24+版本移除dockershim

关系总结：
├── Docker：构建镜像的工具
├── containerd：容器运行时
└── Kubernetes：容器编排平台
```
