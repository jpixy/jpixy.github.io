# 嵌入式电源与电池管理

电源是嵌入式系统的"血液"。本文系统讲解电源设计原理、电池管理技术与功耗优化方法。

---

## 一、电源基础

### 1.1 嵌入式系统常见电压

| 电压 | 用途 | 来源 |
|-----|------|------|
| 5V | USB供电、部分外设 | USB、适配器 |
| 3.3V | 主流MCU、传感器 | LDO/DC-DC降压 |
| 1.8V | 低功耗MCU内核 | LDO降压 |
| 3.7V | 锂电池标称电压 | 电池 |
| 12V/24V | 工业设备、电机驱动 | 电源适配器 |

### 1.2 电源设计核心指标

**输出电压精度**：
- 通常要求±3%以内
- MCU对电压容忍度有限，超出可能不稳定

**负载能力**：
- 需覆盖最大电流需求
- 预留20-30%余量

**效率**：
- 效率 = 输出功率 / 输入功率
- 电池供电时效率直接影响续航

**纹波**：
- 输出电压的交流成分
- 敏感电路（ADC、射频）对纹波要求高

**瞬态响应**：
- 负载突变时电压恢复速度
- 无线模块等负载变化大的场景需关注

## 二、稳压器选型

### 2.1 LDO线性稳压器

**工作原理**：
LDO（Low Dropout Regulator）通过内部晶体管消耗多余的电压差，将输入电压转换为稳定的输出电压。

**特点**：
- 优点：低噪声、电路简单、成本低
- 缺点：效率低（尤其压差大时），发热

**效率计算**：
```
效率 = Vout / Vin
例：3.3V输出，5V输入，效率 = 66%
例：3.3V输出，3.7V输入，效率 = 89%
```

**压差（Dropout）**：
LDO正常工作需要的最小输入输出电压差。低压差LDO可做到100-200mV。

**选型要点**：
- 输入输出压差小于1V时首选LDO
- 噪声敏感电路（模拟、射频）使用LDO
- 关注静态电流（Iq），电池供电时越低越好
- 输出电容影响稳定性，按datasheet选择

### 2.2 DC-DC开关稳压器

**工作原理**：
通过高频开关和电感/电容储能元件，实现高效率的电压转换。

**类型**：

| 类型 | 功能 | 效率 | 应用 |
|-----|------|------|------|
| Buck（降压） | Vin > Vout | 85-95% | 最常用 |
| Boost（升压） | Vin < Vout | 80-95% | 电池升压 |
| Buck-Boost | 升降压均可 | 75-90% | 电池全程工作 |

**特点**：
- 优点：高效率，适合大压差、大电流
- 缺点：有开关噪声，需要电感/电容

**选型要点**：
- 压差超过1V或电流超过100mA考虑DC-DC
- 开关频率影响效率和噪声（高频效率稍低但器件小）
- 电感选型影响纹波和效率
- 输出纹波需用示波器验证

### 2.3 LDO vs DC-DC决策

| 场景 | 推荐 | 原因 |
|-----|------|------|
| 3.7V→3.3V | LDO | 压差小，效率高 |
| 5V→3.3V，<50mA | LDO | 简单，发热可接受 |
| 5V→3.3V，>100mA | DC-DC | LDO发热过大 |
| 12V→3.3V | DC-DC | 压差大，LDO效率仅27% |
| 射频供电 | LDO | 噪声低 |
| 电池供电 | DC-DC+LDO | DC-DC提效，LDO滤噪 |

### 2.4 多电压轨设计

复杂系统通常需要多个电压：

```
电池(3.7V)
    │
    ├──► DC-DC ──► 5V (USB外设)
    │
    ├──► Buck ──► 3.3V (MCU, 传感器)
    │              │
    │              └──► LDO ──► 1.8V (MCU内核)
    │
    └──► Boost ──► 12V (电机驱动)
```

**上电顺序**：
某些IC对电压轨上电顺序有要求，需要设计时序控制或使用带序列控制的PMIC。

## 三、电池技术

### 3.1 电池类型对比

| 类型 | 标称电压 | 能量密度 | 循环次数 | 自放电 | 特点 |
|-----|---------|---------|---------|--------|------|
| 碱性电池 | 1.5V | 中 | 一次性 | 低 | 便宜，不可充 |
| 镍氢(NiMH) | 1.2V | 中 | 500-1000 | 高 | 可充，记忆效应 |
| 锂离子 | 3.7V | 高 | 500-1000 | 低 | 主流可充电池 |
| 锂聚合物 | 3.7V | 高 | 300-500 | 低 | 形状灵活 |
| 磷酸铁锂 | 3.2V | 中 | 2000+ | 极低 | 安全，长寿命 |
| 锂亚硫酰氯 | 3.6V | 极高 | 一次性 | 极低 | 表计、追踪器 |

### 3.2 锂电池特性

**放电曲线**：
锂电池电压随电量变化的典型曲线：
- 满电：4.2V
- 标称：3.7V（约50%电量）
- 截止：3.0V（需停止放电）
- 过放会永久损坏电池

**关键参数**：
- 容量(mAh)：标称放电电流下能持续的时间×电流
- C率：充放电速率。1C表示1小时充满/放完
- 内阻：影响大电流放电能力和效率

**安全注意**：
- 过充（>4.25V）：可能起火爆炸
- 过放（<2.5V）：永久损坏
- 过温：加速老化，极端情况危险
- 短路：瞬间大电流，极度危险

### 3.3 电池选型

**容量估算**：
```
所需容量 = 平均电流 × 使用时长 / 效率系数
效率系数通常取0.7-0.8（考虑DC-DC效率、电池老化等）
```

**例子**：
设备平均电流20mA，目标续航48小时：
```
容量 = 20mA × 48h / 0.75 = 1280mAh
选择1500mAh或更大电池
```

## 四、电池管理系统(BMS)

### 4.1 BMS功能

| 功能 | 说明 |
|-----|------|
| 充电管理 | 控制充电电流、电压、终止条件 |
| 放电保护 | 过流、过放保护 |
| 电量估算 | SOC(剩余电量百分比) |
| 均衡 | 多节电池电压均衡 |
| 温度监控 | 过温保护、低温限制 |
| 通信 | 向主控报告电池状态 |

### 4.2 锂电池充电过程

标准CC-CV（恒流-恒压）充电：

**阶段1：预充（可选）**
- 条件：电池电压<3.0V（深度放电）
- 电流：0.1C
- 目的：安全激活电池

**阶段2：恒流充电(CC)**
- 电压：<4.2V
- 电流：0.5C-1C恒定
- 占充电时间的大部分

**阶段3：恒压充电(CV)**
- 电压：恒定4.2V
- 电流：逐渐降低
- 终止条件：电流降至0.1C或更低

**充电时间估算**：
约2-3小时充满（取决于C率和CV阶段时长）

### 4.3 常用充电IC

| 芯片 | 输入 | 充电电流 | 特点 |
|-----|------|---------|------|
| TP4056 | 5V | 1A可调 | 最常用，便宜 |
| BQ24072 | 5V | 1.5A | 带路径管理 |
| BQ25895 | 5V-12V | 3A | 支持QC快充 |
| MP2615 | 5V | 2A | 集成升压 |

**路径管理**：
高级充电IC支持边充边用，自动切换电源路径，避免电池反复充放。

### 4.4 电量估算(SOC)

**电压法**：
根据电池电压查表估算电量。简单但不准确：
- 电压与电量非线性关系
- 负载影响电压（电流越大电压越低）
- 温度影响电压

**库仑计数法**：
积分充放电电流计算电量变化：
```
SOC = SOC_初始 + ∫(I)dt / 容量
```
需要高精度电流采样，长期运行有累积误差，需要定期校准。

**综合法**：
结合电压和库仑计数，用卡尔曼滤波等算法融合。

**专用电量计IC**：
- TI BQ27441：集成库仑计数、内阻测量
- Maxim MAX17048：电压+建模算法
- 减少开发工作量，精度更高

### 4.5 多节电池管理

多节串联锂电池需要额外管理：

**电压均衡**：
- 问题：各电芯容量/内阻差异导致电压不一致
- 被动均衡：通过电阻放掉高电压电芯的能量
- 主动均衡：将高电压电芯的能量转移到低电压电芯

**保护板**：
多节电池必须使用保护板，监测每节电压，提供过充/过放/过流保护。

## 五、功耗优化

### 5.1 功耗组成分析

```
总功耗 = MCU功耗 + 外设功耗 + 电源损耗

MCU功耗 = 运行功耗 + 睡眠功耗
外设功耗 = 常开外设 + 间歇外设
```

### 5.2 MCU低功耗设计

**时钟优化**：
- 降低主频：功耗与频率近似正比
- 关闭不用的外设时钟
- 使用低功耗时钟源

**电压优化**：
- 部分MCU支持动态电压调节
- 低频运行时可降低内核电压

**睡眠模式**：

| 模式 | 唤醒速度 | 功耗 | 保留内容 |
|-----|---------|------|---------|
| Sleep | 最快 | 高 | 全部 |
| Stop | 中等 | 低 | RAM+寄存器 |
| Standby | 最慢 | 最低 | 仅备份寄存器 |

**唤醒源规划**：
- RTC定时唤醒：周期性任务
- 外部中断：事件驱动
- 串口唤醒：通信触发

### 5.3 外设功耗管理

**按需开关电源**：
- 使用GPIO控制外设电源（通过MOS管）
- 使用前开启，使用后关闭

**传感器占空比**：
- 间歇采样而非持续采样
- 采样频率与需求匹配

**无线模块**：
- WiFi待机功耗高（数mA），尽量少用
- BLE广播间隔对功耗影响巨大
- 需要时再开启射频

### 5.4 功耗估算与测量

**估算方法**：
1. 列出所有状态：活动、采集、传输、睡眠
2. 估算各状态电流（查datasheet）
3. 估算各状态持续时间占比
4. 加权计算平均电流

**例子**：
```
状态      电流      时间占比
睡眠      5μA       95%
采集      5mA       3%
传输      50mA      2%

平均电流 = 5×0.95 + 5000×0.03 + 50000×0.02
        = 4.75 + 150 + 1000 = 1155μA ≈ 1.2mA
```

**测量工具**：
- 万用表：平均电流，精度有限
- 电流探头+示波器：观察瞬态波形
- Nordic PPK2：专业功耗分析，μA级精度
- Joulescope：高精度能量分析仪

## 六、实际设计案例

### 案例：电池供电传感器节点

**需求**：
- 锂电池供电
- LoRa每小时上报一次
- 目标续航1年

**功耗分析**：
```
LoRa发送：100mA × 100ms = 10mAs/次
MCU处理：10mA × 50ms = 0.5mAs/次
睡眠：5μA × 3599.85s = 18mAs/小时

每小时消耗 = 10 + 0.5 + 18 = 28.5mAs
```

**电池选型**：
```
年消耗 = 28.5mAs × 24 × 365 = 249,660mAs = 69.4mAh
考虑1.5倍余量：需要约100mAh
选择容量：500-1000mAh（留余量）
```

**设计要点**：
- MCU使用最低功耗睡眠模式
- LoRa模块不用时完全关断电源
- DC-DC选择高效率、低静态电流型号
- 避免漏电路径（如上拉电阻）

## 总结

电源设计的核心原则：

| 维度 | 要点 |
|-----|------|
| 稳压器选型 | 压差大用DC-DC，噪声敏感用LDO |
| 电池选择 | 根据能量密度、安全、成本综合考虑 |
| BMS设计 | 充电管理、保护、电量估算 |
| 功耗优化 | 睡眠模式、外设管理、占空比 |
| 验证测试 | 功耗测量、续航验证、极端条件测试 |

电源设计是嵌入式系统可靠运行的基石，值得投入足够的时间和精力。
