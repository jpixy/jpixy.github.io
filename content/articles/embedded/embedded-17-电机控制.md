# 嵌入式电机控制

电机控制是工业自动化、机器人、无人机、电动汽车的核心技术。本文系统讲解各类电机的原理与控制方法。

---

## 一、电机控制概述

### 1.1 为什么要学电机控制

**应用广泛**：
- 工业自动化：机械臂、传送带、CNC
- 消费电子：无人机、扫地机器人、电动工具
- 交通工具：电动汽车、电动自行车
- 家用电器：空调压缩机、洗衣机、风扇

**技术门槛高**：
- 涉及电力电子、控制理论、嵌入式软件
- 需要理解电机物理原理
- 实时性要求高
- AI短期难以替代（需要硬件调试）

### 1.2 电机分类

| 电机类型 | 特点 | 典型应用 |
|---------|------|---------|
| 直流有刷电机 | 简单、便宜、有电刷磨损 | 玩具、简单驱动 |
| 直流无刷电机(BLDC) | 高效、长寿命、需电子换相 | 无人机、电动车 |
| 永磁同步电机(PMSM) | BLDC的高级形式，正弦驱动 | 伺服、电动汽车 |
| 步进电机 | 精确定位、开环控制 | 3D打印机、CNC |
| 交流异步电机 | 结构简单、成本低 | 工业驱动、家电 |
| 舵机 | 集成驱动和减速器 | 机器人关节、遥控模型 |

### 1.3 控制系统组成

一个典型的电机控制系统包含：

**硬件部分**：
- MCU：执行控制算法
- 功率驱动：H桥、三相逆变器
- 电流采样：检测相电流
- 位置/速度反馈：编码器、霍尔传感器
- 保护电路：过流、过压、过温保护

**软件部分**：
- PWM生成：控制功率器件
- 采样处理：电流、位置信号
- 控制算法：PID、FOC等
- 状态机：启动、运行、故障处理

## 二、直流有刷电机

### 2.1 工作原理

直流有刷电机通过电刷和换向器实现机械换相：
- 电枢（转子）通电产生磁场
- 与定子磁场相互作用产生转矩
- 换向器保证转矩方向一致

**特性方程**：
```
转速 ∝ 电压
转矩 ∝ 电流
```

### 2.2 控制方法

**调速**：
通过改变电枢电压调速，最常用PWM调压：
- PWM占空比控制平均电压
- 频率通常选择10-20kHz（超出人耳听觉）

**方向控制**：
使用H桥电路切换电流方向：
- 对角导通：正转
- 另一对角导通：反转
- 同侧导通：制动

**H桥驱动芯片**：

| 芯片 | 电压 | 电流 | 特点 |
|-----|------|------|------|
| L298N | 46V | 2A | 经典，效率低 |
| TB6612 | 15V | 1.2A | 效率高，推荐 |
| DRV8833 | 10.8V | 1.5A | 小封装，低压 |
| BTS7960 | 27V | 43A | 大电流 |

### 2.3 PID速度控制

**编码器反馈**：
使用正交编码器测量转速，闭环控制实现精确调速。

**PID控制器**：
```
输出 = Kp·误差 + Ki·∫误差dt + Kd·d(误差)/dt
```

**参数整定**：
- Kp（比例）：快速响应，过大会振荡
- Ki（积分）：消除稳态误差，过大会过冲
- Kd（微分）：抑制振荡，过大会放大噪声

**整定方法**：
1. 先将Ki、Kd设为0
2. 增大Kp直到系统开始振荡
3. 将Kp减小到振荡临界值的60%
4. 逐渐增加Ki消除稳态误差
5. 如有需要，少量增加Kd

## 三、步进电机

### 3.1 工作原理

步进电机每收到一个脉冲信号，转子转动一个固定角度（步距角）。

**类型**：
- 永磁式：步距角大（7.5°-15°），转矩小
- 混合式：步距角小（1.8°），转矩大，最常用
- 可变磁阻式：较少使用

**常见规格**：
- 42步进（NEMA 17）：1.8°步距角，200步/圈，3D打印机常用
- 57步进（NEMA 23）：更大转矩，CNC常用
- 86步进（NEMA 34）：大型设备

### 3.2 驱动方式

**整步驱动**：
每次激励一相或两相，步距角为标称值。
- 单相激励：A→B→C→D
- 双相激励：AB→BC→CD→DA（转矩更大）

**半步驱动**：
交替使用单相和双相激励，步距角减半。

**细分驱动**：
通过控制各相电流的比例，实现更小的步距角。
- 1/4细分：1.8° → 0.45°
- 1/8细分：1.8° → 0.225°
- 1/16、1/32...更高细分

细分的好处：
- 更高的定位精度
- 更平滑的运动
- 减少振动和噪声

### 3.3 驱动器选型

| 驱动器 | 电压 | 电流 | 细分 | 特点 |
|-------|------|------|------|------|
| A4988 | 35V | 2A | 1/16 | 入门级，便宜 |
| DRV8825 | 45V | 2.5A | 1/32 | A4988升级版 |
| TMC2209 | 29V | 2A | 1/256 | 静音，推荐 |
| TB6600 | 42V | 4A | 1/16 | 大电流，外置 |

**TMC系列优势**：
- StealthChop：静音模式，几乎无噪声
- SpreadCycle：高动态响应
- StallGuard：无传感器失步检测

### 3.4 控制策略

**开环控制**：
步进电机的天然优势，不需要反馈也能精确定位。
- 计算目标位置需要的脉冲数
- 按加减速曲线发送脉冲
- 前提：不失步

**失步问题**：
负载过大或加速过快会导致失步（丢步）。

**预防失步**：
- 合理设计加减速曲线（S曲线或梯形）
- 留足转矩余量
- 使用闭环步进（带编码器）

**加减速规划**：
- 梯形加减速：简单，但有冲击
- S曲线加减速：平滑，无冲击，推荐

### 3.5 步进vs伺服

| 维度 | 步进电机 | 伺服电机 |
|-----|---------|---------|
| 控制复杂度 | 简单，开环即可 | 复杂，需闭环 |
| 成本 | 低 | 高 |
| 转矩特性 | 低速转矩大，高速下降 | 全速恒转矩 |
| 定位精度 | 靠细分，一般1/256 | 靠编码器，更高 |
| 过载能力 | 无法过载，会失步 | 可短时过载 |
| 适用场景 | 低速、定位、成本敏感 | 高速、高精度、高动态 |

## 四、无刷直流电机(BLDC)

### 4.1 工作原理

BLDC使用电子换相代替机械换向器：
- 定子：三相绑组，产生旋转磁场
- 转子：永磁体，被磁场拉动旋转
- 换相：根据转子位置切换绕组通电顺序

**与有刷电机的对比**：

| 维度 | 有刷电机 | 无刷电机 |
|-----|---------|---------|
| 换相方式 | 机械（电刷） | 电子 |
| 维护 | 电刷需更换 | 几乎免维护 |
| 效率 | 75-80% | 85-95% |
| 寿命 | 较短 | 长 |
| 成本 | 低 | 较高 |
| 控制 | 简单 | 复杂 |

### 4.2 换相方式

**六步换相（方波驱动）**：
- 每个时刻只有两相导通
- 根据霍尔传感器确定位置
- 每60°电角度换相一次
- 简单易实现，有转矩波动

**霍尔传感器位置**：
三个霍尔传感器相隔120°电角度，产生8种组合（6种有效）。

| 霍尔状态(HCB) | 导通相 | 备注 |
|--------------|--------|------|
| 101 | A+B- | 第1步 |
| 100 | A+C- | 第2步 |
| 110 | B+C- | 第3步 |
| 010 | B+A- | 第4步 |
| 011 | C+A- | 第5步 |
| 001 | C+B- | 第6步 |

**无传感器控制**：
通过检测未导通相的反电动势（BEMF）过零点来确定位置。
- 省去霍尔传感器成本
- 低速时BEMF太小，难以检测
- 启动需要特殊策略（开环启动后切闭环）

### 4.3 驱动电路

**三相逆变器**：
由6个功率开关（通常是MOSFET或IGBT）组成，上下桥臂各3个。

**死区时间**：
同一桥臂的上下开关不能同时导通（会短路），需要插入死区时间。

**集成驱动芯片**：

| 芯片 | 电压 | 电流 | 特点 |
|-----|------|------|------|
| L6234 | 52V | 4A | 经典三相驱动 |
| DRV8313 | 60V | 3.5A | 集成驱动+保护 |
| MP6540 | 28V | 5A | 高集成度 |
| STSPIN32F0 | 45V | 15A | 内置MCU |

### 4.4 速度控制

**占空比调节**：
通过PWM占空比控制平均电压，从而控制转速。

**速度闭环**：
使用霍尔信号或编码器测量实际转速，PID控制器调节占空比。

## 五、FOC矢量控制

### 5.1 为什么需要FOC

六步换相的问题：
- 转矩波动大（约14%）
- 噪声大
- 效率受限

FOC（Field Oriented Control，磁场定向控制）解决这些问题：
- 转矩波动极小
- 运行平滑安静
- 效率更高
- 低速性能好

### 5.2 FOC核心思想

**目标**：让定子电流产生的磁场始终与转子磁场垂直90°，此时转矩最大。

**实现方法**：
将三相交流量变换到与转子同步旋转的坐标系中，变成直流量控制。

**坐标变换**：
1. Clarke变换：三相(ABC) → 两相静止(αβ)
2. Park变换：两相静止(αβ) → 两相旋转(dq)

**dq坐标系含义**：
- d轴（直轴）：与转子磁场同向，励磁分量
- q轴（交轴）：与转子磁场垂直，转矩分量

**控制策略**：
- 控制id=0：不需要额外励磁
- 控制iq：直接控制转矩

### 5.3 FOC控制流程

```
速度给定 → 速度PI → iq给定 ─┐
                              ├→ dq电流PI → 逆Park → SVPWM → 逆变器 → 电机
id给定(0) ────────────────────┘
                 ↑
                 │ dq电流反馈
                 │
电流采样 → Clarke → Park ──────┘
                 ↑
                 │ 转子位置
                 │
         编码器/观测器
```

### 5.4 关键技术环节

**电流采样**：
- 三电阻法：每相串联采样电阻
- 双电阻法：只采样两相，第三相计算
- 单电阻法：在直流母线采样，需要时机配合

**位置检测**：
- 编码器：最精确，成本高
- 霍尔传感器：精度有限，需插值
- 无传感器观测器：滑模观测器、MRAS等

**SVPWM（空间矢量PWM）**：
比传统SPWM更高效地利用直流母线电压，提高约15%的电压利用率。

**弱磁控制**：
高速时反电动势接近供电电压，通过注入负id实现弱磁，扩展调速范围。

### 5.5 FOC实现资源

**硬件要求**：
- 支持高级定时器（互补PWM、死区）
- 足够的ADC（同步采样更好）
- 足够的运算能力（控制周期通常10-20kHz）

**常用MCU**：
- STM32G4：专为电机控制设计，内置运放、比较器
- STM32F4：性能足够，资源丰富
- TI C2000：专业电机控制DSP

**开源资源**：
- SimpleFOC：Arduino友好，适合学习
- MCSDK（ST官方）：完整的FOC库
- ODrive：开源高性能BLDC控制器

## 六、电机控制实践要点

### 6.1 调试步骤

**建议顺序**：
1. 确认电源和功率电路正常
2. 测试PWM输出波形
3. 开环测试：固定占空比，电机能转
4. 测试反馈信号：编码器/霍尔
5. 闭环测试：速度环、位置环

### 6.2 常见问题

| 问题 | 可能原因 |
|-----|---------|
| 电机抖动不转 | 相序错误、换相表错误 |
| 高频啸叫 | PWM频率太低、死区设置问题 |
| 转速不稳 | PID参数不合适、采样噪声 |
| 过流保护 | 启动电流过大、短路 |
| 发热严重 | 效率低、过载 |

### 6.3 安全考虑

**硬件保护**：
- 过流保护：采样电阻+比较器
- 过压保护：TVS二极管
- 过温保护：温度传感器

**软件保护**：
- 电流限幅
- 堵转检测
- 故障状态机

## 总结

电机控制知识体系：

| 电机类型 | 控制方法 | 适用场景 |
|---------|---------|---------|
| 有刷直流 | PWM + PID | 简单驱动 |
| 步进电机 | 脉冲 + 加减速曲线 | 精确定位 |
| BLDC六步 | 霍尔换相 + PWM | 风机、简单无刷应用 |
| BLDC/PMSM FOC | 矢量控制 | 高性能驱动 |

电机控制是嵌入式领域的"硬核"方向，需要软硬件结合、理论实践并重。建议从有刷电机开始，逐步深入到步进和无刷，最终挑战FOC算法。
