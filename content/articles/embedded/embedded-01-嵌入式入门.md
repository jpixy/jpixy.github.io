# 嵌入式开发入门指南

嵌入式系统无处不在：智能手表、汽车ECU、工业控制器、智能家居设备。本文为零基础入门者提供系统性的学习路线。

---

## 一、什么是嵌入式系统

### 1.1 嵌入式系统定义

| 特征 | 说明 |
|-----|------|
| 专用性 | 为特定任务设计，非通用计算 |
| 资源受限 | CPU/内存/存储有限 |
| 实时性 | 需要在规定时间内响应 |
| 可靠性 | 7x24运行，容错要求高 |
| 低功耗 | 电池供电场景常见 |

### 1.2 嵌入式 vs 通用计算

| 维度 | 嵌入式系统 | 通用计算机 |
|-----|-----------|-----------|
| 操作系统 | 裸机/RTOS/嵌入式Linux | Windows/macOS/Linux |
| 存储 | KB~GB级别 | GB~TB级别 |
| 启动时间 | 毫秒~秒级 | 秒~分钟级 |
| 用户交互 | 有限或无 | 丰富 |
| 开发方式 | 交叉编译 | 本地编译 |

### 1.3 嵌入式系统分类

| 类别 | 典型代表 | 应用场景 |
|-----|---------|---------|
| 8位MCU | ATmega328 (Arduino) | 简单控制、传感器 |
| 32位MCU | STM32, ESP32 | 物联网、工业控制 |
| MPU | ARM Cortex-A, 树莓派 | 复杂应用、图形处理 |
| DSP | TI C6000系列 | 信号处理、音视频 |
| FPGA | Xilinx, Altera | 高速并行处理 |

## 二、硬件基础知识

### 2.1 电子学基础

#### 基本概念

| 概念 | 单位 | 说明 |
|-----|------|------|
| 电压 (V) | 伏特 | 电势差，驱动电流流动 |
| 电流 (I) | 安培 | 电荷流动速率 |
| 电阻 (R) | 欧姆 | 阻碍电流流动 |
| 功率 (P) | 瓦特 | P = V × I |

#### 欧姆定律

```
V = I × R
I = V / R
R = V / I
```

#### 常用元器件

| 元器件 | 符号 | 作用 |
|--------|-----|------|
| 电阻 | R | 限流、分压 |
| 电容 | C | 滤波、储能、耦合 |
| 电感 | L | 滤波、储能 |
| 二极管 | D | 整流、保护 |
| LED | LED | 发光指示 |
| 晶体管 | Q | 开关、放大 |

### 2.2 数字电路基础

#### 逻辑电平

| 标准 | 低电平 | 高电平 | 典型应用 |
|-----|--------|--------|---------|
| TTL | 0~0.8V | 2~5V | 传统5V系统 |
| CMOS 3.3V | 0~0.8V | 2~3.3V | 现代MCU |
| CMOS 1.8V | 0~0.6V | 1.2~1.8V | 低功耗设备 |

#### 基本逻辑门

| 门 | 功能 | 真值表概述 |
|---|------|-----------|
| AND | 与 | 全1出1 |
| OR | 或 | 有1出1 |
| NOT | 非 | 取反 |
| XOR | 异或 | 不同出1 |
| NAND | 与非 | AND取反 |

### 2.3 MCU核心组成

```
┌─────────────────────────────────────────────────┐
│                    MCU芯片                       │
│  ┌─────────┐  ┌─────────┐  ┌─────────────────┐  │
│  │   CPU   │  │  Flash  │  │      SRAM       │  │
│  │  Core   │  │ (程序)  │  │     (数据)      │  │
│  └────┬────┘  └─────────┘  └─────────────────┘  │
│       │                                          │
│  ┌────┴────────────────────────────────────┐    │
│  │              总线 (Bus)                  │    │
│  └────┬────────┬────────┬────────┬────────┘    │
│       │        │        │        │              │
│  ┌────┴───┐┌───┴───┐┌───┴───┐┌───┴───┐        │
│  │  GPIO  ││ Timer ││  ADC  ││ UART  │ ...    │
│  └────────┘└───────┘└───────┘└───────┘        │
└─────────────────────────────────────────────────┘
```

| 组件 | 功能 |
|-----|------|
| CPU Core | 执行指令 |
| Flash | 存储程序代码（非易失） |
| SRAM | 运行时数据存储（易失） |
| GPIO | 通用输入输出引脚 |
| Timer | 定时、计数、PWM |
| ADC | 模拟信号转数字 |
| UART/SPI/I2C | 通信外设 |

## 四、开发环境搭建

### 4.1 Arduino开发环境

#### 安装步骤

1. 下载 Arduino IDE: https://www.arduino.cc/en/software
2. 安装并启动
3. 选择开发板: Tools → Board → Arduino Uno
4. 选择端口: Tools → Port → COMx (Windows) 或 /dev/ttyUSBx (Linux)

#### Linux额外配置

```bash
# 添加用户到dialout组（访问串口权限）
sudo usermod -a -G dialout $USER
# 重新登录生效
```

### 4.2 STM32开发环境

#### 方案一：STM32CubeIDE（官方推荐）

1. 下载: https://www.st.com/stm32cubeide
2. 集成了代码生成、编译、调试
3. 免费，跨平台

#### 方案二：VS Code + PlatformIO

```bash
# 安装VS Code后，安装PlatformIO扩展
# 支持Arduino、STM32、ESP32等多平台
```

#### 方案三：命令行工具链

```bash
# Ubuntu/Debian
sudo apt install gcc-arm-none-eabi openocd gdb-multiarch

# 编译
arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -o main.elf main.c

# 烧录
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
        -c "program main.elf verify reset exit"
```

### 4.3 调试器/烧录器

| 工具 | 支持芯片 | 价格 | 说明 |

## 五、第一个程序：点亮LED

### 5.1 Arduino版本

```cpp
// 经典的Blink程序
void setup() {
    // 初始化数字引脚13为输出模式
    pinMode(13, OUTPUT);
}

void loop() {
    digitalWrite(13, HIGH);  // 点亮LED
    delay(1000);             // 等待1秒
    digitalWrite(13, LOW);   // 熄灭LED
    delay(1000);             // 等待1秒
}
```

#### 代码解析

| 函数 | 作用 |
|-----|------|
| `setup()` | 初始化，只运行一次 |
| `loop()` | 主循环，反复执行 |
| `pinMode(pin, mode)` | 设置引脚模式 |
| `digitalWrite(pin, value)` | 设置引脚电平 |
| `delay(ms)` | 延时（毫秒） |

### 5.2 STM32 HAL版本

```c
#include "stm32f1xx_hal.h"

int main(void) {
    HAL_Init();
    SystemClock_Config();
    
    // 使能GPIOC时钟
    __HAL_RCC_GPIOC_CLK_ENABLE();
    
    // 配置PC13为推挽输出
    GPIO_InitTypeDef GPIO_InitStruct = {0};
    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
    
    while (1) {
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
        HAL_Delay(500);
    }
}
```

### 5.3 STM32 寄存器版本（理解底层）

```c
#include "stm32f10x.h"

int main(void) {
    // 1. 使能GPIOC时钟
    RCC->APB2ENR |= RCC_APB2ENR_IOPCEN;
    
    // 2. 配置PC13为推挽输出，最大速度2MHz
    GPIOC->CRH &= ~(0xF << 20);  // 清除PC13配置
    GPIOC->CRH |= (0x2 << 20);   // 输出模式，2MHz
    
    while (1) {
        GPIOC->ODR ^= (1 << 13);  // 翻转PC13
        for (int i = 0; i < 500000; i++);  // 简单延时
    }
}
```

## 六、核心概念速览

### 6.1 GPIO操作

| 模式 | 说明 | 典型应用 |
|-----|------|---------|
| 输入浮空 | 高阻态，易受干扰 | 外部有上下拉时 |
| 输入上拉 | 默认高电平 | 按键检测 |
| 输入下拉 | 默认低电平 | 按键检测 |
| 推挽输出 | 可输出高/低电平 | 驱动LED |
| 开漏输出 | 只能拉低，需外部上拉 | I2C总线 |
| 复用功能 | 由外设控制 | UART TX/RX |

### 6.2 中断

```c
// 中断的基本流程
void EXTI0_IRQHandler(void) {
    if (EXTI->PR & EXTI_PR_PR0) {
        // 处理中断事件
        handle_button_press();
        
        // 清除中断标志
        EXTI->PR = EXTI_PR_PR0;
    }
}
```

| 中断类型 | 触发源 | 典型应用 |
|---------|--------|---------|
| 外部中断 | GPIO电平变化 | 按键、传感器 |
| 定时器中断 | 定时器溢出 | 周期任务 |
| 串口中断 | 数据收发 | 通信处理 |
| DMA中断 | 传输完成 | 大数据传输 |

### 6.3 定时器

| 功能 | 说明 |
|-----|------|
| 定时中断 | 周期性触发中断 |
| PWM输出 | 脉宽调制，控制电机/LED亮度 |
| 输入捕获 | 测量脉冲宽度/频率 |
| 编码器模式 | 读取旋转编码器 |

```c
// PWM配置示例（伪代码）
Timer_Init(TIM2, 1000);         // 1kHz PWM频率
Timer_PWM_Init(TIM2_CH1, 50);   // 50%占空比
Timer_Start(TIM2);
```

### 6.4 ADC模数转换

```c
// 读取模拟传感器值
uint16_t adc_value = ADC_Read(ADC1, CHANNEL_0);

// 转换为电压（12位ADC，3.3V参考电压）
float voltage = (adc_value / 4095.0) * 3.3;
```

## 八、常见问题

### 8.1 程序无法烧录

| 问题 | 解决方案 |
|-----|---------|
| 端口未识别 | 安装驱动，检查USB线 |
| 权限不足 | Linux添加dialout组 |
| 芯片被锁 | 使用SWD/JTAG解锁 |
| Boot配置错误 | 检查BOOT0/BOOT1引脚 |

### 8.2 程序运行异常

| 问题 | 可能原因 |
|-----|---------|
| LED不亮 | 引脚配置错误，极性接反 |
| 串口乱码 | 波特率不匹配 |
| 程序卡死 | 死循环，中断未处理 |
| 复位重启 | 看门狗未喂狗，电源不稳 |

## 九、下一步学习

完成入门后，建议按以下顺序深入：

1. **通信协议**: UART、SPI、I2C、CAN
2. **中断与DMA**: 高效数据处理
3. **低功耗设计**: 电池供电应用
4. **RTOS**: FreeRTOS任务管理
5. **项目实战**: 完整产品开发

## 总结

嵌入式开发的核心是**理解硬件、掌握软硬件交互**。与纯软件开发不同，你需要：

- 会看原理图和数据手册
- 理解时序和电气特性
- 具备基本的调试能力

这正是嵌入式开发的护城河——AI可以帮你写代码，但无法替你接示波器调信号。

祝你入门顺利！
