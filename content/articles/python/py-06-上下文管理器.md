# py Python的上下文管理器ContextManager

### **Python 的上下文管理器（Context Manager）**
上下文管理器是一种用于封装资源分配和释放的协议，它允许你在进入和退出代码块时自动执行特定的操作。上下文管理器的核心是两个特殊方法：`__enter__()` 和 `__exit__()`。

#### **1. **`__enter__()`** 方法**
+ 在进入上下文管理器的代码块时被调用。
+ 它的返回值通常会被赋值给 `with` 语句中指定的变量（如果有）。
+ 通常用于初始化资源（如打开文件、建立数据库连接等）。

#### **2. **`__exit__()`** 方法**
+ 在退出上下文管理器的代码块时被调用，无论是正常退出还是因为异常退出。
+ 它的参数包括异常类型、异常值和异常的回溯信息（如果有的话）。
+ 通常用于清理资源（如关闭文件、释放数据库连接等）。
+ 如果 `__exit__()` 方法返回 `True`，则会捕获异常，不会传播；否则，异常会继续传播。

### `with`** 语句**
`with` 语句是 Python 中用于简化资源管理的语法糖。它通过上下文管理器协议，确保资源在使用完毕后被正确释放。

#### **语法**
```python
with context_manager as variable:
    # 代码块
```

+ `context_manager` 是一个实现了上下文管理器协议的对象。
+ `variable` 是可选的，用于接收 `__enter__()` 方法的返回值。

### **上下文管理器与 **`with`** 的关系**
上下文管理器是 `with` 语句的基础。`with` 语句通过上下文管理器的 `__enter__()` 和 `__exit__()` 方法来管理资源的分配和释放。

### **示例：文件操作**
```python
class FileContextManager:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode
        self.file = None

    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.file.close()
        if exc_type:
            print(f"Exception occurred: {exc_val}")
        return False  # 让异常继续传播

with FileContextManager("example.txt", "w") as file:
    file.write("Hello, World!")
```

#### **解释**
1. **进入上下文管理器**：
    - `__enter__()` 方法被调用，打开文件并返回文件对象。
    - 文件对象被赋值给 `file`。
2. **执行代码块**：
    - 在 `with` 代码块中，可以操作文件对象。
3. **退出上下文管理器**：
    - `__exit__()` 方法被调用，关闭文件。
    - 如果代码块中发生异常，`__exit__()` 方法会捕获异常并处理。

### **内置上下文管理器**
Python 提供了一些内置的上下文管理器，例如：

+ **文件对象**：

```python
with open("example.txt", "r") as file:
    content = file.read()
```

+ **线程锁**：

```python
import threading

lock = threading.Lock()
with lock:
    # 临界区代码
    pass
```

### **使用 **`contextlib`** 模块**
Python 的 `contextlib` 模块提供了一些工具，用于更方便地创建上下文管理器。

#### `contextlib.contextmanager`
通过装饰器实现上下文管理器：

```python
from contextlib import contextmanager

@contextmanager
def file_context_manager(filename, mode):
    file = open(filename, mode)
    try:
        yield file
    finally:
        file.close()

with file_context_manager("example.txt", "w") as file:
    file.write("Hello, World!")
```

#### `contextlib.closing`
用于确保对象的 `close()` 方法被调用：

```python
from contextlib import closing

with closing(open("example.txt", "r")) as file:
    content = file.read()
```

### **总结**
+ **上下文管理器** 是一个协议，通过 `__enter__()` 和 `__exit__()` 方法管理资源的分配和释放。
+ `with`** 语句** 是 Python 的语法糖，用于简化上下文管理器的使用。
+ 使用上下文管理器可以确保资源在使用完毕后被正确释放，避免资源泄漏。
+ Python 提供了内置的上下文管理器（如文件对象、线程锁）和 `contextlib` 模块，方便开发者实现自定义的上下文管理器。
