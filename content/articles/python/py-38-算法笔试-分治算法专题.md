## 概述

分治算法是将问题分解为若干规模较小的相同问题，递归求解后合并结果的算法策略。本文详细介绍分治思想及其经典应用。

# 一、分治算法基础

## 1.1 核心思想

```python
"""
分治算法三步骤：

1. 分解（Divide）
   - 将原问题分解为若干规模较小的子问题
   - 子问题与原问题形式相同

2. 解决（Conquer）
   - 递归求解子问题
   - 当子问题足够小时直接求解（基本情况）

3. 合并（Combine）
   - 将子问题的解合并为原问题的解

分治适用条件：
- 问题可以分解为规模较小的相同问题
- 子问题的解可以合并为原问题的解
- 子问题相互独立（无重叠，否则用DP）
"""

def divide_and_conquer(problem):
    """
    分治算法模板
    """
    # 基本情况
    if is_base_case(problem):
        return base_solution(problem)
    
    # 分解
    subproblems = divide(problem)
    
    # 递归求解
    subsolutions = [divide_and_conquer(sub) for sub in subproblems]
    
    # 合并
    return combine(subsolutions)
```

## 1.2 时间复杂度分析

```python
"""
主定理（Master Theorem）

对于递归式 T(n) = aT(n/b) + f(n)，其中：
- a: 子问题数量
- b: 子问题规模缩小因子
- f(n): 分解和合并的代价

设 c = log_b(a)，则：

情况1: 若 f(n) = O(n^(c-ε))，则 T(n) = Θ(n^c)
情况2: 若 f(n) = Θ(n^c)，则 T(n) = Θ(n^c × log n)
情况3: 若 f(n) = Ω(n^(c+ε))，则 T(n) = Θ(f(n))

常见例子：
- 二分查找: T(n) = T(n/2) + O(1) → O(log n)
- 归并排序: T(n) = 2T(n/2) + O(n) → O(n log n)
- 快速排序(平均): T(n) = 2T(n/2) + O(n) → O(n log n)
- 快速排序(最坏): T(n) = T(n-1) + O(n) → O(n²)
"""
```

# 二、归并排序

## 2.1 基础实现

```python
def merge_sort(nums: list) -> list:
    """
    归并排序
    
    参数:
        nums: List[int] - 待排序数组
    返回:
        List[int] - 排序后的数组
    
    时间复杂度: O(n log n) - 稳定
    空间复杂度: O(n) - 需要额外空间
    
    特点:
        - 稳定排序
        - 适合链表排序
        - 适合外部排序
    """
    if len(nums) <= 1:
        return nums
    
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    
    return merge(left, right)


def merge(left: list, right: list) -> list:
    """
    合并两个有序数组
    
    时间复杂度: O(n)
    """
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    
    return result


# 原地归并排序（减少空间）
def merge_sort_inplace(nums: list, left: int = 0, right: int = None) -> None:
    """
    原地归并排序
    
    空间复杂度: O(n) 用于临时数组，O(log n) 用于递归栈
    """
    if right is None:
        right = len(nums) - 1
    
    if left >= right:
        return
    
    mid = (left + right) // 2
    merge_sort_inplace(nums, left, mid)
    merge_sort_inplace(nums, mid + 1, right)
    merge_inplace(nums, left, mid, right)


def merge_inplace(nums: list, left: int, mid: int, right: int) -> None:
    """
    原地合并
    """
    temp = nums[left:right + 1]
    i, j = 0, mid - left + 1
    k = left
    
    while i <= mid - left and j <= right - left:
        if temp[i] <= temp[j]:
            nums[k] = temp[i]
            i += 1
        else:
            nums[k] = temp[j]
            j += 1
        k += 1
    
    while i <= mid - left:
        nums[k] = temp[i]
        i += 1
        k += 1
    
    while j <= right - left:
        nums[k] = temp[j]
        j += 1
        k += 1
```

## 2.2 归并排序应用

```python
# 1. 计算逆序对
def count_inversions(nums: list) -> int:
    """
    LeetCode 剑指Offer 51. 数组中的逆序对
    
    逆序对: i < j 且 nums[i] > nums[j]
    
    思路: 在归并过程中统计逆序对
    """
    def merge_count(nums, left, mid, right):
        temp = nums[left:right + 1]
        i, j = 0, mid - left + 1
        k = left
        count = 0
        
        while i <= mid - left and j <= right - left:
            if temp[i] <= temp[j]:
                nums[k] = temp[i]
                i += 1
            else:
                nums[k] = temp[j]
                j += 1
                # 统计逆序对：左边剩余的元素都与当前右边元素构成逆序对
                count += mid - left - i + 1
            k += 1
        
        while i <= mid - left:
            nums[k] = temp[i]
            i += 1
            k += 1
        
        while j <= right - left:
            nums[k] = temp[j]
            j += 1
            k += 1
        
        return count
    
    def sort_count(nums, left, right):
        if left >= right:
            return 0
        
        mid = (left + right) // 2
        count = sort_count(nums, left, mid)
        count += sort_count(nums, mid + 1, right)
        count += merge_count(nums, left, mid, right)
        
        return count
    
    nums = nums.copy()  # 不修改原数组
    return sort_count(nums, 0, len(nums) - 1)


# 2. 计算右侧小于当前元素的个数
def count_smaller(nums: list) -> list:
    """
    LeetCode 315. Count of Smaller Numbers After Self
    
    返回每个元素右边比它小的元素个数
    """
    n = len(nums)
    result = [0] * n
    # (值, 原始索引)
    indexed = [(num, i) for i, num in enumerate(nums)]
    
    def merge_count(arr, left, mid, right):
        temp = arr[left:right + 1]
        i, j = 0, mid - left + 1
        k = left
        
        while i <= mid - left and j <= right - left:
            if temp[i][0] <= temp[j][0]:
                # 左边元素入结果，右边已入结果的都比它小
                result[temp[i][1]] += j - (mid - left + 1)
                arr[k] = temp[i]
                i += 1
            else:
                arr[k] = temp[j]
                j += 1
            k += 1
        
        while i <= mid - left:
            result[temp[i][1]] += j - (mid - left + 1)
            arr[k] = temp[i]
            i += 1
            k += 1
        
        while j <= right - left:
            arr[k] = temp[j]
            j += 1
            k += 1
    
    def sort_count(arr, left, right):
        if left >= right:
            return
        mid = (left + right) // 2
        sort_count(arr, left, mid)
        sort_count(arr, mid + 1, right)
        merge_count(arr, left, mid, right)
    
    sort_count(indexed, 0, n - 1)
    return result


# 3. 合并K个有序链表
def merge_k_lists(lists: list):
    """
    LeetCode 23. Merge k Sorted Lists
    
    分治合并
    """
    if not lists:
        return None
    
    def merge_two(l1, l2):
        dummy = ListNode(0)
        curr = dummy
        while l1 and l2:
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        curr.next = l1 or l2
        return dummy.next
    
    def merge_range(left, right):
        if left == right:
            return lists[left]
        mid = (left + right) // 2
        l = merge_range(left, mid)
        r = merge_range(mid + 1, right)
        return merge_two(l, r)
    
    return merge_range(0, len(lists) - 1)
```

# 三、快速排序

## 3.1 基础实现

```python
import random

def quick_sort(nums: list) -> list:
    """
    快速排序（返回新数组）
    
    时间复杂度: 平均O(n log n)，最坏O(n²)
    空间复杂度: O(log n) 递归栈
    
    特点:
        - 不稳定排序
        - 原地排序
        - 实际应用中常最快
    """
    if len(nums) <= 1:
        return nums
    
    pivot = random.choice(nums)  # 随机选择pivot
    
    left = [x for x in nums if x < pivot]
    mid = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]
    
    return quick_sort(left) + mid + quick_sort(right)


def quick_sort_inplace(nums: list, left: int = 0, right: int = None) -> None:
    """
    快速排序（原地）
    
    使用Lomuto分区方案
    """
    if right is None:
        right = len(nums) - 1
    
    if left >= right:
        return
    
    # 随机选择pivot并交换到末尾
    pivot_idx = random.randint(left, right)
    nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
    
    pivot = nums[right]
    i = left
    
    for j in range(left, right):
        if nums[j] < pivot:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
    
    nums[i], nums[right] = nums[right], nums[i]
    
    quick_sort_inplace(nums, left, i - 1)
    quick_sort_inplace(nums, i + 1, right)


def quick_sort_hoare(nums: list, left: int = 0, right: int = None) -> None:
    """
    快速排序（Hoare分区方案）
    
    双指针从两端向中间移动，交换次数更少
    """
    if right is None:
        right = len(nums) - 1
    
    if left >= right:
        return
    
    pivot = nums[(left + right) // 2]
    i, j = left, right
    
    while i <= j:
        while nums[i] < pivot:
            i += 1
        while nums[j] > pivot:
            j -= 1
        if i <= j:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1
    
    quick_sort_hoare(nums, left, j)
    quick_sort_hoare(nums, i, right)
```

## 3.2 三路快排

```python
def quick_sort_3way(nums: list, left: int = 0, right: int = None) -> None:
    """
    三路快排：处理大量重复元素
    
    将数组分为三部分：< pivot, == pivot, > pivot
    
    特别适合有大量重复元素的情况
    """
    if right is None:
        right = len(nums) - 1
    
    if left >= right:
        return
    
    # 随机选择pivot
    pivot_idx = random.randint(left, right)
    nums[left], nums[pivot_idx] = nums[pivot_idx], nums[left]
    pivot = nums[left]
    
    # lt: 小于pivot的右边界
    # gt: 大于pivot的左边界
    lt = left
    gt = right
    i = left + 1
    
    while i <= gt:
        if nums[i] < pivot:
            nums[lt], nums[i] = nums[i], nums[lt]
            lt += 1
            i += 1
        elif nums[i] > pivot:
            nums[gt], nums[i] = nums[i], nums[gt]
            gt -= 1
        else:
            i += 1
    
    # 递归排序小于和大于的部分
    quick_sort_3way(nums, left, lt - 1)
    quick_sort_3way(nums, gt + 1, right)
```

## 3.3 快速选择

```python
def quick_select(nums: list, k: int) -> int:
    """
    快速选择：找第k小的元素
    
    LeetCode 215. Kth Largest Element in an Array（找第k大）
    
    时间复杂度: 平均O(n)，最坏O(n²)
    空间复杂度: O(1)
    """
    def partition(left, right):
        # 随机选择pivot
        pivot_idx = random.randint(left, right)
        nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
        
        pivot = nums[right]
        i = left
        
        for j in range(left, right):
            if nums[j] < pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        
        nums[i], nums[right] = nums[right], nums[i]
        return i
    
    left, right = 0, len(nums) - 1
    
    while left <= right:
        pivot_idx = partition(left, right)
        
        if pivot_idx == k - 1:
            return nums[pivot_idx]
        elif pivot_idx < k - 1:
            left = pivot_idx + 1
        else:
            right = pivot_idx - 1
    
    return -1


def find_kth_largest(nums: list, k: int) -> int:
    """
    找第k大的元素
    """
    return quick_select(nums.copy(), len(nums) - k + 1)
```

# 四、其他分治应用

## 4.1 最大子数组和（分治）

```python
def max_subarray_dc(nums: list) -> int:
    """
    LeetCode 53. Maximum Subarray（分治解法）
    
    分治思路：
    - 最大子数组要么完全在左半部分
    - 要么完全在右半部分
    - 要么跨越中点
    
    时间复杂度: O(n log n)
    """
    def max_crossing(left, mid, right):
        # 从中点向左扩展
        left_sum = float('-inf')
        curr = 0
        for i in range(mid, left - 1, -1):
            curr += nums[i]
            left_sum = max(left_sum, curr)
        
        # 从中点向右扩展
        right_sum = float('-inf')
        curr = 0
        for i in range(mid + 1, right + 1):
            curr += nums[i]
            right_sum = max(right_sum, curr)
        
        return left_sum + right_sum
    
    def dc(left, right):
        if left == right:
            return nums[left]
        
        mid = (left + right) // 2
        left_max = dc(left, mid)
        right_max = dc(mid + 1, right)
        cross_max = max_crossing(left, mid, right)
        
        return max(left_max, right_max, cross_max)
    
    return dc(0, len(nums) - 1)
```

## 4.2 求幂

```python
def my_pow(x: float, n: int) -> float:
    """
    LeetCode 50. Pow(x, n)
    
    快速幂（分治）
    
    时间复杂度: O(log n)
    """
    if n == 0:
        return 1
    if n < 0:
        return 1 / my_pow(x, -n)
    
    half = my_pow(x, n // 2)
    
    if n % 2 == 0:
        return half * half
    else:
        return half * half * x


# 迭代版本
def my_pow_iter(x: float, n: int) -> float:
    if n < 0:
        x = 1 / x
        n = -n
    
    result = 1
    while n > 0:
        if n & 1:
            result *= x
        x *= x
        n >>= 1
    
    return result
```

## 4.3 构建二叉树

```python
def build_tree(preorder: list, inorder: list):
    """
    LeetCode 105. Construct Binary Tree from Preorder and Inorder Traversal
    
    分治构建二叉树
    """
    if not preorder or not inorder:
        return None
    
    # 前序的第一个是根
    root_val = preorder[0]
    root = TreeNode(root_val)
    
    # 在中序中找到根的位置
    mid = inorder.index(root_val)
    
    # 递归构建左右子树
    root.left = build_tree(preorder[1:mid + 1], inorder[:mid])
    root.right = build_tree(preorder[mid + 1:], inorder[mid + 1:])
    
    return root


# 优化版本（使用索引避免切片）
def build_tree_optimized(preorder: list, inorder: list):
    inorder_map = {val: i for i, val in enumerate(inorder)}
    
    def build(pre_left, pre_right, in_left, in_right):
        if pre_left > pre_right:
            return None
        
        root_val = preorder[pre_left]
        root = TreeNode(root_val)
        
        in_root = inorder_map[root_val]
        left_size = in_root - in_left
        
        root.left = build(pre_left + 1, pre_left + left_size, 
                          in_left, in_root - 1)
        root.right = build(pre_left + left_size + 1, pre_right, 
                           in_root + 1, in_right)
        
        return root
    
    return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

## 4.4 最近点对

```python
def closest_pair(points: list) -> float:
    """
    最近点对问题
    
    分治解法：O(n log n)
    """
    import math
    
    def distance(p1, p2):
        return math.sqrt((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)
    
    def brute_force(pts):
        min_dist = float('inf')
        for i in range(len(pts)):
            for j in range(i + 1, len(pts)):
                min_dist = min(min_dist, distance(pts[i], pts[j]))
        return min_dist
    
    def closest_in_strip(strip, d):
        min_dist = d
        strip.sort(key=lambda p: p[1])  # 按y排序
        
        for i in range(len(strip)):
            for j in range(i + 1, len(strip)):
                if strip[j][1] - strip[i][1] >= min_dist:
                    break
                min_dist = min(min_dist, distance(strip[i], strip[j]))
        
        return min_dist
    
    def dc(pts):
        n = len(pts)
        if n <= 3:
            return brute_force(pts)
        
        mid = n // 2
        mid_x = pts[mid][0]
        
        dl = dc(pts[:mid])
        dr = dc(pts[mid:])
        d = min(dl, dr)
        
        # 找出中间带内的点
        strip = [p for p in pts if abs(p[0] - mid_x) < d]
        
        return min(d, closest_in_strip(strip, d))
    
    points_sorted = sorted(points, key=lambda p: p[0])
    return dc(points_sorted)
```

## 4.5 大整数乘法

```python
def karatsuba(x: int, y: int) -> int:
    """
    Karatsuba大整数乘法
    
    传统乘法: O(n²)
    Karatsuba: O(n^1.585)
    
    原理:
    x = a * 10^m + b
    y = c * 10^m + d
    x * y = ac * 10^(2m) + ((a+b)(c+d) - ac - bd) * 10^m + bd
    """
    # 基本情况
    if x < 10 or y < 10:
        return x * y
    
    # 计算位数
    n = max(len(str(x)), len(str(y)))
    m = n // 2
    
    # 分解
    high1, low1 = divmod(x, 10**m)
    high2, low2 = divmod(y, 10**m)
    
    # 递归计算
    z0 = karatsuba(low1, low2)
    z2 = karatsuba(high1, high2)
    z1 = karatsuba(low1 + high1, low2 + high2) - z0 - z2
    
    return z2 * 10**(2*m) + z1 * 10**m + z0
```

## 总结

### 分治算法对比

| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|------------|------------|--------|
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) 平均 | O(log n) | 不稳定 |
| 快速选择 | O(n) 平均 | O(1) | - |
| 最近点对 | O(n log n) | O(n) | - |

### 应用场景

| 问题 | 分治策略 |
|------|----------|
| 排序 | 归并排序、快速排序 |
| 选择第k元素 | 快速选择 |
| 逆序对 | 归并排序中统计 |
| 最大子数组 | 分解+跨越中点 |
| 构建二叉树 | 递归构建左右子树 |

### 关键记忆

1. **归并排序**：稳定，适合链表和外部排序
2. **快速排序**：随机选pivot避免最坏情况
3. **三路快排**：处理大量重复元素
4. **快速选择**：O(n)找第k元素
5. **逆序对**：归并排序变形
