# Python 装饰器和类装饰器详解
装饰器是Python中一种强大的语法特性，它允许你在不修改原函数或类代码的情况下，为其添加额外的功能。装饰器本质上是一个可调用对象（函数或类），它接受一个函数或类作为参数并返回一个新的函数或类。

## 一、函数装饰器
### 1. 基本函数装饰器
函数装饰器是最常见的装饰器形式，它用于修饰函数。

```python
def simple_decorator(func):
    def wrapper():
        print("Before function call")
        func()
        print("After function call")
    return wrapper

@simple_decorator
def say_hello():
    print("Hello!")

say_hello()
```

输出：

```
Before function call
Hello!
After function call
```

### 2. 带参数的函数装饰器
装饰器也可以接受参数，这需要再嵌套一层函数：

```python
def repeat(num_times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(num_times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(num_times=3)
def greet(name):
    print(f"Hello {name}")

greet("Alice")
```

输出：

```
Hello Alice
Hello Alice
Hello Alice
```

### 3. 保留原函数的元信息
使用装饰器后，原函数的`__name__`、`__doc__`等元信息会被替换为装饰器内部函数的。可以使用`functools.wraps`来保留这些信息：

```python
from functools import wraps

def logged(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__} with {args}, {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@logged
def add(x, y):
    """Add two numbers"""
    return x + y

print(add.__name__)  # 输出 'add'
print(add.__doc__)   # 输出 'Add two numbers'
```

## 二、类装饰器
### 1. 用类作为装饰器
类也可以作为装饰器，只需要实现`__call__`方法：

```python
class Timer:
    def __init__(self, func):
        self.func = func
    
    def __call__(self, *args, **kwargs):
        import time
        start = time.time()
        result = self.func(*args, **kwargs)
        end = time.time()
        print(f"Executed in {end - start:.4f} seconds")
        return result

@Timer
def long_running_func():
    import time
    time.sleep(2)

long_running_func()
```

### 2. 带参数的类装饰器
类装饰器也可以接受参数：

```python
class DecoratorWithArgs:
    def __init__(self, *args, **kwargs):
        self.args = args
        self.kwargs = kwargs
    
    def __call__(self, func):
        def wrapper(*args, **kwargs):
            print(f"Decorator args: {self.args}, {self.kwargs}")
            return func(*args, **kwargs)
        return wrapper

@DecoratorWithArgs(1, 2, 3, debug=True)
def test_function(a, b):
    print(f"Function called with {a}, {b}")

test_function(10, 20)
```

## 三、装饰类的装饰器
装饰器不仅可以装饰函数，还可以装饰类：

### 1. 基本类装饰器
```python
def add_methods(cls):
    cls.new_method = lambda self: print("This is a new method")
    return cls

@add_methods
class MyClass:
    pass

obj = MyClass()
obj.new_method()  # 输出 "This is a new method"
```

### 2. 更复杂的类装饰器
```python
def singleton(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    def __init__(self):
        print("Database created")

d1 = Database()
d2 = Database()
print(d1 is d2)  # 输出 True
```

## 四、装饰器的堆叠
可以同时使用多个装饰器，它们会从下往上依次执行：

```python
def decorator1(func):
    def wrapper():
        print("Decorator 1")
        func()
    return wrapper

def decorator2(func):
    def wrapper():
        print("Decorator 2")
        func()
    return wrapper

@decorator1
@decorator2
def my_function():
    print("Original function")

my_function()
```

输出：

```
Decorator 1
Decorator 2
Original function
```

## 五、内置装饰器
Python提供了一些有用的内置装饰器：

1. `@property` - 将方法转换为属性
2. `@classmethod` - 定义类方法
3. `@staticmethod` - 定义静态方法
4. `@functools.lru_cache` - 缓存函数结果
5. `@dataclasses.dataclass` - 自动生成特殊方法的类装饰器

## 六、实际应用场景
1. **日志记录**：自动记录函数调用信息
2. **性能测试**：测量函数执行时间
3. **权限验证**：检查用户是否有权限执行函数
4. **缓存**：存储函数结果避免重复计算
5. **事务处理**：确保数据库操作要么全部成功要么全部失败
6. **路由注册**：如Flask中的路由装饰器

装饰器是Python中非常强大的工具，合理使用可以使代码更加简洁、可读和可维护。
