## Goroutine

### 基本使用

```go
// 启动goroutine
go func() {
    fmt.Println("Hello from goroutine")
}()

// 带参数
go func(msg string) {
    fmt.Println(msg)
}("Hello")

// 等待goroutine完成
var wg sync.WaitGroup
wg.Add(1)
go func() {
    defer wg.Done()
    // 工作
}()
wg.Wait()
```

### Goroutine特性

- **轻量**：初始栈约2KB（线程约1MB）
- **可扩展**：栈按需增长
- **M:N调度**：M个goroutine运行在N个OS线程上
- **无返回值**：通过channel传递结果

### 调度器

```go
// GOMAXPROCS设置使用的CPU核心数
runtime.GOMAXPROCS(4)

// 让出执行权
runtime.Gosched()

// 获取goroutine数量
runtime.NumGoroutine()
```

## Channel

### 基本操作

```go
// 创建channel
ch := make(chan int)       // 无缓冲
ch := make(chan int, 10)   // 有缓冲，容量10

// 发送和接收
ch <- 42      // 发送
value := <-ch // 接收
value, ok := <-ch // 接收，ok表示channel是否关闭

// 关闭channel
close(ch)

// 只读/只写channel
func send(ch chan<- int) { ch <- 1 }  // 只写
func recv(ch <-chan int) { <-ch }     // 只读
```

### 无缓冲 vs 有缓冲

**无缓冲（同步）**：
```go
ch := make(chan int)
// 发送阻塞直到有接收者
// 接收阻塞直到有发送者
```

**有缓冲（异步）**：
```go
ch := make(chan int, 3)
ch <- 1  // 不阻塞（缓冲区未满）
ch <- 2  // 不阻塞
ch <- 3  // 不阻塞
ch <- 4  // 阻塞（缓冲区满）
```

### 遍历channel

```go
// range遍历
for value := range ch {
    fmt.Println(value)
}
// range会在channel关闭后退出

// 检测关闭
value, ok := <-ch
if !ok {
    // channel已关闭
}
```

## Select

### 基本使用

```go
select {
case v := <-ch1:
    fmt.Println("received from ch1:", v)
case ch2 <- 42:
    fmt.Println("sent to ch2")
case <-time.After(time.Second):
    fmt.Println("timeout")
default:
    fmt.Println("no communication ready")
}
```

### 超时控制

```go
select {
case result := <-ch:
    fmt.Println(result)
case <-time.After(3 * time.Second):
    fmt.Println("timeout")
}
```

### 非阻塞操作

```go
select {
case msg := <-ch:
    fmt.Println(msg)
default:
    fmt.Println("no message available")
}
```

### 退出信号

```go
done := make(chan struct{})

go func() {
    for {
        select {
        case <-done:
            return
        default:
            // 工作
        }
    }
}()

// 发送退出信号
close(done)
```

## sync包

### Mutex

```go
var mu sync.Mutex
var count int

func increment() {
    mu.Lock()
    defer mu.Unlock()
    count++
}
```

### RWMutex

```go
var rwmu sync.RWMutex
var data map[string]string

func read(key string) string {
    rwmu.RLock()
    defer rwmu.RUnlock()
    return data[key]
}

func write(key, value string) {
    rwmu.Lock()
    defer rwmu.Unlock()
    data[key] = value
}
```

### WaitGroup

```go
var wg sync.WaitGroup

for i := 0; i < 10; i++ {
    wg.Add(1)
    go func(id int) {
        defer wg.Done()
        fmt.Println("Worker", id)
    }(i)
}

wg.Wait()  // 等待所有goroutine完成
```

### Once

```go
var once sync.Once
var instance *Singleton

func GetInstance() *Singleton {
    once.Do(func() {
        instance = &Singleton{}
    })
    return instance
}
```

### Cond

```go
var mu sync.Mutex
var cond = sync.NewCond(&mu)
var ready bool

// 等待方
mu.Lock()
for !ready {
    cond.Wait()
}
// 使用数据
mu.Unlock()

// 通知方
mu.Lock()
ready = true
cond.Signal()    // 通知一个
// cond.Broadcast()  // 通知所有
mu.Unlock()
```

### Pool

```go
var pool = sync.Pool{
    New: func() interface{} {
        return make([]byte, 1024)
    },
}

// 获取
buf := pool.Get().([]byte)

// 使用后归还
pool.Put(buf)
```

### Map

```go
var m sync.Map

m.Store("key", "value")
value, ok := m.Load("key")
m.Delete("key")
m.Range(func(key, value interface{}) bool {
    fmt.Println(key, value)
    return true  // 继续遍历
})
```

## Context

### 基本使用

```go
import "context"

// 创建context
ctx := context.Background()
ctx := context.TODO()

// 带取消
ctx, cancel := context.WithCancel(context.Background())
defer cancel()

// 带超时
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()

// 带截止时间
ctx, cancel := context.WithDeadline(context.Background(), time.Now().Add(time.Hour))
defer cancel()

// 带值
ctx := context.WithValue(parentCtx, "key", "value")
value := ctx.Value("key")
```

### 传递与检查

```go
func worker(ctx context.Context) {
    for {
        select {
        case <-ctx.Done():
            fmt.Println("cancelled:", ctx.Err())
            return
        default:
            // 继续工作
        }
    }
}
```

### 请求链路

```go
func handler(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()
    
    // 设置超时
    ctx, cancel := context.WithTimeout(ctx, 5*time.Second)
    defer cancel()
    
    // 传递给下游
    result, err := doWork(ctx)
}
```

## 并发模式

### Worker Pool

```go
func workerPool(numWorkers int, jobs <-chan int, results chan<- int) {
    var wg sync.WaitGroup
    
    for i := 0; i < numWorkers; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for job := range jobs {
                results <- process(job)
            }
        }()
    }
    
    wg.Wait()
    close(results)
}
```

### Pipeline

```go
func generator(nums ...int) <-chan int {
    out := make(chan int)
    go func() {
        for _, n := range nums {
            out <- n
        }
        close(out)
    }()
    return out
}

func square(in <-chan int) <-chan int {
    out := make(chan int)
    go func() {
        for n := range in {
            out <- n * n
        }
        close(out)
    }()
    return out
}

// 使用
nums := generator(1, 2, 3, 4)
squares := square(nums)
for result := range squares {
    fmt.Println(result)
}
```

### Fan-out/Fan-in

```go
// Fan-out: 多个goroutine从同一channel读取
func fanOut(in <-chan int, n int) []<-chan int {
    outs := make([]<-chan int, n)
    for i := 0; i < n; i++ {
        outs[i] = worker(in)
    }
    return outs
}

// Fan-in: 多个channel合并到一个
func fanIn(channels ...<-chan int) <-chan int {
    var wg sync.WaitGroup
    out := make(chan int)
    
    for _, ch := range channels {
        wg.Add(1)
        go func(c <-chan int) {
            defer wg.Done()
            for v := range c {
                out <- v
            }
        }(ch)
    }
    
    go func() {
        wg.Wait()
        close(out)
    }()
    
    return out
}
```

### 限流

```go
// 令牌桶
limiter := make(chan struct{}, 10)

for task := range tasks {
    limiter <- struct{}{}  // 获取令牌
    go func(t Task) {
        defer func() { <-limiter }()  // 释放令牌
        process(t)
    }(task)
}
```

## 常见问题

### 数据竞争

```go
// 检测
go run -race main.go

// 错误示例
var count int
go func() { count++ }()
go func() { count++ }()

// 正确：使用锁或atomic
var count int64
atomic.AddInt64(&count, 1)
```

### Goroutine泄漏

```go
// 错误：goroutine永远阻塞
ch := make(chan int)
go func() {
    result := <-ch  // 永远阻塞
    fmt.Println(result)
}()
// 忘记发送或关闭channel

// 正确：使用context取消
ctx, cancel := context.WithTimeout(context.Background(), time.Second)
defer cancel()

go func() {
    select {
    case result := <-ch:
        fmt.Println(result)
    case <-ctx.Done():
        return
    }
}()
```

## 总结

| 组件 | 用途 |
|------|------|
| goroutine | 轻量级并发执行单元 |
| channel | goroutine间通信 |
| select | 多路复用 |
| sync.Mutex | 互斥锁 |
| sync.WaitGroup | 等待组 |
| context | 取消、超时、值传递 |

**Go并发哲学**：
> "Don't communicate by sharing memory; share memory by communicating."
> 不要通过共享内存来通信，而要通过通信来共享内存。
