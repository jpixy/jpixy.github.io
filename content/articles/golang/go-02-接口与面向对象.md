## 方法

### 方法定义

```go
type Rectangle struct {
    Width, Height float64
}

// 值接收者
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// 指针接收者
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}

// 使用
rect := Rectangle{10, 5}
area := rect.Area()  // 50
rect.Scale(2)        // 修改rect
```

### 值接收者 vs 指针接收者

| 类型 | 特点 | 使用场景 |
|------|------|----------|
| 值接收者 | 方法接收副本 | 小对象、不需修改 |
| 指针接收者 | 方法可修改原值 | 大对象、需要修改 |

**规则**：如果类型有指针接收者方法，所有方法都应用指针接收者。

### 任意类型的方法

```go
type MyInt int

func (m MyInt) Double() MyInt {
    return m * 2
}

var x MyInt = 5
x.Double()  // 10
```

## 接口

### 接口定义

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 接口组合
type ReadWriter interface {
    Reader
    Writer
}
```

### 隐式实现

```go
// 无需显式声明实现接口
type File struct {}

func (f *File) Read(p []byte) (n int, err error) {
    // 实现
    return len(p), nil
}

func (f *File) Write(p []byte) (n int, err error) {
    // 实现
    return len(p), nil
}

// File自动实现了Reader、Writer、ReadWriter接口
var rw ReadWriter = &File{}
```

### 空接口

```go
// 可以存储任何值
var x interface{}
x = 42
x = "hello"
x = []int{1, 2, 3}

// any是interface{}的别名（Go 1.18+）
var y any = "hello"
```

## 类型断言与类型转换

### 类型断言

```go
var x interface{} = "hello"

// 带检查的类型断言
s, ok := x.(string)
if ok {
    fmt.Println(s)
}

// 不带检查（失败会panic）
s := x.(string)
```

### 类型Switch

```go
func describe(x interface{}) {
    switch v := x.(type) {
    case int:
        fmt.Printf("int: %d\n", v)
    case string:
        fmt.Printf("string: %s\n", v)
    case bool:
        fmt.Printf("bool: %t\n", v)
    default:
        fmt.Printf("unknown type: %T\n", v)
    }
}
```

## 组合代替继承

### 结构体嵌入

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() {
    fmt.Println("...")
}

type Dog struct {
    Animal  // 嵌入
    Breed string
}

func (d Dog) Speak() {
    fmt.Println("Woof!")
}

d := Dog{Animal{"Buddy"}, "Labrador"}
d.Name     // 直接访问嵌入字段
d.Speak()  // 调用Dog的方法
d.Animal.Speak()  // 调用嵌入类型的方法
```

### 接口嵌入

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Closer interface {
    Close() error
}

type ReadCloser interface {
    Reader
    Closer
}
```

## 常用接口

### Stringer

```go
type Stringer interface {
    String() string
}

type Person struct {
    Name string
    Age  int
}

func (p Person) String() string {
    return fmt.Sprintf("%s (%d years)", p.Name, p.Age)
}

p := Person{"Alice", 30}
fmt.Println(p)  // Alice (30 years)
```

### error

```go
type error interface {
    Error() string
}

type MyError struct {
    Code    int
    Message string
}

func (e *MyError) Error() string {
    return fmt.Sprintf("[%d] %s", e.Code, e.Message)
}
```

### io.Reader和io.Writer

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 使用
func Copy(dst io.Writer, src io.Reader) (int64, error)
```

### sort.Interface

```go
type Interface interface {
    Len() int
    Less(i, j int) bool
    Swap(i, j int)
}

type ByAge []Person

func (a ByAge) Len() int           { return len(a) }
func (a ByAge) Less(i, j int) bool { return a[i].Age < a[j].Age }
func (a ByAge) Swap(i, j int)      { a[i], a[j] = a[j], a[i] }

sort.Sort(ByAge(people))
```

## 接口设计原则

### 小接口

```go
// 好：小而专注
type Reader interface {
    Read(p []byte) (n int, err error)
}

// 差：大而杂
type FileSystem interface {
    Read(...)
    Write(...)
    Delete(...)
    List(...)
    // ...太多方法
}
```

### 接口由使用者定义

```go
// 在使用的地方定义接口，而非实现的地方
package consumer

type DataSource interface {
    GetData() []byte
}

func Process(ds DataSource) {
    data := ds.GetData()
    // ...
}
```

### 接受接口，返回具体类型

```go
// 好
func NewService(repo Repository) *Service {
    return &Service{repo: repo}
}

// 差
func NewService(repo Repository) ServiceInterface {
    return &Service{repo: repo}
}
```

## 接口内部实现

### 接口值的组成

```go
// 接口值 = (类型, 值)
var r io.Reader

var f *os.File
r = f  // (type: *os.File, value: nil)

// nil接口 vs 持有nil值的接口
var r1 io.Reader         // nil接口
var r2 io.Reader = (*os.File)(nil)  // 非nil接口，但值是nil

r1 == nil  // true
r2 == nil  // false！
```

### 类型元数据

```go
// 运行时获取类型信息
var x interface{} = 42
fmt.Printf("%T\n", x)  // int

// reflect包深入操作
t := reflect.TypeOf(x)
v := reflect.ValueOf(x)
```

## 泛型接口（Go 1.18+）

### 类型参数接口

```go
type Ordered interface {
    ~int | ~int8 | ~int16 | ~int32 | ~int64 |
    ~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 |
    ~float32 | ~float64 | ~string
}

func Min[T Ordered](a, b T) T {
    if a < b {
        return a
    }
    return b
}
```

### comparable约束

```go
func Contains[T comparable](slice []T, target T) bool {
    for _, v := range slice {
        if v == target {
            return true
        }
    }
    return false
}
```

## 总结

| 概念 | 说明 |
|------|------|
| 方法 | 绑定到类型的函数 |
| 接口 | 方法集合，隐式实现 |
| 空接口 | 可存储任何值 |
| 类型断言 | 从接口提取具体类型 |
| 组合 | 代替继承的方式 |
| 小接口 | Go的设计哲学 |

Go通过接口和组合实现了灵活的面向对象编程，没有类继承但更加简洁。
