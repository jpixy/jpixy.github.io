## 导数

### 定义

导数衡量函数在某点的变化率。

f'(x) = lim[h→0] (f(x+h) - f(x)) / h

几何上是切线的斜率。

### 基本求导法则

**常数**：(c)' = 0

**幂函数**：(xⁿ)' = nxⁿ⁻¹

**指数**：(eˣ)' = eˣ，(aˣ)' = aˣ ln(a)

**对数**：(ln x)' = 1/x

**三角**：(sin x)' = cos x，(cos x)' = -sin x

### 复合函数求导

**链式法则**：(f(g(x)))' = f'(g(x)) × g'(x)

从外到内逐层求导，乘起来。

### 乘法与除法

**乘法**：(uv)' = u'v + uv'

**除法**：(u/v)' = (u'v - uv') / v²

## 偏导数与梯度

### 偏导数

多元函数对某一变量的导数，其他变量视为常数。

∂f/∂x 表示f对x的偏导数。

### 梯度

所有偏导数组成的向量。

∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)

梯度指向函数增长最快的方向，其模是最大变化率。

### 方向导数

函数沿任意方向的变化率。

Dᵤf = ∇f · u，u是单位方向向量。

### 梯度与等值线

梯度垂直于等值线（等高线）。

沿等值线移动，函数值不变，变化率为零。

---

## 积分

### 不定积分

导数的逆运算。

∫f(x)dx = F(x) + C，其中F'(x) = f(x)

### 定积分

曲线下的面积。

∫ₐᵇ f(x)dx = F(b) - F(a)

### 多重积分

计算多维空间中的体积或更高维的"体积"。

双重积分：∫∫ f(x,y) dxdy

积分顺序可交换（Fubini定理，条件满足时）。

### 换元与分部

**换元积分**：u = g(x)，∫f(g(x))g'(x)dx = ∫f(u)du

**分部积分**：∫udv = uv - ∫vdu

## 优化

### 极值条件

**必要条件**：在极值点，梯度为零（∇f = 0）。

**充分条件**：需要检验二阶导数（Hessian矩阵）。

### 一元函数

f''(x) > 0：极小值
f''(x) < 0：极大值
f''(x) = 0：需进一步分析

### 多元函数

Hessian矩阵：H = [∂²f/∂xᵢ∂xⱼ]

**正定**（所有特征值 > 0）：极小值
**负定**（所有特征值 < 0）：极大值
**不定**：鞍点

### 凸函数

凸函数的局部最小值就是全局最小值。

判断：Hessian矩阵半正定。

凸优化问题保证找到全局最优。

### 约束优化

**拉格朗日乘子法**：将约束优化转化为无约束优化。

max f(x) s.t. g(x) = 0

L(x, λ) = f(x) - λg(x)

解∇L = 0。

**KKT条件**：不等式约束的推广。

## 梯度下降

### 基本思想

沿负梯度方向迭代更新参数，逐步逼近最小值。

x_{n+1} = xₙ - α∇f(xₙ)

α是学习率。

### 学习率选择

太大：可能越过最小值，发散。

太小：收敛太慢。

自适应学习率方法：Adam、RMSprop。

### 变种

**批量梯度下降**：使用全部数据计算梯度。

**随机梯度下降（SGD）**：每次使用一个样本。

**小批量梯度下降**：折中，使用一小批样本。

### 动量

累积历史梯度，加速收敛，减少振荡。

v = βv + ∇f
x = x - αv

## 泰勒展开

### 公式

函数在某点的多项式近似。

f(x) ≈ f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + ...

### 一阶近似

f(x + Δx) ≈ f(x) + f'(x)Δx

线性近似，梯度下降的理论基础。

### 二阶近似

f(x + Δx) ≈ f(x) + f'(x)Δx + f''(x)Δx²/2

牛顿法使用二阶信息加速收敛。

### 多元泰勒展开

f(x + Δx) ≈ f(x) + ∇f(x)·Δx + Δx'HΔx/2

H是Hessian矩阵。

## 机器学习中的应用

### 损失函数最小化

训练就是最小化损失函数，梯度下降是主要方法。

### 反向传播

链式法则计算神经网络中每个参数的梯度。

### 正则化

L2正则化对应梯度增加权重衰减项。

### 牛顿法与拟牛顿法

使用二阶信息加速收敛。

拟牛顿法（如BFGS）近似Hessian矩阵，减少计算量。

## 总结

| 概念 | 要点 |
|------|------|
| 导数 | 变化率，切线斜率 |
| 梯度 | 偏导数向量，最快增长方向 |
| 极值 | 梯度为零，Hessian判定 |
| 凸函数 | 局部最优即全局最优 |
| 梯度下降 | 沿负梯度迭代 |
| 泰勒展开 | 多项式近似 |

微积分是优化算法的数学基础。理解梯度和Hessian的含义是理解机器学习优化过程的关键。
