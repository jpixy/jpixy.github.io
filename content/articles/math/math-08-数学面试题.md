## 概率论

### 条件概率与贝叶斯

**问题**：一种疾病发病率1%，检测准确率99%（敏感性和特异性都是99%）。检测阳性时，实际患病的概率是多少？

**解答**：使用贝叶斯定理。

P(病|阳) = P(阳|病)P(病) / P(阳)
= P(阳|病)P(病) / [P(阳|病)P(病) + P(阳|无病)P(无病)]
= 0.99×0.01 / [0.99×0.01 + 0.01×0.99]
= 0.5

即使检测准确率很高，低发病率下阳性预测值也只有50%。

### 期望与方差

**问题**：掷一枚公平骰子，期望和方差是多少？

**解答**：

期望E[X] = (1+2+3+4+5+6)/6 = 3.5

方差Var(X) = E[X²] - (E[X])²
E[X²] = (1+4+9+16+25+36)/6 = 91/6
Var(X) = 91/6 - 12.25 = 35/12 ≈ 2.92

### 独立与不相关

**问题**：独立和不相关有什么区别？

**解答**：

不相关：Cov(X,Y) = 0，线性关系为零。

独立：任何函数的关系都为零，P(X,Y) = P(X)P(Y)。

独立一定不相关，不相关不一定独立。

例外：联合正态分布时，不相关等价于独立。

## 线性代数

### 特征值的意义

**问题**：特征值和特征向量的几何意义是什么？

**解答**：

特征向量是在线性变换下方向不变（或反向）的向量。

特征值是对应的拉伸因子。

例如：旋转矩阵在实数域无特征向量；缩放矩阵的任何向量都是特征向量。

### SVD的应用

**问题**：SVD有哪些应用？

**解答**：

1. **降维**：保留最大奇异值对应的分量
2. **推荐系统**：矩阵分解发现潜在因子
3. **图像压缩**：低秩近似
4. **伪逆**：解病态方程组
5. **PCA**：协方差矩阵的特征分解等价于数据矩阵的SVD

### 矩阵秩

**问题**：为什么满秩方阵可逆？

**解答**：

满秩意味着列向量线性无关，张成整个空间。

任何向量b都可以表示为列向量的线性组合，Ax = b有唯一解。

等价条件：行列式非零、特征值都非零、零空间只有零向量。

## 微积分与优化

### 梯度下降为什么有效

**问题**：梯度下降为什么能找到最小值？

**解答**：

泰勒展开一阶近似：f(x+Δx) ≈ f(x) + ∇f·Δx

要使f减小，需要∇f·Δx < 0。

当Δx = -α∇f时，∇f·Δx = -α||∇f||² < 0（α > 0）。

沿负梯度方向是下降最快的方向。

### 凸函数

**问题**：为什么凸函数好优化？

**解答**：

凸函数的任何局部最小值都是全局最小值。

不会陷入非全局的局部最优。

证明：假设存在局部最小x*和更小的全局最小x，则x*和x连线上的点应该更小（凸性），与x*是局部最小矛盾。

### 拉格朗日乘子

**问题**：拉格朗日乘子法的直觉是什么？

**解答**：

在约束曲面上，最优点处目标函数梯度与约束梯度平行。

否则可以沿约束曲面移动使目标函数改进。

λ是平行系数，表示约束放松时目标函数的改进率。

## 信息论

### 交叉熵为什么用于分类

**问题**：为什么分类问题用交叉熵而不是MSE？

**解答**：

1. **概率解释**：交叉熵对应最大似然估计
2. **梯度性质**：交叉熵+softmax的梯度形式简洁，不会饱和
3. **MSE问题**：sigmoid+MSE在预测错误且置信时梯度很小

### 互信息

**问题**：互信息和相关系数有什么区别？

**解答**：

相关系数只衡量线性关系。

互信息衡量任何依赖关系（包括非线性）。

互信息为零等价于独立；相关系数为零只是不相关。

## 统计学

### 最大似然估计

**问题**：正态分布数据的均值和方差的MLE是什么？

**解答**：

对数似然：l = -n/2 log(2πσ²) - Σ(xᵢ-μ)²/(2σ²)

对μ求导令其为零：μ̂ = Σxᵢ/n = 样本均值

对σ²求导令其为零：σ̂² = Σ(xᵢ-μ̂)²/n

注意：方差的MLE除以n而非n-1，是有偏估计。

### p值的误解

**问题**：p值=0.03意味着什么？

**解答**：

正确理解：如果H₀为真，观察到当前或更极端结果的概率是3%。

常见误解：
- ❌ H₀为真的概率是3%
- ❌ 有97%把握H₁为真
- ❌ 重复实验97%会得到相同结论

p值不告诉你效应大小或实际意义。

## 机器学习相关

### 偏差-方差权衡

**问题**：解释偏差-方差权衡。

**解答**：

**偏差**：模型对真实关系的系统性偏离。简单模型偏差高。

**方差**：模型对训练数据变化的敏感度。复杂模型方差高。

期望误差 = 偏差² + 方差 + 噪声

增加模型复杂度减少偏差但增加方差。最优点在中间某处。

### 过拟合检测

**问题**：如何判断模型过拟合？

**解答**：

训练误差很低但验证/测试误差高。

两者差距（泛化差距）大是过拟合的标志。

学习曲线：随着数据增加，训练误差上升、验证误差下降并趋于收敛。

## 证明题

### 方差公式

**问题**：证明Var(X) = E[X²] - (E[X])²

**解答**：

Var(X) = E[(X - E[X])²]
= E[X² - 2X·E[X] + (E[X])²]
= E[X²] - 2E[X]·E[X] + (E[X])²
= E[X²] - (E[X])²

### 条件熵不增

**问题**：证明H(X|Y) ≤ H(X)

**解答**：

I(X;Y) = H(X) - H(X|Y) ≥ 0

因为互信息非负（可由KL散度非负性证明）。

所以H(X|Y) ≤ H(X)。

给定信息不会增加不确定性。

## 面试技巧

### 概念解释

用简单语言解释，从直觉出发，举例说明。

不要只背定义，展示理解深度。

### 计算题

写出步骤，边算边解释。

数值结果做合理性检查。

### 不会的问题

承认不知道比瞎猜好。

说出你知道的相关内容，展示思考过程。
