## 概率基础

### 基本概念

**随机实验**：结果不确定但所有可能结果已知的实验。

**样本空间**：所有可能结果的集合，记为Ω。

**事件**：样本空间的子集。

**概率**：事件发生可能性的度量，取值0到1。

### 概率公理

1. 非负性：P(A) ≥ 0
2. 规范性：P(Ω) = 1
3. 可加性：互斥事件概率可加

### 基本运算

**补事件**：P(A') = 1 - P(A)

**并事件**：P(A∪B) = P(A) + P(B) - P(A∩B)

**交事件**：P(A∩B) = P(A)P(B|A)

---

## 条件概率

### 定义

在事件B已发生的条件下，事件A发生的概率。

P(A|B) = P(A∩B) / P(B)，其中P(B) > 0

### 链式法则

P(A∩B∩C) = P(A)P(B|A)P(C|A∩B)

可推广到任意多个事件。

### 全概率公式

若B₁, B₂, ..., Bₙ是样本空间的划分，则：

P(A) = Σᵢ P(A|Bᵢ)P(Bᵢ)

将复杂事件的概率分解为条件概率的加权和。

### 独立性

事件A和B独立当且仅当P(A∩B) = P(A)P(B)。

等价于P(A|B) = P(A)，B的发生不影响A的概率。

---

## 贝叶斯定理

### 公式

P(A|B) = P(B|A)P(A) / P(B)

从先验概率P(A)更新到后验概率P(A|B)。

### 各项含义

**P(A)**：先验概率，观察到证据之前对A的信念。

**P(B|A)**：似然，给定A时观察到B的概率。

**P(A|B)**：后验概率，观察到B后对A的更新信念。

**P(B)**：证据，可通过全概率公式计算。

### 应用

**分类问题**：朴素贝叶斯分类器。

**医学诊断**：根据检测结果更新患病概率。

**垃圾邮件过滤**：根据词汇判断邮件是否为垃圾。

**参数估计**：贝叶斯推断，结合先验知识。

---

## 随机变量

### 定义

随机变量是从样本空间到实数的映射。

**离散随机变量**：取有限或可数个值。

**连续随机变量**：取实数区间上的值。

### 离散分布

**概率质量函数（PMF）**：P(X = x)，每个值的概率。

**累积分布函数（CDF）**：F(x) = P(X ≤ x)。

### 连续分布

**概率密度函数（PDF）**：f(x)，P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx。

单点概率P(X = x) = 0。

**CDF**：F(x) = ∫₋∞ˣ f(t)dt，PDF是CDF的导数。

---

## 常见分布

### 离散分布

**伯努利分布**：单次二元试验，参数p（成功概率）。

**二项分布**：n次独立伯努利试验中成功的次数。

**泊松分布**：单位时间内事件发生次数，参数λ（平均发生率）。适合稀有事件。

**几何分布**：首次成功前失败的次数。

### 连续分布

**均匀分布**：区间上等概率分布。

**正态分布**：钟形曲线，参数μ（均值）和σ（标准差）。中心极限定理使其无处不在。

**指数分布**：事件间隔时间，参数λ。无记忆性。

**Gamma分布**：多个指数分布之和。

**Beta分布**：概率的概率分布，贝叶斯先验。

## 期望与方差

### 期望（均值）

随机变量的平均值。

离散：E[X] = Σ xᵢ P(X = xᵢ)
连续：E[X] = ∫ x f(x) dx

**线性性**：E[aX + bY] = aE[X] + bE[Y]，总是成立。

### 方差

衡量随机变量偏离均值的程度。

Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²

**标准差**：方差的平方根，与X单位相同。

### 协方差

衡量两个随机变量的线性相关程度。

Cov(X, Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]

正值表示正相关，负值表示负相关，零表示不相关。

### 相关系数

标准化的协方差，取值-1到1。

ρ(X, Y) = Cov(X, Y) / (σₓ σᵧ)

±1表示完全线性相关，0表示不相关。

## 多维随机变量

### 联合分布

两个或多个随机变量的共同分布。

**联合PMF/PDF**：所有变量取特定值的概率。

### 边缘分布

从联合分布得到单个变量的分布。

对其他变量求和（离散）或积分（连续）。

### 条件分布

给定一个变量的值，另一个变量的分布。

f(y|x) = f(x,y) / f(x)

### 独立随机变量

X和Y独立当且仅当f(x,y) = f(x)f(y)。

独立随机变量的期望乘积等于期望的乘积。

独立随机变量的方差可加。

---

## 大数定律与中心极限定理

### 大数定律

样本均值随样本量增加收敛于期望。

**弱大数定律**：概率收敛。

**强大数定律**：几乎必然收敛。

### 中心极限定理

大量独立同分布随机变量的和近似正态分布。

无论原始分布是什么，只要方差有限。

这解释了为什么正态分布在自然界和社会中普遍存在。

## 总结

| 概念 | 要点 |
|------|------|
| 条件概率 | P(A|B) = P(A∩B)/P(B) |
| 贝叶斯 | 后验 ∝ 似然 × 先验 |
| 期望 | 平均值，线性性 |
| 方差 | 离散程度，E[X²] - (E[X])² |
| 正态分布 | 中心极限定理 |
| 大数定律 | 样本均值收敛于期望 |

概率论是理解不确定性的数学工具。机器学习、统计推断、决策理论都建立在概率论基础上。
