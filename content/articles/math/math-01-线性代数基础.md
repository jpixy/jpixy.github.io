## 向量

### 基本概念

向量是有序的数值列表，表示空间中的点或方向。

n维向量有n个分量，可以看作n维空间中的一个点或从原点出发的箭头。

### 向量运算

**加法**：对应分量相加。几何上是向量首尾相接。

**数乘**：每个分量乘以标量。几何上是拉伸或缩短向量。

**点积（内积）**：对应分量相乘后求和。结果是标量。

点积的几何意义：a·b = |a||b|cos(θ)。衡量两个向量的相似程度。

### 向量范数

向量的"长度"或"大小"的度量。

**L1范数**：分量绝对值之和。

**L2范数**：分量平方和的平方根。欧几里得距离。

**L∞范数**：分量绝对值的最大值。

### 向量的线性组合

若干向量乘以系数后相加。

向量组的所有线性组合构成的空间称为生成空间或张成空间。

### 线性无关

一组向量线性无关，当且仅当只有零系数组合才能得到零向量。

线性无关向量提供"独立"的方向信息。

## 矩阵

### 基本概念

矩阵是二维数组，m行n列的矩阵称为m×n矩阵。

矩阵可以表示线性变换，也可以存储数据（如图像）。

### 特殊矩阵

**方阵**：行数等于列数。

**单位矩阵（I）**：对角线为1，其余为0。乘以任何矩阵得到原矩阵。

**对角矩阵**：只有对角线上有非零元素。

**对称矩阵**：A = A^T，转置后不变。

**正交矩阵**：A^T A = I，列向量两两正交且单位长度。

### 矩阵运算

**加法**：对应元素相加。需要维度相同。

**数乘**：每个元素乘以标量。

**矩阵乘法**：A(m×n) × B(n×p) = C(m×p)。C[i,j]是A的第i行与B的第j列的点积。

矩阵乘法不满足交换律：AB ≠ BA（一般情况）。

**转置**：行列互换。(AB)^T = B^T A^T。

### 矩阵的秩

矩阵中线性无关的行（或列）的最大数量。

秩反映矩阵包含的"有效"信息量。

满秩方阵是可逆的。

### 矩阵求逆

只有满秩方阵才有逆矩阵。

A × A^{-1} = I

求解线性方程组Ax = b，若A可逆，则x = A^{-1}b。

## 线性变换

### 几何解释

矩阵乘法可以看作空间变换。

**旋转**：正交矩阵，保持长度和角度。

**缩放**：对角矩阵，沿坐标轴拉伸。

**剪切**：平行线保持平行，但角度改变。

**投影**：降维，将向量投影到子空间。

### 行列式

方阵的行列式是一个标量，表示线性变换对体积的缩放因子。

行列式为0表示矩阵奇异（不可逆），变换将空间压缩到更低维度。

行列式的正负表示是否改变手性（镜像翻转）。

## 特征值与特征向量

### 定义

若Av = λv，v是非零向量，则v是特征向量，λ是对应的特征值。

几何意义：在线性变换下，特征向量只是被拉伸（缩放），方向不变（或反向）。

### 求解

特征值是det(A - λI) = 0的根。

对于每个特征值，解(A - λI)v = 0得到特征向量。

### 特征分解

若A有n个线性无关的特征向量，则A = VΛV^{-1}。

V的列是特征向量，Λ是对角矩阵，对角线是特征值。

### 对称矩阵的性质

实对称矩阵的特征值都是实数。

特征向量可以选为正交的。

可以正交对角化：A = QΛQ^T，Q是正交矩阵。

### 应用

**PCA**：协方差矩阵的特征向量是主成分方向。

**图算法**：图的邻接矩阵特征值用于聚类、排序。

**微分方程**：特征值决定系统稳定性。

## 奇异值分解（SVD）

### 定义

任意矩阵A(m×n)都可以分解为：A = UΣV^T

U(m×m)：左奇异向量，正交矩阵
Σ(m×n)：对角矩阵，对角线是奇异值（非负，降序排列）
V(n×n)：右奇异向量，正交矩阵

### 与特征分解的关系

A^T A的特征向量是V，特征值是σ²。

AA^T的特征向量是U，特征值也是σ²。

### 几何解释

任何线性变换可以分解为：旋转V^T → 缩放Σ → 旋转U。

### 应用

**降维**：只保留最大的k个奇异值，得到秩k近似。

**推荐系统**：矩阵分解，发现潜在因子。

**图像压缩**：低秩近似减少存储。

**伪逆**：求解超定或欠定方程组。

## 线性方程组

### 表示

Ax = b，A是系数矩阵，x是未知数，b是常数项。

### 解的情况

**唯一解**：A满秩，b在A的列空间中。

**无解**：b不在A的列空间中。

**无穷解**：A不满秩，有自由变量。

### 求解方法

**高斯消元**：化为阶梯形，回代求解。

**LU分解**：A = LU，L下三角，U上三角。先解Ly = b，再解Ux = y。

**最小二乘**：超定方程组（方程比未知数多），最小化残差范数。

## 向量空间

### 基本概念

向量空间是满足加法和数乘封闭的集合，遵循向量公理。

**基**：线性无关且能生成整个空间的向量组。

**维度**：基向量的个数。

### 重要子空间

对于矩阵A：

**列空间**：A的列的所有线性组合。表示Ax能达到的所有b。

**零空间**：满足Ax = 0的所有x。

**行空间**：A的行的所有线性组合。

这些空间的维度关系：rank(A) + dim(null(A)) = n（列数）。

## 总结

| 概念 | 要点 |
|------|------|
| 向量 | 加法、点积、范数 |
| 矩阵 | 乘法、转置、求逆 |
| 特征值 | Av = λv，特征分解 |
| SVD | A = UΣV^T，任意矩阵 |
| 线性变换 | 旋转、缩放、投影 |
| 线性方程组 | 解的存在性与唯一性 |

线性代数是机器学习和数据分析的数学基础。矩阵运算和分解技术在各种算法中广泛应用。
