## 概述

事件驱动策略基于特定事件（财报、新闻、公告等）进行交易。这类策略试图在事件发生前后的价格调整中获利。

---

## 一、事件驱动基础

### 1.1 什么是事件驱动

```
事件驱动策略定义：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   核心思想：                                            │
│   ──────────                                            │
│   特定事件会导致资产价格变动                            │
│   在事件前后布局，获取超额收益                          │
│                                                          │
│   事件类型：                                            │
│   ──────────                                            │
│   • 定期事件：财报发布、分红除权                        │
│   • 公司事件：并购、重组、拆分                          │
│   • 市场事件：指数调整、政策发布                        │
│   • 新闻事件：重大新闻、舆情变化                        │
│                                                          │
│   策略逻辑：                                            │
│   ──────────                                            │
│   • 事件前：预测事件影响方向                            │
│   • 事件中：快速反应                                    │
│   • 事件后：利用过度反应或反应不足                      │
│                                                          │
│   与其他策略的区别：                                    │
│   ──────────                                            │
│   • 趋势/动量：基于价格模式                             │
│   • 因子投资：基于持续特征                              │
│   • 事件驱动：基于离散事件                              │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 1.2 事件驱动的优势与挑战

```
优势与挑战：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   优势：                                                │
│   ────                                                  │
│   • 逻辑清晰：事件有明确的时间和内容                    │
│   • 可预测性：定期事件时间已知                          │
│   • 高收益潜力：事件可能引发大幅波动                    │
│   • 与市场相关性低：独立于大盘走势                      │
│                                                          │
│   挑战：                                                │
│   ────                                                  │
│   • 事件结果难以预测                                    │
│   • 信息劣势（vs 内部人士）                             │
│   • 波动大，风险高                                      │
│   • 数据获取和处理复杂                                  │
│   • 竞争激烈（尤其是高频反应）                          │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

│   ──────────────                                        │
│   • EPS：每股收益 vs 预期                               │
│   • 营收：收入 vs 预期                                  │

### 2.2 财报惊喜策略

```
财报惊喜（Earnings Surprise）：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   定义：                                                │
│   ────                                                  │
│   实际业绩 vs 分析师预期的差异                          │
│   正惊喜：实际 > 预期                                   │
│   负惊喜：实际 < 预期                                   │
│                                                          │
│   标准化惊喜（SUE）：                                   │
│   ────                                                  │
│   SUE = (实际 EPS - 预期 EPS) / 标准差                  │
│                                                          │
│   市场反应规律：                                        │
│   ────                                                  │
│   • 正惊喜：股价通常上涨                                │
│   • 负惊喜：股价通常下跌                                │
│   • 反应程度与惊喜大小相关                              │
│                                                          │
│   PEAD（财报后价格漂移）：                              │
│   ────                                                  │
│   • 市场对财报信息反应不足                              │
│   • 正惊喜后股价持续上涨                                │
│   • 负惊喜后股价持续下跌                                │
│   • 持续时间：1-3 个月                                  │
│                                                          │
└─────────────────────────────────────────────────────────┘

策略示例：
```python
def earnings_surprise_strategy(data, threshold=1.0):
    """
    财报惊喜策略
    data: 包含 actual_eps, expected_eps, eps_std 的 DataFrame
    threshold: SUE 阈值
    """
    # 计算标准化惊喜
    data['sue'] = (data['actual_eps'] - data['expected_eps']) / data['eps_std']
    
    # 生成信号
    data['signal'] = 0
    data.loc[data['sue'] > threshold, 'signal'] = 1   # 正惊喜买入
    data.loc[data['sue'] < -threshold, 'signal'] = -1  # 负惊喜卖空
    
    return data
```

### 3.2 情绪分析

from transformers import pipeline

# 使用预训练模型进行情绪分析
sentiment_analyzer = pipeline("sentiment-analysis", 
                              model="ProsusAI/finbert")

def analyze_news_sentiment(headlines):
    """
    分析新闻标题情绪
    """
    results = []
    for headline in headlines:
        sentiment = sentiment_analyzer(headline)[0]
        results.append({
            'headline': headline,
            'sentiment': sentiment['label'],  # positive/negative/neutral
            'score': sentiment['score']
        })
    return results

# 示例
headlines = [
    "Apple reports record quarterly revenue, beats expectations",
    "Tesla faces production challenges amid supply chain issues",
    "Fed signals potential rate cuts in upcoming meeting"
]

sentiments = analyze_news_sentiment(headlines)
for s in sentiments:
    print(f"{s['sentiment']} ({s['score']:.2f}): {s['headline'][:50]}...")

## 五、并购套利

### 5.1 并购套利基础

```
并购套利（Merger Arbitrage）：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   原理：                                                │
│   ────                                                  │
│   宣布并购后，目标公司股价通常低于收购价                │
│   原因：交易可能失败（监管否决、融资问题等）            │
│   这个价差就是套利空间                                  │
│                                                          │
│   示例：                                                │
│   ────                                                  │
│   A 公司宣布以 $100/股收购 B 公司                       │
│   B 公司当前股价：$95                                   │
│   价差：$5（5%）                                        │
│   如果交易完成，赚 $5                                   │
│   如果交易失败，可能大亏（股价回落）                    │
│                                                          │
│   收益来源：                                            │
│   ────                                                  │
│   • 承担交易失败风险的补偿                              │
│   • 资金时间价值                                        │
│                                                          │
│   典型收益：                                            │
│   ────                                                  │
│   年化 5-15%（取决于交易风险）                          │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 六、事件驱动策略构建

### 6.1 策略框架

```python
class EventDrivenStrategy:
    """事件驱动策略框架"""
    
    def __init__(self, event_source, signal_generator, risk_manager):
        self.event_source = event_source
        self.signal_generator = signal_generator
        self.risk_manager = risk_manager
        self.positions = {}
    
    def on_event(self, event):
        """
        处理事件
        """
        # 1. 解析事件
        event_type = event['type']
        symbol = event['symbol']
        event_data = event['data']
        
        # 2. 生成信号
        signal = self.signal_generator.generate(event_type, event_data)
        
        if signal is None:
            return
        
        # 3. 风控检查
        if not self.risk_manager.check(signal, self.positions):
            return
        
        # 4. 执行交易
        self.execute(signal)
    
    def execute(self, signal):
        """执行交易"""
        print(f"Execute: {signal['action']} {signal['symbol']} "
              f"size={signal['size']}")


class EarningsSignalGenerator:
    """财报信号生成器"""
    
    def __init__(self, sue_threshold=1.5):
        self.sue_threshold = sue_threshold
    
    def generate(self, event_type, event_data):
        if event_type != 'earnings':
            return None
        
        sue = self._calculate_sue(event_data)
        
        if sue > self.sue_threshold:
            return {
                'action': 'buy',
                'symbol': event_data['symbol'],
                'size': self._calculate_size(sue),
                'holding_period': 20  # 持有 20 天
            }
        elif sue < -self.sue_threshold:
            return {
                'action': 'sell',
                'symbol': event_data['symbol'],
                'size': self._calculate_size(abs(sue)),
                'holding_period': 20
            }
        
        return None
    
    def _calculate_sue(self, data):
        return (data['actual_eps'] - data['expected_eps']) / data['eps_std']
    
    def _calculate_size(self, sue_abs):
        # 惊喜越大，仓位越大
        return min(1.0, sue_abs / 3.0)
```
