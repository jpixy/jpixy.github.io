## 概述

本文按**风险从低到高**整理全球主要金融品类，并列出各品类对应的**主要交易市场**，供量化交易与资产配置参考。风险划分基于**波动率、流动性、信用/对手方风险、杠杆与监管环境**等综合考量。

**本文能帮你：**

- 按风险等级快速定位资产品类与对应市场  
- 做组合配置时对照「风险阶梯」做自检  
- 查阅某一大类（股、债、期、汇、衍生品、另类）时按市场索引

## 风险等级说明

| 等级 | 含义 | 典型特征 | 典型年化波动率（示意） |
|------|------|----------|------------------------|
| 极低 | 本金与收益相对确定 | 主权信用、高流动性、无杠杆 | &lt;1% |
| 低 | 小幅波动，违约概率极低 | 投资级债券、货币市场 | 1%～3% |
| 中低 | 波动可控，流动性好 | 宽基指数 ETF、蓝筹股 | 3%～10% |
| 中 | 波动与回撤明显 | 单股、行业 ETF、可转债 | 10%～18% |
| 中高 | 高波动或杠杆 | 期货、外汇、高收益债 | 15%～25%+ |
| 高 | 大幅波动或复杂衍生品 | 期权、杠杆 ETF、新兴市场 | 20%～40%+ |
| 极高 | 投机性强、监管弱 | 加密货币、另类、高杠杆衍生品 | 40%+ 或难以估量 |

**风险驱动因素简述：**

- **极低～低**：久期短、信用高（主权/准主权）、无杠杆、流动性极好。  
- **中低～中**：久期或权益暴露增加，单一发行人/行业集中度带来波动与回撤。  
- **中高**：杠杆、保证金、汇率与商品价格波动、高收益债信用风险。  
- **高**：非线性收益（期权）、杠杆倍数、新兴市场政治与流动性风险。  
- **极高**：监管缺失、对手方/平台风险、流动性枯竭、高杠杆与投机情绪。

## 重点概念说明

以下对文中易混淆或相对不常见的概念做简要解释，便于对照表格理解。

| 概念 | 说明 |
|------|------|
| **股指期权**（Index Options） | 标的为**股票指数**（如 S&P 500、沪深 300）的期权，与「股票期权」（标的为单只股票或 ETF）不同。多数股指期权为**现金交割**（到期按指数与行权价差额结算，不交割股票），且常为**欧式**（仅到期日可行权）。用于对冲指数风险、做波动率或方向交易。 |
| **股票期权**（Equity Options） | 标的为**单只股票或 ETF** 的看涨/看跌期权，美式居多（到期前可随时行权），行权后交割股票或现金。 |
| **期货期权**（Options on Futures） | 标的为**某一期货合约**的期权，行权后得到的是该期货的多/空头寸，而非现货。常见于商品、利率、股指期货（如 CME 的 E-mini 期权）。用于在保留期货杠杆的同时限制下行风险。 |
| **波动率衍生品**（Volatility Derivatives） | 以**波动率**为标的的衍生品，如 VIX（美国恐慌指数）期货/期权、欧洲 VSTOXX 期权。不直接押注涨跌，而是押注市场波动幅度，常用于对冲尾部风险或做波动率策略。 |
| **TIPS / 通胀挂钩国债** | 本金或票息与**通胀指数**（如美国 CPI）挂钩的主权债，通胀上升时本金或利息上调，用于抵御通胀风险。 |
| **可转债**（Convertible Bonds） | 债券持有人有权在约定条件下将债券**转换为发行人的股票**，兼具债性（票息、到期还本）与股性（转股后参与股价上涨）。 |
| **优先股**（Preferred Shares） | 相对普通股享有**优先分红、优先求偿**，通常无投票权或投票权受限，股息多为固定或浮动公式，介于债与股之间。 |
| **杠杆/反向 ETF** | **杠杆 ETF**：每日追求指数收益的 N 倍（如 2x、3x）；**反向 ETF**：每日追求指数收益的 -1 倍。因**每日再平衡**，长期持有会与「N 倍指数累计收益」严重偏离，适合短期战术性交易。 |
| **二元期权**（Binary Options） | 到期时只有两种结果：要么获得固定收益，要么损失全部权利金，收益结构为「全有或全无」。零售端在多国受严格限制。 |
| **奇异期权**（Exotic Options） | 收益结构**非标准**的期权，如障碍期权、亚式期权、价差期权等，多为 OTC 定制，流动性与透明度低于普通香草期权。 |
| **价差合约**（CFD） | 不交割标的资产，仅就**标的价格变动**进行现金结算的合约，可做多/做空、带杠杆。在欧盟等地对零售杠杆有上限，中国境内禁止。 |
| **永续合约**（Perpetual） | 无到期日的期货，多见于加密货币交易所，通过**资金费率**机制使价格锚定现货，可高杠杆。 |
| **碳信用 / 排放权** | 碳排放配额（如欧盟 EU ETS）或自愿减排凭证（如 VER），可在合规市场或自愿市场交易，用于履约或 ESG 目标。 |
| **结构化票据**（Structured Notes） | 债券与衍生品的组合：本金或收益**挂钩**某一标的（股、指、商品、汇率等），可能保本、部分保本或非保本，收益结构复杂。 |
| **ADR / GDR** | **美国存托凭证**（ADR）、**全球存托凭证**（GDR）：境外公司股票由存托银行在本地发行的**凭证**，便于本地投资者交易，以当地货币计价。 |
| **利率期货** | 标的为**短期利率**（如美国 Fed Funds、欧元区 Euribor）或**国债价格/收益率**（如美国 2/5/10/30 年国债、德国 Bund）的期货，用于对冲利率风险或投机利率走向。 |
| **信用违约互换**（CDS） | 买方向卖方支付保费，若**参考实体**发生信用事件（如违约），卖方对买方进行赔付，相当于对信用风险的保险或做空，多为 OTC。 |
| **利率互换**（IRS） | 双方约定交换**固定利率与浮动利率**的利息流（本金通常不交换），用于管理利率久期或转换融资结构，OTC 为主。 |
| **认股权证**（Warrants） | 发行人（或第三方）发行的、约定在到期前以约定价格**认购**（或认沽）标的股票/指数的凭证，与交易所标准化期权不同，多为**欧式**、期限较长，流动性因标的与发行人而异。 |
| **单股期货**（Single Stock Futures） | 以**单只股票**为标的的期货，到期交割股票或现金，可做空、带杠杆。在美国产品较少；在印度、南非、欧洲等地有活跃市场。 |
| **REIT**（房地产信托） | 持有并运营**房地产或房地产相关资产**的信托，在交易所上市交易，通常须将大部分收益以股息形式分配，波动介于股票与债券之间。 |

## 一、按风险从低到高的品类清单

**风险阶梯速查（从低到高）：**  
现金/隔夜 → 国债·存款·货币基金·T-Bills → TIPS·机构债·投资级公司债·市政债·短期债券 ETF·优先股 → 宽基 ETF·中长期国债·红利/低波 ETF·REIT ETF·贵金属 ETF·商品指数 ETF → 单股·行业 ETF·可转债·高收益债·新兴市场主权债·结构化票据（保本）·碳信用 → 股指/利率/外汇/商品期货·外汇现货·中小盘股·杠杆 ETF → 股票/指数/期货/外汇/波动率期权·新兴市场股票·HY/EM 债券 ETF → 加密货币·二元/奇异期权·PE/VC·对冲基金·高杠杆保证金·粉单·非保本结构化·艺术品/另类

以下分档列出品类与主要交易市场。

### 1. 极低风险

| 品类 | 英文 | 简要说明 | 主要交易市场 |
|------|------|----------|--------------|
| 央行准备金/隔夜利率 | Central Bank Reserves / Overnight Rate | 商业银行在央行的准备金、政策利率锚定 | 各国央行（非公开市场）、银行间市场 |
| 主权国债（发达市场） | Government Bonds (DM) | 美、德、英、日等主权发行的本币国债 | **美国**：NYSE/Bond、TreasuryDirect；**德国**：Xetra、Eurex Bond；**英国**：LSE；**日本**：TSE、JGB 市场 |
| 存款/储蓄 | Deposits / Savings | 银行存款、大额存单（CD） | 商业银行、部分交易所挂牌 CD |
| 货币市场基金 | Money Market Funds (MMF) | 短久期、高流动性现金管理工具 | 基金发行方（如美国 MMF 在券商/银行申购） |

## 五、风险自检清单

在配置组合或选择交易品类时，可用下面清单做自检，避免风险错配。

### 5.1 品类与风险等级

- [ ] 我能说出自己持仓中**最高风险等级**的品类（如期权、期货、加密货币），并确认其不超过我可承受范围。  
- [ ] 高波动或带杠杆的品类（期货、期权、杠杆 ETF、加密货币）占组合比例是否设了**上限**？  
- [ ] 我是否把「极低～低风险」资产（国债、存款、货币基金）当作**应急金或底仓**，而不是全部投入高波动品种？  
- [ ] 新兴市场、高收益债、单一行业/主题 ETF 我是否了解其**额外风险**（流动性、信用、政治）？

### 5.2 市场与渠道

- [ ] 我交易的**交易所/平台**是否受当地监管、是否有投资者保护（如 SIPC、存款保险）？  
- [ ] 跨境交易（外汇、海外股票/期货、加密货币）我是否确认了**合规与税务**（如中国外汇管制、美国 PFIC 等）？  
- [ ] 我是否知道主要仓位的**流动性**在极端行情下可能变差（价差扩大、无法平仓）？

### 5.3 杠杆与保证金

- [ ] 若使用保证金或期货，我是否清楚**强平/追保规则**及最大亏损可能超过本金？  
- [ ] 杠杆 ETF 的**每日再平衡**导致的长期偏离，我是否理解并接受？

### 5.4 自检结果

- **多数勾选「是」**：说明你对品类风险、市场与杠杆有基本把握，可定期复盘组合是否仍符合风险偏好。  
- **多数不确定**：建议先缩小高波动/杠杆仓位，补课后再扩大；可重点阅读本站 [量化交易风险管理与资金管理](/articles/quant/quant-06-量化交易风险管理与资金管理/)。

## 六、常见问题（FAQ）

**Q1：同一品类在不同国家风险一样吗？**  
不完全一样。监管、流动性、汇率、税务不同，同一名称产品（如「高收益债 ETF」）在不同市场风险可能不同。表中按典型情况归类，具体需看标的与规则。

**Q2：ETF 和股票谁风险高？**  
宽基 ETF 通常比单只股票波动小（分散）；行业/主题 ETF 介于宽基与单股之间；杠杆/反向 ETF 风险高于普通股票。

**Q3：期货和期权哪个风险更大？**  
两者都可能亏损超过本金。期权买方最大亏损为期权利金，卖方与期货类似，可能面临大额亏损甚至爆仓。复杂度与流动性也会影响实际风险。

**Q4：加密货币为什么放在「极高风险」？**  
监管不统一、平台/对手方风险高、波动极大、流动性在极端时可能枯竭，且部分市场存在操纵与欺诈，综合归为极高风险。

**Q5：表中「主要交易市场」是否覆盖所有可交易渠道？**  
否。表中为代表性市场，便于查找。具体产品可能还在其他交易所或 OTC 交易，以券商/交易所公告为准。

**Q6：风险等级会变吗？**  
会。市场环境、流动性、信用事件、监管变化都可能改变某品类或某标的的实际风险，建议定期回顾组合与本文对照。
