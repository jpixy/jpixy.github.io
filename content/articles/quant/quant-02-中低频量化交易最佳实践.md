## 概述

中低频量化交易（持仓周期从天到月）是最适合个人投资者的量化方向。本文系统介绍中低频量化的最佳实践。

---

## 一、中低频策略的特点

### 1.1 定义与优势

```
中低频交易定义：

┌────────────────┬───────────────┬───────────────────────┐
│     频率       │   持仓周期    │        特点            │
├────────────────┼───────────────┼───────────────────────┤
│ 低频           │ 周 ~ 月 ~ 年 │ 最稳健，容量大         │
├────────────────┼───────────────┼───────────────────────┤
│ 中频           │ 天 ~ 周      │ 平衡风险和收益         │
├────────────────┼───────────────┼───────────────────────┤
│ 高频           │ 秒 ~ 分钟    │ 个人难以参与           │
└────────────────┴───────────────┴───────────────────────┘

中低频优势：
• 交易成本占比低
• 不需要极致技术
• 有时间分析和调整
• 更适合基本面结合
• 策略容量更大
```

### 1.2 中低频 vs 高频

```
核心差异：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   高频交易                    中低频交易                │
│   ──────────                  ──────────                │
│   拼速度                      拼逻辑                    │
│   技术驱动                    研究驱动                  │
│   统计优势                    经济逻辑                  │
│   低收益高频次                高收益低频次              │
│   容量有限                    容量较大                  │
│   衰减快                      相对稳定                  │
│                                                          │
│   中低频更适合：                                        │
│   • 结合基本面分析                                      │
│   • 利用市场非效率                                      │
│   • 价值投资的量化实现                                  │
│   • 宏观择时                                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 二、策略开发最佳实践

### 2.1 策略开发流程

```
中低频策略开发流程：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   1. 假设形成                                           │
│   ────────────                                          │
│   • 基于经济逻辑或市场观察                              │
│   • 而非数据挖掘                                        │
│   • 问：为什么这个策略应该有效？                        │
│                                                          │
│   2. 数据准备                                           │
│   ────────────                                          │
│   • 获取足够长的历史数据                                │

│   • 划分训练集/测试集                                   │
│                                                          │
│   3. 初步验证                                           │
│   ────────────                                          │
│   • 简单回测                                            │
│   • 查看是否有基本信号                                  │
│   • 不急于优化                                          │
│                                                          │
│   4. 深入研究                                           │
│   ────────────                                          │
│   • 分析不同市场环境表现                                │
│   • 收益来源分析                                        │
│   • 风险特征分析                                        │
│                                                          │
│   5. 稳健性测试                                         │
│   ────────────                                          │
│   • 样本外测试                                          │
│   • 参数敏感性分析                                      │
│   • 不同市场测试                                        │
│                                                          │
│   6. 模拟交易                                           │
│   ────────────                                          │
│   • Paper Trading 至少 3-6 个月                         │
│   • 验证执行可行性                                      │
│                                                          │
│   7. 小资金实盘                                         │
│   ────────────                                          │
│   • 从小资金开始                                        │
│   • 逐步增加                                            │
│                                                          │

### 2.2 策略设计原则

```
好策略的特征：

┌─────────────────────────────────────────────────────────┐

│   1. 有经济逻辑                                         │

## 三、回测最佳实践

### 3.1 避免回测陷阱

```
常见回测陷阱及解决：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   Look-ahead Bias（前视偏差）                           │
│   ─────────────────────────                             │
│   问题：使用了未来才知道的信息                          │
│   解决：严格使用截止到决策时刻的数据                    │
│                                                          │
│   Survivorship Bias（幸存者偏差）                       │
│   ─────────────────────────                             │
│   问题：只用存活的股票，忽略退市的                      │
│   解决：使用包含退市股票的完整数据                      │
│                                                          │
│   Overfitting（过拟合）                                 │
│   ─────────────────────────                             │
│   问题：过度优化参数，拟合噪音                          │
│   解决：简化参数、样本外测试、Walk-forward              │
│                                                          │
│   Data Snooping（数据窥探）                             │
│   ─────────────────────────                             │
│   问题：反复测试直到"发现"有效策略                     │
│   解决：留出真正未见过的测试集                          │
│                                                          │
│   忽视交易成本                                          │
│   ─────────────────────────                             │
│   问题：不考虑佣金、滑点                                │
│   解决：加入真实的成本估算                              │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 回测设计

```
回测分割方法：

方法1：训练/测试分割

┌─────────────────────────────────────────┐
│                                          │
│  ├──────── 训练集 ────────┤├─ 测试集 ─┤ │
│  │         70%            ││    30%    │ │
│  └────────────────────────┴───────────┘ │
│                                          │
└─────────────────────────────────────────┘

方法2：Walk-forward（推荐）

┌─────────────────────────────────────────┐
│                                          │
│  训练1 │测试1│                          │
│  ──────┼────┼                           │
│        │训练2 │测试2│                   │
│        └─────┼────┼                     │
│              │训练3 │测试3│             │
│              └─────┼────┼               │
│                    │训练4 │测试4│       │
│                    └─────┴────┘         │
│                                          │
│  滚动窗口训练和测试                      │
│                                          │
└─────────────────────────────────────────┘

方法3：K-Fold 交叉验证
• 适合数据量有限时
• 注意时间序列的顺序性
```

### 3.3 绩效评估指标

```
核心评估指标：

┌─────────────────┬────────────────────────────────────┐
│      指标       │              说明                   │
├─────────────────┼────────────────────────────────────┤
│ 年化收益率      │ 策略的平均年度收益                  │
├─────────────────┼────────────────────────────────────┤
│ 夏普比率        │ 风险调整收益，> 1 较好              │
│ (Sharpe Ratio)  │ = (收益 - 无风险利率) / 波动率     │
├─────────────────┼────────────────────────────────────┤
│ 最大回撤        │ 从峰值到谷底的最大跌幅              │
│ (Max Drawdown)  │ 越小越好                           │
├─────────────────┼────────────────────────────────────┤
│ 卡玛比率        │ 年化收益 / 最大回撤                 │
│ (Calmar Ratio)  │ > 1 较好                           │
├─────────────────┼────────────────────────────────────┤
│ 胜率            │ 盈利交易占比                        │
├─────────────────┼────────────────────────────────────┤
│ 盈亏比          │ 平均盈利 / 平均亏损                 │
├─────────────────┼────────────────────────────────────┤
│ Alpha           │ 超越基准的超额收益                  │
├─────────────────┼────────────────────────────────────┤
│ Beta            │ 与市场的相关性                      │
└─────────────────┴────────────────────────────────────┘

健康策略参考：
• 夏普比率 > 1
• 最大回撤 < 20-30%
• 卡玛比率 > 1
```

## 四、风险管理

### 4.1 仓位管理

```
仓位管理方法：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   固定金额法                                            │
│   ────────────                                          │
│   每次投入固定金额                                      │
│   例：每只股票投入 10 万                                │
│   简单但不考虑风险差异                                  │
│                                                          │
│   固定比例法                                            │
│   ────────────                                          │
│   每次投入账户的固定比例                                │
│   例：每只股票投入总资金的 5%                           │
│   自动再平衡                                            │
│                                                          │
│   波动率调整法（推荐）                                  │
│   ────────────                                          │
│   根据标的波动率调整仓位                                │
│   高波动 → 低仓位                                       │
│   低波动 → 高仓位                                       │
│   保持风险贡献一致                                      │
│                                                          │
│   Kelly 公式                                            │
│   ────────────                                          │
│   f = (bp - q) / b                                      │
│   b=赔率, p=胜率, q=败率                                │
│   理论最优，实践中用一半 Kelly                          │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 4.2 止损策略

```
止损类型：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   固定止损                                              │
│   ────────                                              │
│   亏损达到固定百分比止损                                │
│   例：-5% 止损                                          │
│   简单但可能频繁止损                                    │
│                                                          │
│   ATR 止损                                              │
│   ────────                                              │
│   基于 Average True Range                               │
│   例：2 倍 ATR 止损                                     │
│   考虑波动性，更灵活                                    │
│                                                          │
│   时间止损                                              │
│   ────────                                              │
│   持仓一定时间后未盈利则退出                            │
│   例：5 天内无起色则出场                                │
│                                                          │
│   跟踪止损                                              │
│   ────────                                              │
│   随价格上涨移动止损点                                  │
│   锁定利润                                              │
│                                                          │
│   策略止损                                              │
│   ────────                                              │
│   当策略信号转弱或逆转时退出                            │
│   最符合策略逻辑                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 4.3 组合风险管理

```
组合层面风险控制：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   分散化                                                │
│   ────────                                              │
│   • 多个不相关策略                                      │
│   • 多个市场/资产                                       │
│   • 避免集中在单一因子                                  │
│                                                          │
│   相关性控制                                            │
│   ────────                                              │
│   • 监控策略间相关性                                    │
│   • 避免高度相关的策略                                  │
│   • 危机时相关性会上升                                  │
│                                                          │
│   总仓位控制                                            │
│   ────────                                              │
│   • 设置最大总仓位                                      │
│   • 市场极端时降低仓位                                  │
│   • 保持现金储备                                        │
│                                                          │
│   回撤控制                                              │
│   ────────                                              │
│   • 设置最大允许回撤                                    │
│   • 达到阈值时减仓                                      │
│   • 给自己冷静期                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 五、执行最佳实践

### 5.1 执行注意事项

```
从回测到实盘的差距：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   滑点                                                  │
│   ────                                                  │
│   • 实际成交价与预期价格的差异                          │
│   • 流动性差时更严重                                    │
│   • 回测时要加入滑点估算                                │
│                                                          │
│   延迟                                                  │
│   ────                                                  │
│   • 信号产生到执行的时间差                              │
│   • 中低频影响较小，但要考虑                            │
│                                                          │
│   部分成交                                              │
│   ────                                                  │
│   • 大单可能无法一次成交                                │
│   • 需要分批执行策略                                    │
│                                                          │
│   市场冲击                                              │
│   ────                                                  │
│   • 大额交易影响价格                                    │
│   • 小资金影响小                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```
