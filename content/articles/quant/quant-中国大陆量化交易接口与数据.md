## 二、交易接口

### 2.1 股票/基金接口

```
A股程序化交易接口：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   券商官方接口（有限）                                  │
│   ────────────────────                                  │
│   • 大多数券商不对个人开放程序化接口                    │
│   • 部分券商有条件开放（如资金量要求）                  │
│   • 需咨询具体券商                                      │
│                                                          │
│   第三方接口                                            │
│   ────────────────────                                  │
│   • QMT（迅投）                                         │
│     - 部分券商支持                                      │
│     - 需申请，有一定门槛                                │
│     - 较专业的量化平台                                  │
│                                                          │
│   • PTrade（恒生）                                      │
│     - 机构级别                                          │
│     - 个人较难获取                                      │
│                                                          │
│   • easytrader（开源）                                  │
│     - 模拟客户端操作                                    │
│     - 非官方，有风险                                    │
│     - 稳定性不保证                                      │
│                                                          │
│   模拟盘接口                                            │
│   ────────────────────                                  │
│   • 聚宽模拟交易                                        │
│   • 米筐模拟交易                                        │
│   • 优矿模拟交易                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘

⚠️ 注意：
• A股程序化交易对个人限制较多
• 谨慎使用非官方接口
• 优先考虑券商官方渠道
```

│   1. 在期货公司开户                                     │
│   2. 申请 CTP 接口                                      │

│   ────────────────                                      │

│   • 恒生 UFT                                            │

└─────────────────────────────────────────────────────────┘

期货量化开发示例（vnpy）：

main_engine = MainEngine()
main_engine.add_gateway(CtpGateway)

# 连接
setting = {
    "用户名": "xxx",
    "密码": "xxx",
    "经纪商代码": "xxx",
    "交易服务器": "xxx",
    "行情服务器": "xxx",
}
main_engine.connect(setting, "CTP")
```
