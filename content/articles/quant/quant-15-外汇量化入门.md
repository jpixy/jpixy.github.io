## 概述

外汇市场是全球最大的金融市场，日交易量超过 6 万亿美元。24/5 交易、高流动性和杠杆特性使其对量化交易者具有吸引力，但也伴随着独特的风险。

### 2.2 报价方式

```
外汇报价：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   基本概念：                                            │
│   ──────────                                            │
│   EUR/USD = 1.1000                                      │
│   意思：1 欧元 = 1.1000 美元                            │
│                                                          │
│   基础货币（Base）：EUR（前面）                         │

│                                                          │
│   买入/卖出：                                           │
│   ──────────                                            │
│   Bid（买价）：1.0998 — 你卖出基础货币的价格            │
│   Ask（卖价）：1.1002 — 你买入基础货币的价格            │

│                                                          │
│   点（Pip）：                                           │
│   ──────────                                            │
│   • 大多数货币对：小数点后第 4 位                       │
│   • EUR/USD 从 1.1000 到 1.1001 = 1 点                  │
│   • 日元货币对：小数点后第 2 位                         │
│   • USD/JPY 从 110.00 到 110.01 = 1 点                  │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 三、杠杆与风险

### 3.1 杠杆机制

```
外汇杠杆：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   杠杆倍数：                                            │
│   ──────────                                            │
│   • 零售外汇通常提供 50:1 到 500:1 杠杆                 │
│   • 100:1 意味着 $1,000 可以控制 $100,000               │
│                                                          │
│   保证金计算：                                          │
│   ──────────                                            │
│   保证金 = 头寸大小 / 杠杆                              │
│   例：$100,000 头寸，100:1 杠杆                         │
│   保证金 = $100,000 / 100 = $1,000                      │
│                                                          │
│   盈亏计算：                                            │
│   ──────────                                            │
│   EUR/USD 买入 1 标准手（100,000）                      │
│   价格从 1.1000 涨到 1.1050 = 50 点                     │
│   盈利 = 50 点 × $10/点 = $500                          │
│                                                          │
│   ⚠️ 杠杆是双刃剑                                       │
│   ──────────                                            │
│   同样的价格变动：                                      │
│   • 1:1 杠杆：盈亏 0.5%                                 │
│   • 100:1 杠杆：盈亏 50%                                │
│   高杠杆放大收益，也放大亏损                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 风险管理

```
外汇风险管理：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   杠杆建议：                                            │
│   ──────────                                            │
│   • 新手：不超过 10:1                                   │
│   • 有经验：不超过 20:1                                 │
│   • 高杠杆 = 高风险爆仓                                 │
│                                                          │
│   仓位计算：                                            │
│   ──────────                                            │
│   单笔风险 = 账户 × 1-2%                                │
│   仓位大小 = 单笔风险 / 止损点数 / 每点价值             │
│                                                          │
│   示例：                                                │
│   账户 $10,000，风险 1%，止损 50 点                     │
│   单笔风险 = $100                                       │
│   仓位 = $100 / 50 点 / $10 = 0.2 手                    │
│                                                          │
│   止损必须设置：                                        │
│   ──────────                                            │
│   • 外汇波动快                                          │
│   • 杠杆放大损失                                        │
│   • 周末跳空风险                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 四、外汇量化策略

### 4.1 趋势跟踪

```
外汇趋势策略：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   适用性：                                              │
│   ────────                                              │
│   • 外汇市场存在明显趋势                                │
│   • 央行政策、经济周期驱动                              │
│   • 趋势可以持续数月                                    │
│                                                          │
│   常用方法：                                            │
│   ────────                                              │
│   • 均线系统（如 20/50/200 日）                         │
│   • 通道突破（Donchian Channel）                        │
│   • 动量指标（ADX 确认趋势强度）                        │
│                                                          │
│   多货币对分散：                                        │
│   ────────                                              │
│   • 同时交易多个货币对                                  │
│   • 降低单一货币对风险                                  │
│   • 捕捉更多趋势机会                                    │
│                                                          │
└─────────────────────────────────────────────────────────┘

示例：均线趋势系统
```python
def forex_trend_strategy(data, fast=20, slow=50):
    data['MA_fast'] = data['close'].rolling(fast).mean()
    data['MA_slow'] = data['close'].rolling(slow).mean()
    
    # 多头信号
    data['long'] = (data['MA_fast'] > data['MA_slow']) & \
                   (data['MA_fast'].shift(1) <= data['MA_slow'].shift(1))
    
    # 空头信号
    data['short'] = (data['MA_fast'] < data['MA_slow']) & \
                    (data['MA_fast'].shift(1) >= data['MA_slow'].shift(1))
    
    return data
```

### 4.2 套息交易（Carry Trade）

```
套息交易：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   原理：                                                │
│   ────                                                  │
│   • 借入低利率货币                                      │
│   • 买入高利率货币                                      │
│   • 赚取利差                                            │
│                                                          │
│   示例：                                                │
│   ────                                                  │
│   日本利率：0.1%                                        │
│   澳大利亚利率：4.0%                                    │
│   借日元买澳元，赚取约 3.9% 年利差                      │
│                                                          │
│   执行方式：                                            │
│   ────                                                  │
│   • 做多 AUD/JPY                                        │
│   • 每日获得正向隔夜利息（Swap）                        │
│                                                          │
│   风险：                                                │
│   ────                                                  │
│   • 汇率波动可能大于利差收益                            │
│   • 风险情绪转变时高息货币暴跌                          │
│   • 2008 年危机套息交易巨亏                             │
│                                                          │
│   适合：                                                │
│   ────                                                  │
│   • 风险情绪稳定时期                                    │
│   • 结合趋势判断                                        │
│   • 控制杠杆                                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 5.2 API 接口

```python
# OANDA API 示例
import oandapyV20
from oandapyV20 import API
from oandapyV20.endpoints import orders, pricing

client = API(access_token='YOUR_TOKEN', environment='practice')

# 获取报价
params = {'instruments': 'EUR_USD,USD_JPY'}
r = pricing.PricingInfo(accountID='YOUR_ACCOUNT', params=params)
response = client.request(r)

for price in response['prices']:
    print(f"{price['instrument']}: {price['bids'][0]['price']}/{price['asks'][0]['price']}")

# 下单
data = {
    'order': {
        'instrument': 'EUR_USD',
        'units': '10000',  # 0.1 手
        'type': 'MARKET',
        'positionFill': 'DEFAULT'
    }
}
r = orders.OrderCreate(accountID='YOUR_ACCOUNT', data=data)
client.request(r)
