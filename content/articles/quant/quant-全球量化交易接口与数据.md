## 二、交易接口

### 2.1 Interactive Brokers（盈透证券）

```
Interactive Brokers（IB）⭐ 强烈推荐

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   优点                                                  │
│   ────                                                  │
│   • 全球市场覆盖（150+ 市场）                           │
│   • 专业的 API 接口                                     │
│   • 低佣金                                              │
│   • 支持多种资产类别                                    │
│   • 个人可开户                                          │
│                                                          │
│   API 接口                                              │
│   ────                                                  │
│   • TWS API（Java/C++/C#/Python）                       │
│   • Client Portal API（REST）                           │
│   • ib_insync（Python 推荐）                            │
│                                                          │
│   门槛                                                  │
│   ────                                                  │
│   • 最低入金要求（不同地区不同）                        │
│   • 需要一定编程能力                                    │
│                                                          │
│   费用                                                  │
│   ────                                                  │
│   • 市场数据费（可选）                                  │
│   • 交易佣金（较低）                                    │
│                                                          │
└─────────────────────────────────────────────────────────┘

Python 示例（ib_insync）：
```python
from ib_insync import *

# 连接
ib = IB()
ib.connect('127.0.0.1', 7497, clientId=1)

# 获取行情
contract = Stock('AAPL', 'SMART', 'USD')
ib.qualifyContracts(contract)
ticker = ib.reqMktData(contract)

# 下单
order = MarketOrder('BUY', 100)
trade = ib.placeOrder(contract, order)

ib.disconnect()
```

Alpaca（零佣金）

┌─────────────────────────────────────────────────────────┐

│                                                          │
│   地址：alpaca.markets                                  │
│                                                          │

Python 示例：
```python
import alpaca_trade_api as tradeapi

api = tradeapi.REST(
    key_id='YOUR_API_KEY',
    secret_key='YOUR_SECRET_KEY',
    base_url='https://paper-api.alpaca.markets'  # 模拟盘
)

# 获取账户
account = api.get_account()

# 下单
api.submit_order(
    symbol='AAPL',
    qty=10,
    side='buy',
    type='market',
    time_in_force='gtc'
)
```
