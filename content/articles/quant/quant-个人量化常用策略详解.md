## 概述

量化策略种类繁多，但并非所有策略都适合个人投资者。本文详细介绍几类经过验证、适合中低频个人量化的经典策略。

## 一、策略分类

### 1.1 按交易逻辑分类

```
主要策略类型：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   趋势跟踪 (Trend Following)                            │
│   ──────────────────────────                            │
│   核心思想：顺势而为，追涨杀跌                          │
│   持仓周期：中长期                                      │

│                                                          │
│   均值回归 (Mean Reversion)                             │
│   ──────────────────────────                            │
│   核心思想：物极必反，逆势操作                          │
│   持仓周期：短中期                                      │
│   胜率较高，但盈亏比低                                  │
│                                                          │
│   动量策略 (Momentum)                                   │
│   ──────────────────────────                            │
│   核心思想：强者恒强，弱者恒弱                          │
│   持仓周期：中期                                        │
│   在不同资产类别间轮动                                  │
│                                                          │
│   因子投资 (Factor Investing)                           │
│   ──────────────────────────                            │
│   核心思想：根据特定因子选股                            │
│   持仓周期：中长期                                      │
│   如价值、质量、规模等因子                              │
│                                                          │
│   统计套利 (Statistical Arbitrage)                      │
│   ──────────────────────────                            │
│   核心思想：利用统计关系                                │
│   持仓周期：短期                                        │
│   如配对交易                                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 二、趋势跟踪策略

### 2.1 策略原理

```
趋势跟踪核心思想：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   "截断亏损，让利润奔跑"                                │
│   (Cut losses short, let profits run)                   │
│                                                          │
│   基本假设：                                            │
│   • 市场存在趋势                                        │
│   • 趋势会延续一段时间                                  │
│   • 无法预测趋势何时开始/结束                           │
│   • 但可以在趋势中获利                                  │
│                                                          │
│   特点：                                                │
│   • 胜率低（30-40%）                                    │
│   • 盈亏比高（2:1 以上）                                │
│   • 需要严格止损                                        │
│   • 适合趋势明显的市场                                  │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 2.2 经典策略：双均线

```
双均线策略：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   规则：                                                │
│   • 短期均线上穿长期均线 → 买入                         │
│   • 短期均线下穿长期均线 → 卖出                         │
│                                                          │
│   常用参数：                                            │
│   • 5日/20日                                            │
│   • 10日/50日                                           │
│   • 50日/200日（黄金交叉）                              │
│                                                          │
│   示意图：                                              │
│                                                          │
│   价格 ─────────────────────                            │
│        ╱╲    ╱────╲                                     │
│       ╱  ╲  ╱      ╲                                    │
│      ╱    ╲╱        ╲                                   │
│   短期均线 -----                                        │
│   长期均线 ───                                          │
│              ↑买入    ↓卖出                             │
│                                                          │
└─────────────────────────────────────────────────────────┘

Python 示例：
```python
import pandas as pd

def dual_ma_strategy(df, short=10, long=50):
    df['MA_short'] = df['close'].rolling(short).mean()
    df['MA_long'] = df['close'].rolling(long).mean()
    
    df['signal'] = 0
    df.loc[df['MA_short'] > df['MA_long'], 'signal'] = 1
    df.loc[df['MA_short'] < df['MA_long'], 'signal'] = -1
    
    df['position'] = df['signal'].shift(1)  # 避免 look-ahead
    return df
```

### 2.3 经典策略：海龟交易

```
海龟交易策略：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   入场规则：                                            │
│   • 突破 20 日最高价 → 买入                             │
│   • 突破 20 日最低价 → 卖出/做空                        │
│                                                          │
│   出场规则：                                            │
│   • 突破 10 日最低价 → 平多仓                           │
│   • 突破 10 日最高价 → 平空仓                           │
│                                                          │
│   仓位管理（ATR 法）：                                  │
│   • 每单位 = 账户 1% / ATR                              │
│   • 最多 4 个单位                                       │
│   • 加仓条件：盈利 0.5 ATR                              │
│                                                          │
│   止损：                                                │
│   • 2 ATR 止损                                          │
│                                                          │
└─────────────────────────────────────────────────────────┘

核心概念 - ATR（平均真实波动幅度）：
• 衡量市场波动性
• 用于自适应仓位和止损
• ATR = 过去 N 日真实波幅的平均
```

## 三、动量/轮动策略

### 3.1 策略原理

```
动量效应：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   核心发现（学术验证）：                                │
│   • 过去表现好的资产，未来一段时间继续表现好            │
│   • 过去表现差的资产，未来一段时间继续表现差            │
│   • 中期有效（3-12个月）                                │
│                                                          │
│   可能原因：                                            │
│   • 投资者反应不足                                      │
│   • 信息传播延迟                                        │
│   • 行为偏差（锚定、保守）                              │
│                                                          │
│   应用：                                                │
│   • 资产类别轮动（股票/债券/商品）                      │
│   • 行业轮动                                            │
│   • 个股动量选股                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 ETF 轮动策略

```
ETF 轮动策略示例：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   标的池（示例）：                                      │
│   • SPY（美国大盘）                                     │
│   • QQQ（纳斯达克）                                     │
│   • IWM（美国小盘）                                     │
│   • EFA（发达市场）                                     │
│   • EEM（新兴市场）                                     │
│   • TLT（长期国债）                                     │
│   • GLD（黄金）                                         │
│                                                          │
│   规则：                                                │
│   • 每月末计算过去 N 个月收益                           │
│   • 选择收益最高的 2-3 只                               │
│   • 等权重持有                                          │
│   • 下月末再平衡                                        │
│                                                          │
│   变体：                                                │
│   • 加入绝对收益过滤（负收益不买）                      │
│   • 使用风险调整收益（夏普比）                          │
│   • 加入趋势过滤                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘

Python 示例：
```python
def momentum_rotation(prices, lookback=6, n_hold=3):
    # 计算过去 lookback 个月收益
    returns = prices.pct_change(lookback * 21)  # 假设每月 21 交易日
    
    # 排名，选择最高的 n_hold 个
    rankings = returns.rank(axis=1, ascending=False)
    
    # 生成持仓信号
    weights = (rankings <= n_hold).astype(float)
    weights = weights.div(weights.sum(axis=1), axis=0)  # 等权重
    
    return weights
```

### 3.3 双动量策略

```
Gary Antonacci 双动量策略：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   绝对动量（Absolute Momentum）                         │
│   ────────────────────────────                          │
│   • 资产收益 > 无风险利率 → 持有                        │
│   • 资产收益 < 无风险利率 → 不持有/持有现金             │
│                                                          │
│   相对动量（Relative Momentum）                         │
│   ────────────────────────────                          │
│   • 比较多个资产的相对强弱                              │
│   • 持有最强的资产                                      │
│                                                          │
│   双动量组合：                                          │
│   1. 先用相对动量选择最强资产                           │
│   2. 再用绝对动量过滤（避免熊市持有）                   │
│   3. 不满足条件则持有债券/现金                          │
│                                                          │
│   示例（GEM - Global Equity Momentum）：                │
│   • 标的：美国股票 vs 国际股票                          │
│   • 比较过去 12 个月收益                                │
│   • 选强者，但需超过国债收益                            │
│   • 否则持有债券                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 四、均值回归策略

### 4.1 策略原理

```
均值回归思想：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   核心假设：                                            │
│   • 价格围绕均值波动                                    │
│   • 偏离过大会回归                                      │
│   • 极端状态不会持续                                    │
│                                                          │
│   典型场景：                                            │
│   • 超跌反弹                                            │
│   • 超买回调                                            │
│   • 价差收敛                                            │
│                                                          │
│   风险：                                                │
│   • "便宜可能更便宜"                                   │
│   • 趋势市场表现差                                      │
│   • 需要判断何时"够便宜"                               │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 4.2 RSI 策略

```
RSI 均值回归策略：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   RSI（相对强弱指数）：                                 │
│   • 衡量价格涨跌的强度                                  │
│   • 范围 0-100                                          │
│   • >70 超买，<30 超卖                                  │
│                                                          │
│   简单策略：                                            │
│   • RSI < 30 → 买入                                     │
│   • RSI > 70 → 卖出                                     │
│                                                          │
│   改进版本：                                            │
│   • 使用 RSI(2) 更敏感                                  │
│   • 累积 RSI 信号                                       │
│   • 结合趋势过滤                                        │
│                                                          │
└─────────────────────────────────────────────────────────┘

Python 示例：
```python
def rsi_strategy(df, period=14, oversold=30, overbought=70):
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0)
    loss = -delta.where(delta < 0, 0)
    
    avg_gain = gain.rolling(period).mean()
    avg_loss = loss.rolling(period).mean()
    
    rs = avg_gain / avg_loss
    df['RSI'] = 100 - (100 / (1 + rs))
    
    df['signal'] = 0
    df.loc[df['RSI'] < oversold, 'signal'] = 1    # 买入
    df.loc[df['RSI'] > overbought, 'signal'] = -1  # 卖出
    
    return df
```

### 4.3 布林带策略

```
布林带均值回归：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   布林带构成：                                          │
│   • 中轨：N 日移动平均                                  │
│   • 上轨：中轨 + K 倍标准差                             │
│   • 下轨：中轨 - K 倍标准差                             │
│   • 通常 N=20, K=2                                      │
│                                                          │
│   均值回归策略：                                        │
│   • 价格触及下轨 → 买入                                 │
│   • 价格回到中轨 → 平仓                                 │
│   • 价格触及上轨 → 卖出/做空                            │
│                                                          │
│   注意：                                                │
│   • 趋势市场会沿着轨道运行                              │
│   • 需要判断震荡 vs 趋势环境                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 五、因子投资

### 5.1 经典因子

```
五大经典因子（Fama-French + Momentum）：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   市场因子（Market）                                    │
│   ────────────────                                      │
│   股票 vs 无风险资产的超额收益                          │
│   Beta 风险                                             │
│                                                          │
│   规模因子（Size - SMB）                                │
│   ────────────────                                      │
│   小盘股 vs 大盘股                                      │
│   小公司溢价                                            │
│                                                          │
│   价值因子（Value - HML）                               │
│   ────────────────                                      │
│   高账面市值比 vs 低账面市值比                          │
│   便宜股票溢价                                          │
│                                                          │
│   动量因子（Momentum - UMD）                            │
│   ────────────────                                      │
│   过去赢家 vs 过去输家                                  │
│   趋势延续                                              │
│                                                          │
│   质量因子（Quality）                                   │
│   ────────────────                                      │
│   高盈利质量 vs 低盈利质量                              │
│   ROE、毛利率等                                         │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 5.2 因子策略实现

```
因子策略构建流程：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   1. 因子计算                                           │
│   ────────────                                          │
│   • 获取财务数据                                        │
│   • 计算因子值（如 P/B, ROE）                           │
│   • 数据清洗和标准化                                    │
│                                                          │
│   2. 因子排名                                           │
│   ────────────                                          │
│   • 对所有股票按因子值排名                              │

│                                                          │
│   3. 组合构建                                           │
│   ────────────                                          │
│   • 做多高分位组                                        │
│   • （可选）做空低分位组                                │
│   • 等权或市值加权                                      │
│                                                          │
│   4. 定期再平衡                                         │
│   ────────────                                          │
│   • 月度或季度调仓                                      │
│   • 根据最新因子值重新排名                              │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

```

### 6.2 风险平价

```
风险平价配置：

┌─────────────────────────────────────────────────────────┐
│                                                          │
│   核心思想：                                            │
│   • 各资产贡献相同的风险                                │
│   • 而非相同的资金                                      │
│                                                          │
│   传统 60/40 问题：                                     │
│   • 60% 股票 + 40% 债券                                 │
│   • 但股票波动大，贡献 90%+ 风险                        │
│   • 实际上仍是股票主导                                  │
│                                                          │
│   风险平价做法：                                        │
│   • 低波动资产（债券）：高权重                          │
│   • 高波动资产（股票）：低权重                          │
│   • 各资产风险贡献相等                                  │
│                                                          │
│   计算：                                                │
│   权重 ∝ 1 / 波动率                                     │
│                                                          │
└─────────────────────────────────────────────────────────┘
```
